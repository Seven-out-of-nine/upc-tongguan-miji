# 离散数学 · 笔记分享

[返回本课程](../README.md) · [返回社区首页](../../README.md) · [贡献教程](../../CONTRIBUTING.md)

这里收集同学们分享的离散数学课堂笔记、知识总结、错题笔记与复习笔记。

## 提交约定

本课程的同学笔记统一放在 **`离散数学/笔记分享/`**，可以按学年、章节或主题继续建立子目录。课件、习题和历年试题等其他资料仍放在本课程相应分类中。

- 文件名建议写清学年、章节或主题，例如 `2026-2027_章节主题_个人笔记.pdf`；学年请按实际情况填写。
- 在 PR 或笔记开头简要注明内容、适用范围和整理者／来源；个人解答与待核对内容请标清。
- 保留原作者署名和授权说明，分享允许公开的内容，去除学号、联系方式等个人信息。

## 怎样分享

在自己的 Fork 中进入本目录，点击 **Add file → Upload files** 上传笔记并提交，再向主仓库发起 Pull Request。完整步骤见[网页上传教程](../../README.md#first-upload)。

欢迎从一页笔记或一个知识点开始，和其他同学一起补充完善。
