## 题目

F11.05 非偶数除数【★★】【函数+整型数组+指针】

【题目描述】
请编写函数Fun ，它的功能是：求出能整除参数 x 且不是偶数的各整数 , 并按从小到大的顺序放在 aa数组中 , 这些除数的个数通过形参 n 返回。

【输入】

一个整数x。

【输出】

能整除形参 x 且不是偶数的各整数。

【提示】

**注意：本题只需提交Fun函数即可**

预设代码

前置代码

```text
#include <stdio.h>
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main( )
{  
      int  x, aa[1000], n, i ;
      scanf("%d", &x) ;
      Fun(x, aa, &n ) ;
      for( i = 0 ; i < n ; i++ )
           printf(" %d", aa[i]) ;
      printf("\n") ;
      return 0;
}
```

例如:

**样例 1**

**输入：**

```text
35
```

**输出：**

```text
 1 5 7 35
```

**样例 2**

**输入：**

```text
100
```

**输出：**

```text
 1 5 25
```

### 题目与实现说明

- 原题未给x范围，按原main使用正整数和1000项结果数组；枚举法便于入门，运行时间随x增大。

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(int x, int aa[], int *n) {
    *n = 0;
    for (long long d = 1; d <= x; d += 2) {
        if (x % d == 0) aa[(*n)++] = (int)d;
    }
}
```

<details>
<summary>展开完整本地运行程序</summary>

```c
#include <stdio.h>
#include <string.h>

void Fun(int x, int aa[], int *n) {
    *n = 0;
    for (long long d = 1; d <= x; d += 2) {
        if (x % d == 0) aa[(*n)++] = (int)d;
    }
}

int main(void) {
    int x, aa[1000], n;
    scanf("%d", &x);
    Fun(x, aa, &n);
    for (int i = 0; i < n; i++) printf(" %d", aa[i]);
    printf("\n");
    return 0;
}
```

## 讲解

1. 按正整数的常规除数定义，从1开始枚举所有奇数候选。
2. 候选d若满足x%d==0，就能整除x，放入aa并增加计数。
3. 从小到大枚举，保存顺序自然也是从小到大；例如12只留下1、3。
