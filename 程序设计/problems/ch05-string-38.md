## 题目

【题目描述】

求两个不超过100位的非负整数的乘积。

【输入】

有两行，每行是一个不超过100位的非负整数，没有多余的前导0。

【输出】

一行，相乘后的结果。

例如:

**输入：**

```text
123456789
123456789
```

**输出：**

```text
15241578750190521
```

## 解答

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char a[101], b[101]; int result[202] = {0}; scanf("%100s%100s", a, b);
    int n = (int)strlen(a), m = (int)strlen(b);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j)
            result[i + j] += (a[n - 1 - i] - '0') * (b[m - 1 - j] - '0');
    for (int i = 0; i < n + m; ++i) {
        result[i + 1] += result[i] / 10;
        result[i] %= 10;
    }
    int top = n + m;
    while (top > 0 && result[top] == 0) --top;
    for (int i = top; i >= 0; --i) printf("%d", result[i]);
    putchar('\n'); return 0;
}
```

## 讲解

1. 按竖式乘法，把a的每一位与b的每一位相乘。
2. 从右往左编号为0、1、2，两个编号相加就是积要加入的列。
3. 例如12×13，低位列为2×3=6，十位列为1×3+2×1=5，百位列为1，得到156。
4. 所有部分积累加后，从低位向高位统一进位，再倒序输出。

## 知识点总结

- **数位数组的竖式乘法**：个位编号为0时，第i位乘第j位的积贡献给第i+j列；把所有部分积累加后，再从低位向高位统一进位。它沿用数位数组表示，但先做每位两两相乘，不是把两个大整数转换成普通整型相乘；结果最多为两数位数之和位。

## 易错点

- 积为0时仍应输出一个0。
- 两个100位数的积最多200位，数组需留够进位位置。
