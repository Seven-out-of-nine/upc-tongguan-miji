## 题目

2002 精挑细选的钢管

Description

仓库里有大量的钢管，长短粗细不一，并不完全相同。但是每根钢管确保有唯一的一个编码。现在工程师需要从仓库中找出一根钢管，要求如下：

1.这根钢管一定要是仓库中最长的；

2.这根钢管一定要是最长的钢管中最细的；

3.这根钢管一定要是符合前两条的钢管中编码最大的。

Input

第一行一个整数T（0&lt;T&lt;50），所有钢管的数量。

之后有T行，每行三个整数，分别表示一根钢管的长度（毫米）、直径（毫米）和编码（一个9位整数）

Output

一个9位整数，表示选出的那根钢管的编码。

例如:

**输入：**

```text
3
1000 10 123456789
1000 10 123456788
1000 10 123456787
```

**输出：**

```text
123456789
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int n; scanf("%d", &n);
    int best_length, best_diameter, best_id;
    scanf("%d%d%d", &best_length, &best_diameter, &best_id);
    for (int i = 1; i < n; ++i) {
        int length, diameter, id; scanf("%d%d%d", &length, &diameter, &id);
        if (length > best_length ||
            (length == best_length && diameter < best_diameter) ||
            (length == best_length && diameter == best_diameter && id > best_id)) {
            best_length = length; best_diameter = diameter; best_id = id;
        }
    }
    printf("%d\n", best_id); return 0;
}
```

## 讲解

1. 先把第一根钢管设为当前最优，随后逐根比较。
2. 优先比较长度，更长就替换；长度相同才比较直径，更细就替换。
3. 长度和直径都相同，才比较编码，保留编码较大者。
4. 例如同为1000毫米且直径10毫米，编码123456789优于123456788。

## 知识点总结

- 三个变量成组保存：最优钢管的长度、直径和编码要一起更新。
- 逻辑或：三种能够胜出的情况满足一种即可。
- &&：只有前一优先级相等时才进入下一条件。

## 易错点

- 不能先在全部钢管中找最细者，必须先限定最长。
- 编码只在前两项完全相同时决定胜负。
