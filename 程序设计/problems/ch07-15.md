## 题目

3.11 游泳池改造预算【★】

一个圆形游泳池如图所示，现在需要在其周围建一个圆形过道，并在其四周围上栅栏。栅栏价格为35元/米，过道造价为20元/平方米。过道宽度为3米，游泳池半径由键盘输入。要求编程计算并输出过道和栅栏的造价。

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Circle {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    double circumference() const { return 2 * 3.14 * radius; }
    double area() const { return 3.14 * radius * radius; }
};
int main() {
    double radius;
    cout << "Enter the radius of the pool:\n";
    cin >> radius;
    Circle pool(radius), rim(radius+3);
    cout << "Fencing Cost is $" << rim.circumference()*35 << '\n';
    cout << "Concrete Cost is $" << (rim.area()-pool.area())*20 << '\n';
    return 0;
}
```

## 讲解

1. 游泳池半径为r，过道宽3米，因此外圈半径为r+3。
2. 栅栏围在外圈上，长度是外圆周长；乘35得到栅栏造价。
3. 过道是圆环，面积为外圆面积减游泳池面积，再乘20得到过道造价。
4. 例如r=2，外圈半径5，栅栏费1099，过道费1318.8。

## 知识点总结

- 用同一个Circle类创建pool与rim两个对象，各自保存不同半径。
- 对象方法返回数值，main可继续把返回值乘单价。
- 计算圆环面积需要“外圆减内圆”，不能直接用外圆面积当过道面积。

## 易错点

- 半径允许小数，应使用double，不能用int构造参数截断；本题样例要求保留输入提示语。
