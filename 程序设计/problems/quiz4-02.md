## 题目

3035 切饼(循环)

Description

古有善切饼者，名苞丙，苞丁之兄也。把一张大饼置于板上，不许离开，每一刀切下去都是直线。问切n（0≤n≤20）刀最多能分成少块？例如：

如果n=0，则最多能分成1块；

如果n=1，则最多能分成2块，比第0刀多出1块；

如果n=2，则最多能分成4块，比第1刀多出2块；

如果n=3，则最多能分成7块，比第2刀多出3块；

以此类推……

Input

一个正整数n。

Output

切n刀最多能分成的块数。

例如:

**输入：**

```text
4
```

**输出：**

```text
11
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int n, pieces = 1; scanf("%d", &n);
    for (int cut = 1; cut <= n; ++cut) pieces += cut;
    printf("%d\n", pieces); return 0;
}
```

[下载完整源码](../solutions/quiz4-02.c)

## 讲解

1. 不切时是一整张饼，因此块数从1开始。
2. 第k刀最多增加k块，依次累加1到n。
3. 例如切3刀，块数从1变为2、4、7；第4刀再加4得到11。

## 知识点总结

- pieces=1：明确循环前的初始状态。
- cut<=n：把第n刀的新增块数也计算进去。
- pieces+=cut：在原有块数上增加本刀最多新增数。

## 易错点

- 输入0时循环不执行，答案仍为1。
- 本题要求循环累加，保持题目训练目标。
