# \[4.03\]字符的ASCII值★

[学习首页](../README.md) · [本章目录](../chapters/ch02/README.md) · [知识点索引](../知识点索引.md)

来源：【测验】第2章 程序设计基础.html，第16题。

## 题目

**描述**

从键盘输入一个字符，输出其对应的十进制ASCII值。

**输入**

一个字符。

**输出**

十进制ASCII值。

例如:

**输入：**

```text
A
```

**输出：**

```text
65
```

### 题目与实现说明

- 本题讨论ASCII字符；不把一个UTF-8中文字符的多个字节当作一个ASCII字符处理。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int ch = getchar();
    printf("%d\n", ch);
    return 0;
}
```

[下载完整源码](../solutions/ch02-16.c)

## 讲解

1. 用 getchar 读取一个字符，它返回的整数值就是该字符的编码。
2. 直接以十进制整数形式输出这个值。
3. 例如输入字母A，在本题ASCII环境中编码为65，所以输出65。

## 知识点总结

- getchar：从标准输入读取一个字符，返回类型是int。
- 字符与编码：字母A的字符形式是'A'，对应ASCII数值65。
- %d：把编码当成十进制整数输出，而不是用%c再次输出字母。

## 易错点

- 这里需要允许读到空格，不能用会跳过空白的读取方式。
