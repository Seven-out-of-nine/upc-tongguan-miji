## 题目

10.13 字母简化【★★★】

【题目描述】

给出一串全部为小写英文字母的字符串，要求把这串字母简化。简化规则是：统计连续出现的字母数，输出时先输出个数，再输出字母。比如：aaabbbaa，则简化为3a3b2a；而zzzzeeeeea，则简化为4z5e1a。

【输入】

有多行。第一行为一个整数n，表示共有n组测试数据（1≤n≤100）。接下来有n行，每行第一个数为字符串长度t（t≤1000），然后为一个长度为t的字符串。

【输出】

简化后的字符串，每组测试用例占一行。

例如:

**输入：**

```text
3
7 aaaaaaa
4 abcd
6 qwweee
```

**输出：**

```text
7a
1a1b1c1d
1q2w3e
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int cases; scanf("%d", &cases);
    while (cases--) {
        int t; char s[1001]; scanf("%d%1000s", &t, s);
        int i = 0;
        while (i < t) {
            int j = i + 1;
            while (j < t && s[j] == s[i]) ++j;
            printf("%d%c", j - i, s[i]);
            i = j;
        }
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 用i指向当前一段相同字母的开头。
2. 让j前进，直到遇到不同字母或串尾；这一段的长度就是j-i。
3. 例如aaabbbaa分成aaa、bbb、aa，分别输出3a、3b、2a。

## 知识点总结

- j<t&&...：先保证下标有效，再比较字符。
- j-i：计算左闭右开的一段包含多少字符。
- i=j：下一轮从新段的开头继续。

## 易错点

- 只合并连续重复字符，前后分开的同字母不能合并。
