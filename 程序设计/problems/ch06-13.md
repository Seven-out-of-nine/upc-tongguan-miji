## 题目

【函数+指针】F9.1 两数合并【★】

【题目描述】

编写函数Fun，其功能是：将两个两位数的正整数a、b合并形成一个整数放在c中。合并的方式是：将a的十位和个位依次存放在c数的十位和千位上，b的十位和个位依次存放在c数的个位和百位上。

【输入】

仅一行。两个整数a和b，以逗号分隔。

【输出】

仅一行。一个整数，表示合并后的数据c。

预设代码

前置代码

```text
#include <stdio.h>
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    int a, b, c;
    scanf("%d,%d", &a, &b);
    Fun(a, b, &c);
    printf("%d\n", c);
    return 0;
}
```

例如:

**输入：**

```text
45,12
```

**输出：**

```text
5241
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(int a, int b, int *c) {
    *c = (a % 10) * 1000 + (b % 10) * 100 + (a / 10) * 10 + b / 10;
}
```

<details>
<summary>展开完整本地运行程序</summary>

```c
#include <stdio.h>
#include <string.h>

void Fun(int a, int b, int *c) {
    *c = (a % 10) * 1000 + (b % 10) * 100 + (a / 10) * 10 + b / 10;
}

int main(void) {
    int a, b, c;
    scanf("%d,%d", &a, &b);
    Fun(a, b, &c);
    printf("%d\n", c);
    return 0;
}
```

</details>

## 讲解

1. a%10、a/10 分别取 a 的个位与十位，b 也相同。
2. 按题意，千位来自 a 个位，百位来自 b 个位，十位来自 a 十位，个位来自 b 十位。
3. 例如 45 与 12：5*1000+2*100+4*10+1=5241。

## 知识点总结

- 整数除法 a/10 去掉个位，a%10 取得个位。
- 千、百、十位分别乘 1000、100、10，实现位置权重。
- *c 给调用处的 c 赋值，因为 main 传来的是 &c。

## 易错点

- 输入中是英文逗号，scanf 的格式字符串也要包含逗号。
