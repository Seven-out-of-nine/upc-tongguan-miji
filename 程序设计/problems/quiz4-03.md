## 题目

4902 图像相似度

Description

给出两幅相同大小的黑白图像（用 0-255 矩阵）表示，求它们的相似度。两幅图像的相似度定义为相同像素点数占总像素点数的百分比。

Input

第一行包含两个整数 m 和 n，表示图像的行数和列数，中间用单个空格隔开。1&lt;=m&lt;=100, 1&lt;=n&lt;=100。之后 m 行，每行 n 个整数（0-255），表示第一幅黑白图像上各像素点的颜色。相邻两个数之间用单个空格隔开。之后 m 行，每行 n 个整数（0-255），表示第二幅黑白图像上各像素点的颜色。相邻两个数之间用单个空格隔开。

Output

两幅图像的相似度，结果保留小数点后两位。

例如:

**输入：**

```text
3 3 
1 0 1
0 0 1
1 1 0
1 1 0
0 0 1
0 0 1
```

**输出：**

```text
44.44
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int m, n, a[100][100]; scanf("%d%d", &m, &n);
    for (int i = 0; i < m; ++i) for (int j = 0; j < n; ++j) scanf("%d", &a[i][j]);
    int equal = 0;
    for (int i = 0; i < m; ++i) for (int j = 0; j < n; ++j) {
        int pixel; scanf("%d", &pixel);
        if (pixel == a[i][j]) ++equal;
    }
    printf("%.2f\n", 100.0 * equal / (m * n)); return 0;
}
```

## 讲解

1. 先保存第一幅图的每个像素值。
2. 读取第二幅图时，立即与同一行同一列的第一幅图像素比较，相等就计数。
3. 例如2×2图中3个位置相同，相似度为3÷4×100=75.00。

## 知识点总结

- a[i][j]：表示第i行第j列像素，下标都从0开始。
- 嵌套for：外层遍历行，内层遍历该行所有列。
- 100.0：让比例计算使用浮点运算。
- %.2f：固定保留两位小数。

## 易错点

- 必须比较相同位置的像素，不能只比较0或255各自出现次数。
- 不要先用整数除法equal/(m*n)，否则会丢掉小数。
