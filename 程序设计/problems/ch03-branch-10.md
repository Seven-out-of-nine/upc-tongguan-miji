# \[5.10\] 四位数拆分★

## 题目

描述

输入一个四位数，判断千位、百位、十位和个位数字之和是否为偶数，如果是，输出yes，如果不是，输出no；如果不是四位数，输出Invalid data。

输入

输入一个四位数。

输出

如果是偶数，输出：yes，如果是奇数，输出：no

例如:

**输入：**

```text
1234
```

**输出：**

```text
yes
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    if (n < 1000 || n > 9999) {
        puts("Invalid data");
    } else {
        int sum = n / 1000 + n / 100 % 10 + n / 10 % 10 + n % 10;
        if (sum % 2 == 0) puts("yes");
        else puts("no");
    }
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-10.c)

## 讲解

1. 先检查输入是不是1000到9999之间的四位正整数。
2. 用除法和取余分别取出千、百、十、个位，再相加。
3. 例如1234的数字和为1+2+3+4=10，10%2==0，所以输出yes。

## 知识点总结

- 范围检查：n<1000||n>9999表示不在四位正整数范围内。
- 数位提取：n/100%10先去掉后两位，再保留剩下的个位，即原百位。
- 奇偶判断：sum%2==0表示数字和能被2整除。

## 易错点

- 原数的奇偶性不一定和数字和相同，例如1000是偶数，但数字和1为奇数。
- 负数不作为本题的四位正整数。
