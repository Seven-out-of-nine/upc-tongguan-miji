## 题目

**描述**

假设某人从某天起，开始三天打鱼两天晒网，问这个人在以后的第N天是打鱼还是晒网？

**输入**

输入一个不超过1000的正整数。

**输出**

输出Fishing还是Drying。

例如:

**输入：**

```text
103
```

**输出：**

```text
Fishing in day 103
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    int position = (n - 1) % 5;
    if (position < 3) printf("Fishing in day %d\n", n);
    else printf("Drying in day %d\n", n);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-24.c)

## 讲解

1. 打鱼3天、晒网2天，一共5天构成一个重复周期。
2. 把第1天映射成周期位置0，使用(n-1)%5；位置0、1、2打鱼，3、4晒网。
3. 例如第5天的位置为4，晒网；第6天位置回到0，重新开始打鱼。

## 知识点总结

- 取余%5：只保留当前处于五天周期的哪个位置，不必模拟前面的所有天数。
- n-1：把从1开始的“第几天”转换为从0开始的位置。
- 带变量的输出：固定单词后再用%d输出原来的天数n。

## 易错点

- 如果直接用n%5，余数0对应第5天而不是第1天；要特别处理。
- 输出不是只有Fishing或Drying，样例还要求“ in day N”。
