# \[3.08\]分离整数★

## 题目

**描述**

从键盘上输入一个三位整数，计算个位、十位和百位的值，求和，然后输出

**输入**

一行，输入一个三位整数。

**输出**

一行，输出百位、十位、个位的和。

例如:

**输入：**

```text
145
```

**输出：**

```text
10
```

### 题目与实现说明

- 若输入负数，本解按去掉负号后的三位数字求和；原题未单独说明负数情况。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    if (n < 0) n = -n;
    int hundreds = n / 100;
    int tens = n / 10 % 10;
    int ones = n % 10;
    printf("%d\n", hundreds + tens + ones);
    return 0;
}
```

[下载完整源码](../solutions/ch02-11.c)

## 讲解

1. 先把三位数按百位、十位、个位拆开。
2. n/100 取百位，n/10 去掉个位后再%10取十位，n%10取个位。
3. 例如145得到1、4、5，相加就是10。

## 知识点总结

- **运算优先级与括号**：*、/、%优先于+、-；这些同级算术运算按从左到右组合，所以n/10%10等于(n/10)%10。括号可改变分组，整体分母必须写成/(t+2)，不能写成/t+2。

## 易错点

- n/10 得到的是前两位，不是单独的十位，还要再%10。
