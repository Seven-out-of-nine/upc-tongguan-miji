## 题目

3.03 定义一个矩形类，通过其长、宽两个属性计算矩形面积【★】

定义并实现一个矩形类，有长、宽两个属性，包含的成员函数有：设置和获取长、宽属性的成员函数，计算矩形的面积的成员函数等。

例如:

**输入：**

```text
10 6
```

**输出：**

```text
length is 10, width is 6, area is 60
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Rectangle {
private:
    double length, width;
public:
    Rectangle(double l, double w) : length(l), width(w) {}
    void setLength(double l) { length = l; }
    void setWidth(double w) { width = w; }
    double getLength() const { return length; }
    double getWidth() const { return width; }
    double getArea() const { return length * width; }
};
int main() {
    double length, width;
    cin >> length >> width;
    Rectangle r(length,width);
    cout << "length is " << r.getLength() << ", width is " << r.getWidth()
         << ", area is " << r.getArea() << '\n';
    return 0;
}
```

[下载完整源码](../solutions/ch07-09.cpp)

## 讲解

1. 矩形类同时保存长和宽，并提供设置和获取方法。
2. getArea直接把对象当前的长与宽相乘。
3. 例如2.5与4相乘得到10；成员必须用浮点数，不能在构造时先截成2。
