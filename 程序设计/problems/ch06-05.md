## 题目

【函数+字符数组】F10.6 删除星号【★★★】

【题目描述】

假定输入的字符串s中只包含字母和\*号。编写函数Fun ，其功能是：除了尾部的\*号之外，将字符串中其它\*号全部删除。

【输入】

仅一行。字符串s（长度不超过1000）。

【输出】

仅一行。删除指定\*后的字符串。

**前置代码：**

```text
#include <stdio.h>
#include <string.h>
#define N 1000
#include <bits/stdc++.h>
using namespace std;
```

**后置代码：**

```text
int main()
{
    char s[N + 5];
    scanf("%s",s);
    Fun(s);
    puts(s);
    return 0;
}
```

例如:

**输入：**

```text
****A*BC*DEFG*H*******
```

**输出：**

```text
ABCDEFGH*******
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char s[]) {
    int n = (int)strlen(s), last = n - 1;
    while (last >= 0 && s[last] == '*') last--;
    int k = 0;
    for (int i = 0; i < n; i++) {
        if (s[i] != '*' || i > last) s[k++] = s[i];
    }
    s[k] = '\0';
}
```

## 讲解

1. 从右向左跳过连续星号，last 最后停在最后一个字母的位置。
2. 再从左向右扫描：字母都保留；星号只有位于 last 之后才保留。
3. 例如 **A*B*** 的 last 指向 B，结果保留 A、B 和尾部三个星号，即 AB***。
4. 用 k 在原数组中从头写入结果，最后补结束符。

## 知识点总结

- strlen 的结果转成 int 后再减 1，可让空串时 last 为 -1。
- && 的左侧条件不成立时右侧不再求值，因此 last>=0 应放在前面防止越界。
- 在原数组筛选时，写下标 k 永远不超过读下标 i，所以不会覆盖未读字符。

## 易错点

- 全是星号时 last 会变成 -1；所有星号都属于尾部，应全部保留。
