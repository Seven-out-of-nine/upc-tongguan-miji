## 题目

2.04 编写C++程序实现排序输出【★】

编写一个C++风格的程序，输入两个整数，将它们按有小到大的顺序输出。**要求使用变量的引用。**

例如:

**输入：**

```text
4 8
```

**输出：**

```text
4 8
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

void order(int &a, int &b) {
    if (a > b) {
        int temp = a;
        a = b;
        b = temp;
    }
}
int main() {
    int a, b;
    cin >> a >> b;
    order(a, b);
    cout << a << ' ' << b << '\n';
    return 0;
}
```

[下载完整源码](../solutions/ch07-06.cpp)

## 讲解

1. 函数参数写成int&a、int&b，让它们成为main中两个变量的别名。
2. 只有a>b时才交换，先用temp保存a，防止赋值后丢失原值。
3. 例如输入9 2，交换后main中的a确实变为2、b变为9，输出2 9。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 源保存答案使用值参数，未真正修改main中的变量；升序输入无法暴露此问题，必须测试逆序。
