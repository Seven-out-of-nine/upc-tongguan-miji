## 题目

**描述**

ACM国际大学生程序设计竞赛，ACM比赛有个“罚时”(Penalty)的概念，首先做的题多的队伍排名更高，做出题目数量相同的队伍，由罚时来判断。比如C(题号)题在第30分钟做完，做错了2次，第三次得到了“Accepted”，那么这时的罚时是 30+20\*2=70，20是ACM比赛约定俗成的系数，错一次罚20分钟，不过如果这题到比赛结束都没“Accepted”，那么这道题是不罚时的。相同题数的队伍，罚时少的排名更靠前。

**输入**

仅一行。比赛开始时间，题目提交Accepted时间，以及提交错误次数（≥0）。

**输出**

题目成功通过时的罚时。

### 题目与实现说明

- 原题未明写时间的具体分隔符，也没有公开样例；依据保存页展示的输入格式，按h:m h:m 错误次数读取，并按同一天且通过时间不早于开始时间处理。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int start_hour, start_minute, end_hour, end_minute, errors;
    scanf("%d:%d %d:%d %d", &start_hour, &start_minute,
          &end_hour, &end_minute, &errors);
    int start = start_hour * 60 + start_minute;
    int end = end_hour * 60 + end_minute;
    int penalty = end - start + 20 * errors;
    printf("%d\n", penalty);
    return 0;
}
```

[下载完整源码](../solutions/ch02-23.c)

## 讲解

1. 把开始和通过时刻都转换成从当天0点起经过的分钟数。
2. 通过时刻的总分钟减去开始时刻的总分钟，就是耗时，再加20*错误次数。
3. 例如9:00到9:30耗时30分钟，错误2次再加40分钟，总罚时70。

## 知识点总结

- **scanf匹配固定分隔符**：scanf格式中除转换说明和空白外的普通字符，需要与输入逐字匹配。例如"%d:%d"用冒号拆分时分，"%d,%d"按英文逗号读取两数，格式标点要与输入协议一致。

## 易错点

- 不能直接用930-900表示分钟差，跨小时如9:50到10:10就会算错。
