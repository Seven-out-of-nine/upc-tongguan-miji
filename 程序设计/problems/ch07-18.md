## 题目

4.01 派生类的定义及应用【★】

定义一个Document类，有数据成员name，从Document派生出Book类，增加数据成员pageCount。

例如:

**输出：**

```text
Name of book: Book1
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Document {
protected:
    string name; 
public:
    
    Document(string n) : name(n) {}
};


class Book : public Document {
private:
    int pageCount; 
public:
    
    Book(string n, int p) : Document(n), pageCount(p) {}

    
    void printNameOf() {
        cout << "Name of book: " << name << endl;
    }
};

int main()
{
    Document a("Document1");
    Book b("Book1",100);
    b.printNameOf();
    return 0;
}
```

[下载完整源码](../solutions/ch07-18.cpp)

## 讲解

1. Document保存所有文档共有的名称。
2. Book通过public继承获得文档基础部分，再增加自己的页数pageCount。
3. 构造Book("Book1",100)时，先调用Document("Book1")初始化名称，再初始化100页。
4. printNameOf读取继承来的name，输出Name of book: Book1。

## 知识点总结

- class Book:public Document声明公有继承，Book是一种Document。
- protected成员可由本类和派生类访问，但main不能直接读写。
- 派生类初始化列表Document(n)显式调用基类构造函数。

## 易错点

- 基类没有无参构造函数时，派生类构造必须明确提供基类所需名称。
