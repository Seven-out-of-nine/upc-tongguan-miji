## 题目

【题目描述】

ACM俱乐部成功举办了月赛，yyfish找来了cherry、CatCage、Ants等众位大牛帮忙负责月赛的纪念品发放工作。为使得参加月赛的同学所获得的纪念品价值相对均衡，他们要把购来的纪念品根据价格进行分组，但每组最多只能包括两件纪念品，并且每组纪念品的价格之和不能超过一个给定的整数。为了保证在尽量短的时间内发完所有纪念品，yyfish希望分组的数目最少。

你的任务是写一个程序，找出所有分组方案中分组数最少的一种，输出最少的分组数目。

【输入】

有n+2行。第1行包含一个整数w（80 ≤ w ≤ 200），为每组纪念品价格之和的上限。第2行是一个整数n（1≤ n ≤ 30000），表示购来的纪念品的总件数。第3~n+2行每行包含一个正整数pi（5 ≤ pi ≤ w），表示所对应纪念品的价格。

【输出】

仅一行。包含一个整数，即最少的分组数目。

例如:

**输入：**

```text
100
9
90
20
20
30
50
60
70
80
90
```

**输出：**

```text
6
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int limit, n, count[201] = {0}, price[30000];
    scanf("%d%d", &limit, &n);
    for (int i = 0; i < n; ++i) { int x; scanf("%d", &x); ++count[x]; }
    int length = 0;
    for (int x = 0; x <= limit; ++x)
        for (int k = 0; k < count[x]; ++k) price[length++] = x;
    int left = 0, right = n - 1, groups = 0;
    while (left <= right) {
        if (left < right && price[left] + price[right] <= limit) ++left;
        --right; ++groups;
    }
    printf("%d\n", groups);
    return 0;
}
```

## 讲解

1. 先按价格从小到大排列；价格只在5到200，用计数数组统计各价位后依次展开即可。
2. 每轮给最贵的剩余纪念品安排一组：若最便宜的也能与它配对，就把两者一起分走。
3. 若连最便宜的都不能与最贵者配对，其他物品更贵，也不能配，只能让最贵者单独一组。
4. 例如上限100，价格20、30、70、90，90单独一组，70与20配一组，30单独一组，共3组。
5. 最贵者配得上最便宜者时，可将任意方案中的配对交换为这一对而不增加组数，所以逐轮这样做能达到最少组数。

## 知识点总结

- **小值域整数的计数排序**：先用count[x]统计每个价格的出现次数，再按x从小到大输出或展开count[x]个该值，便得到有序序列。工作量与元素数加值域大小有关；本题价格不超过200，即使有30000件也不必作约n²次比较。
- **两端指针与最贵优先配对**：排序后用left、right指向剩余最便宜、最贵的物品，每轮必定安排最贵者。若最便宜者也无法与它同组，它只能独占；能同组时把这对一起移走，可通过交换配对保持最优。两个指针分别向中间推进，每件只处理一次。

## 易错点

- 每组最多两件，不是普通不限件数的装箱问题。
- 最多30000件，不宜用需要约九亿次比较的冒泡排序；小值域计数排序更合适。
