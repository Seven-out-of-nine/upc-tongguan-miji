## 题目

**【题目描述】**

你知道吗？在外国，如果你不修剪你的花圃，是要被贴罚单的。Xman忙于战斗，被贴了好多罚单。这一次好不容易休息了，他决定修剪一下。修剪成什么样子呢？当然是X形。

Xman的花圃是一个n\*n的正方形，其中n为大于等于3的正奇数。在每个位置上都有几个植物，对应的正整数是该植物的高度h。Xman的修剪策略是，首先把不在两条对角线上的植物通通铲光，然后在对角线上找到最矮的一株植物，把剩余的其他植物都裁剪成与它等高，这样一个漂亮整齐的X型就出来了。

Xman的东西当然值钱了。每1单位高度的植物，就可以卖2美元，把减掉的植物都卖掉，就可以弥补罚单的损失了。你帮Xman计算一下一共可以卖多少钱。

**【输入】**

有多行。第1行是一个整数n（n&lt;1000），表示花圃的边长。接下来n行是一个n\*n的正整数二维数组，每个正整数值表示对应植物的高度h（h&lt;1000）。

**【输出】**

仅一行。一个整数，表示卖出的美元总数。

例如:

**输入：**

```text
3
1 1 3 
3 2 2
1 2 2
```

**输出：**

```text
24
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, height, minimum = 1000;
    long long total = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            scanf("%d", &height);
            total += height;
            if ((i == j || i + j == n - 1) && height < minimum) minimum = height;
        }
    }
    long long retained = (2LL * n - 1) * minimum;
    printf("%lld\n", (total - retained) * 2);
    return 0;
}
```

## 讲解

1. 不在两条对角线的植物全去掉；在对角线的植物最终统一保留最矮高度minimum。
2. 边读入边统计全部高度total，并只在对角线上更新minimum。
3. n为奇数时，两条对角线共有2*n-1个不同位置，因此最终保留高度总量为(2*n-1)*minimum。
4. 剪掉的总高度为total减保留总量，再乘每单位2美元；样例总高17、保留5，收入24。

## 知识点总结

- **用下标描述两条对角线**：n阶方阵的主对角线满足i==j，副对角线满足i+j==n-1；用||判断任意一条。当n为奇数时两线中心重合，合计2*n-1个不同位置，不能把中心算两次。

## 易错点

- 两条对角线交于中心，中心只计一次，所以位置数是2*n-1。
- 最小值只能在对角线上取，不能把整片花圃最矮植物作为保留高度。
