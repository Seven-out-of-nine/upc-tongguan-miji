## 题目

2009 白雪公主和小矮人

题目描述

白雪公主和七个小矮子的童话故事伴随了一代又一代人的童年成长。每每想起这段童话故事，全都是些美好的回忆！话说白雪公主和七个小矮人生活在一起的时候，每个周末他们都会举办一个热闹的Party，但是每个小矮人都希望自己是那个邀请白雪公主跳第一支舞的人，这可让白雪公主有些为难了，她不想让任何一个小矮人伤心，于是聪明的她想到了一个好主意，她给7个小矮人们从1~7编好序号，然后她会随机的抽取一个幸运数据，根据这个数据的个位数字来判定谁是舞会的幸运小矮人，如果没有选中任何一位小矮人，他们将一起和白雪公主愉快的跳圆圈舞，这应该是白雪公主最期望的结果，哈哈！

输入

输入有多组数据。每组包含一个正整数n（0&lt;=n&lt;=10000），表示白雪公主抽取的幸运数据。

输出

每行输出一个字符串。如果选中的是小矮人，输出的字符串表示对应小矮人的姓名（1~7对应小矮人姓名分别是Doc，Bashful，Sleepy，Sneezy，Happy，Dopey，Grumpy，否则输出Circle dance。

例如:

**输入：**

```text
125
1000
```

**输出：**

```text
Happy
Circle dance
```

## 解答

```c
#include <stdio.h>

int main(void) {
    const char *names[] = {"Circle dance","Doc","Bashful","Sleepy","Sneezy","Happy","Dopey","Grumpy"};
    int n;
    while (scanf("%d", &n) == 1) {
        int d = n % 10;
        puts(d >= 1 && d <= 7 ? names[d] : names[0]);
    }
    return 0;
}
```

[下载完整源码](../solutions/quiz2-02.c)

## 讲解

1. 整数模10得到个位数字。
2. 个位在1到7之间时，用对应名字表输出；0、8、9输出Circle dance。
3. 例如125的个位是5，对应Happy；1000的个位0没有选中小矮人。

## 知识点总结

- n%10：提取十进制个位。
- const char *names[]：按编号保存固定名字。
- while(scanf(...)==1)：读到输入结束，逐组处理。

## 易错点

- 要依据个位而不是整个整数。
- 0是合法数据，不能把它误当结束标志。
