## 题目

**描述**

严格按照样例格式输出倒三角。

**输入**

没有输入

**输出**

输出样例的倒三角

例如:

**输入：**

```text
没有输入
```

**输出：**

```text
* * * *
 * * *
  * *
   *
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    printf("* * * *\n");
    printf(" * * *\n");
    printf("  * *\n");
    printf("   *\n");
    return 0;
}
```

[下载完整源码](../solutions/ch02-02.c)

## 讲解

1. 把图形看成四行字符串，不需要先学习循环。
2. 第一行前面没有空格，之后三行分别以1、2、3个空格开头。
3. 例如第三行字符串是“两个空格、星号、空格、星号”，所以能让图形逐渐向右缩进。

## 知识点总结

- printf：每次输出一行固定字符串，按语句顺序从上向下执行。
- 空格也是字符：双引号里的前导空格会原样显示，是图形的一部分。
- \n：结束当前行，让下一条 printf 的内容从新的一行开始。

## 易错点

- 不要用 Tab 制表符代替空格，不同环境的显示宽度可能不同。
- 每行最后一个星号后不需要再补空格。
