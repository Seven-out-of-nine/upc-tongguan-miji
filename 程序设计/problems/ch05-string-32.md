# 10.32 找第一个只出现一次的字符【★★】

## 题目

【题目描述】

给定t个字符串，这个字符串只可能由26个小写字母组成，请你找到第一个仅出现一次的字符，如果没有符合要求的字符，就输出NO。

【输入】

有多行。第1行是t(t&lt;100)，接下来是t个字符串，每个字符串长度小于100。

【输出】

由t行组成。对于每个字符串，输出第一个仅出现一次的字符，如果没有符合要求的字符，就输出NO。

例如:

**输入：**

```text
2
aabb
abcdab
```

**输出：**

```text
NO
c
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int t; scanf("%d", &t);
    while (t--) {
        char s[100]; int count[26] = {0}; scanf("%99s", s);
        for (int i = 0; s[i]; ++i) ++count[s[i] - 'a'];
        int found = 0;
        for (int i = 0; s[i]; ++i) if (count[s[i] - 'a'] == 1) {
            printf("%c\n", s[i]); found = 1; break;
        }
        if (!found) puts("NO");
    }
    return 0;
}
```

## 讲解

1. 第一遍扫描统计26个小写字母的频次。
2. 第二遍仍按原串顺序，第一次遇到频次1的字母就输出。
3. 例如abcdab中a、b都出现2次，c是第一个只出现1次的字母。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 不能按a到z顺序找，否则得到的是字典序最小的单次字母。
