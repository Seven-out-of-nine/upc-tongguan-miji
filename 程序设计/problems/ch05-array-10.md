# 8.10 买股票【★★】

## 题目

**【题目描述】**

2015年股市以爆发性行情揭开了新一轮牛市的序幕，小明同学趁着手里有点小钱，想要购买CFun公司的股票，但CFun公司的股票价格是不稳定的，并且购买股票后只能在第三天抛出（条款有点任性呀！）。 现在小明通过QQ群意外获得了Cfun公司未来n天的股票价格，并期望在前n-2天内完成购买（最后2天禁止买入，只能抛出）。现在小明的目标是最大化收益，请计算他第几天（从1开始）购买股票最合适。

**【输入】**

有两行。第1行是一个整数n（2&lt;n&lt;30），表示小明通过QQ群意外获得了Cfun公司未来n天的股票价格。第2行是n个整数，分别表示n天的股票价格。

**【输出】**

仅一行。一个整数，表示小明第几天（从1开始）购买股票最合适。

例如:

**输入：**

```text
15
80 73 90 75 85 82 96 73 81 101 94 106 101 79 94
```

**输出：**

```text
8
```

### 题目与实现说明

- 题干没有规定最大收益并列时取哪天，本解沿用保存答案的规则，取最晚日期。原题只问日期，仍需从合法购买日中选一个。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, price[30], day = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) scanf("%d", &price[i]);
    long long best = (long long)price[2] - price[0];
    for (int i = 1; i < n - 2; ++i) {
        long long gain = (long long)price[i + 2] - price[i];
        if (gain >= best) { best = gain; day = i; }
    }
    printf("%d\n", day + 1);
    return 0;
}
```

## 讲解

1. 购买后的第三天卖出，若购买日下标为i，卖出日下标就是i+2。
2. 依次计算每个合法购买日的收益price[i+2]-price[i]，记录最大收益对应的下标。
3. 先以第一天的收益作初值，即使所有方案都亏损，也能选出损失最少的一天。
4. 样例第8天价格73，第10天101，收益28最大，因此输出8。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 题意是固定相隔两天卖出，不能任意寻找后面的最高卖价。
- 不能把最高收益初始设为0，否则全部亏损时会没有正确日期。
