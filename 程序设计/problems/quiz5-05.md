## 题目

20106 胡恼的差旅统计

胡恼由于工作关系，经常出差，往返于青岛、北京、上海、杭州等地，他最喜欢的交通工具是高铁，因为中国的高铁效率堪比其他国家的飞机，车次多，速度快。更何况他有严重的“波音恐惧症”，如果非要坐飞机，那么他只选C919这个型号，因为机次还不多，所以每次买票跟双11秒拍一样困难。高铁的车次格式为GXXX，XXX代表3位数字，胡恼记录下来一年来每次往返乘坐的高铁车次，今天他心血来潮，想统计一下自己到底跟哪个车次有缘（乘坐次数最多）。

【输入】

若干行，每行两个车次编号，方便起见只记录了数字部分，分别代表往返分别乘坐的车次，最后一行以0代表结束；

测试用例中车次编号在001-999之间（包含001与999）。

【输出】

乘坐次数最多的车次，如果有次数相同的车次，按照数字编号从小到大的顺序输出，以空格分隔。

例如:

**输入：**

```text
187 159
169 159
187 196
0
```

**输出：**

```text
G159 G187
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int count[1000] = {0}, train, maximum = 0;
    while (scanf("%d", &train) == 1 && train != 0) {
        ++count[train]; if (count[train] > maximum) maximum = count[train];
    }
    int first = 1;
    if (maximum) for (int i = 1; i <= 999; ++i) if (count[i] == maximum) {
        if (!first) putchar(' '); printf("G%03d", i); first = 0;
    }
    putchar('\n'); return 0;
}
```

## 讲解

1. 往返车次都同样计数，因此按整数逐个读到0即可。
2. 用车次数值作下标统计次数，同时记录最大次数。
3. 最后按1到999递增扫描，输出所有并列最多车次。
4. 例如1和10都达到最大次数，就依次输出G001 G010。

## 知识点总结

- count[1000]：覆盖编号1到999，0仅作停止标志。
- %03d：把车次补足3位，缺位在前面补0。
- first：只在后续答案前加分隔空格，避免多余尾空格。

## 易错点

- 要同时统计去程和回程，不是按每行只算一次。
- 输出要补齐三位数字，不能写G1。
