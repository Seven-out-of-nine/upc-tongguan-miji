## 题目

3.10 静态成员的用法【★★】

编写一个程序，已有若干学生的数据，包括学号、姓名、成绩，要求输入这些学生的数据并计算出学生人数和平均成绩（**要求将学生人数和总成绩用静态数据成员表示**）。

### 题目与实现说明

- 原网页仅给固定三名学生的演示结果，没有规定键盘输入格式；完整程序沿用固定演示，不虚构输入协议。

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Student {
private:
    int id, score;
    string name;
    static int count;
    static int total;
public:
    Student(int i, string n, int s) : id(i), score(s), name(n) { count++; total += score; }
    void print() const { cout << id << "   " << name << "   " << score << '\n'; }
    static int getCount() { return count; }
    static double getAverage() { return count ? static_cast<double>(total) / count : 0; }
};
int Student::count = 0;
int Student::total = 0;
int main() {
    Student s1(201601,"john",85), s2(201602,"mike",90), s3(201603,"june",95);
    s1.print(); s2.print(); s3.print();
    cout << "共有" << Student::getCount() << "位学生，平均成绩为：" << Student::getAverage() << '\n';
    return 0;
}
```

[下载完整源码](../solutions/ch07-14.cpp)

## 讲解

1. 每创建一名学生，构造函数让共享人数count增加1、共享总分total加上该生分数。
2. 三个对象各自保存自己的学号姓名成绩，但共用同一份count和total。
3. 85+90+95=270，共3人，所以平均成绩为270/3=90。
4. 用类名Student::调用静态查询方法，不需要指定某个学生对象。

## 知识点总结

- **类的静态数据与静态成员函数**：static数据成员由整个类的所有对象共享一份；每次构造学生都更新同一count和total。常规C++11写法需在类外用int Student::count=0提供定义；Student::getCount()直接经类名调用静态方法，静态方法没有this，不能直接访问某个对象的非静态成员。

## 易错点

- 不能把count和total声明成普通成员，否则每名学生都只统计自己。
