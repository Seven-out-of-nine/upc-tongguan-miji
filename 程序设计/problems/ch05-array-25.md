## 题目

【题目描述】

又是一年开学季，大一新生连续三天报到结束后立即开始了他们期待已久的军训生活。军训中，教官按照同学们的身高从低到高给大家排好了队形，但是一周后又来了一名新同学（由于特殊原因，报到晚了），按照现在的队形，他应该站在什么位置呢？请你编程帮帮他！

【输入】

有三行。第1行是一个整数n（1≤n≤1000），表示有n位同学从低到高排好了队。第2行有n个整数，分别表示有序队形中的n位同学的身高。第3行是一个整数，表示新来的同学的身高。

【输出】

仅一行，n个整数，表示新同学加入后的新队形。

例如:

**输入：**

```text
10
153 155 159 161 163 165 167 169 170 172
168
```

**输出：**

```text
153 155 159 161 163 165 167 168 169 170 172
```

### 题目与实现说明

- 输出说明误写n个整数，插入后实际应有n+1个整数，原样例也是如此。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, height[1001], newcomer;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) scanf("%d", &height[i]);
    scanf("%d", &newcomer);
    int position = n;
    while (position > 0 && height[position - 1] > newcomer) {
        height[position] = height[position - 1];
        --position;
    }
    height[position] = newcomer;
    for (int i = 0; i <= n; ++i) {
        if (i) putchar(' ');
        printf("%d", height[i]);
    }
    putchar('\n');
    return 0;
}
```

## 讲解

1. 原队伍已经升序排列，只需给新同学留出合适位置。
2. 从末尾往前看，遇到比新同学高的人，就把他向后移动一格。
3. 第一次遇到不高于新同学的人，或已经到队首，就把新同学放到空位。
4. 例如153 155 159插入154，159和155各后移一位，得到153 154 155 159。

## 知识点总结

- **有序数组插入与后移**：在升序数组中加入一个数，从末尾开始把比它大的元素依次后移一格，最后把新数写进空位。逆序搬移能避免覆盖尚未移动的元素；加入后有效长度增1，因此容量也要多留一格。

## 易错点

- 加入后有n+1个数，输出循环必须包含下标n。
- 不能从前往后直接右移，否则会把后面的身高覆盖掉。
