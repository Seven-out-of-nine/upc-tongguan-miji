# \[3.10\]求三角形面积★★

[学习首页](../README.md) · [本章目录](../chapters/ch02/README.md) · [知识点索引](../知识点索引.md)

## 题目

**描述**

输入三角形三边长，求三角形面积。（假设输入的三边可以组成三角形）S=√\[p(p-a)(p-b)(p-c)\] 而公式里的p为半周长：p=(a+b+c)/2。a、b、c为三角形三边长，都为实数。这就是著名的**海伦－秦九韶公式。**

**输入**

一行，输入三角形三边长。

**输出**

输出三角形面积。结果保留两位小数。

提示：sqrt函数的使用需要某个头文件

例如:

**输入：**

```text
3 4 5
```

**输出：**

```text
6.00
```

## 解答

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
    double a, b, c;
    scanf("%lf %lf %lf", &a, &b, &c);
    double p = (a + b + c) / 2.0;
    double area = sqrt(p * (p - a) * (p - b) * (p - c));
    printf("%.2f\n", area);
    return 0;
}
```

[下载完整源码](../solutions/ch02-13.c)

## 讲解

1. 用 double 读入三条边，先求半周长 p=(a+b+c)/2。
2. 把 p、p-a、p-b、p-c 四个数相乘，再用 sqrt 开平方。
3. 例如3、4、5的半周长是6，面积为 sqrt(6*3*2*1)=6，输出6.00。

## 知识点总结

- <math.h>：声明 sqrt 函数，sqrt(x) 返回x的平方根。
- 括号：先算每个 p-a 这样的差，再参与乘法，保持海伦公式的顺序。
- double 与2.0：全程使用实数，避免把半周长的小数部分丢掉。

## 易错点

- C语言中不能用 √ 直接写运算，必须调用 sqrt。
- 题目已保证能组成三角形，不需要输出其他错误提示。
