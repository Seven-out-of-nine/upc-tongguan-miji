## 题目

【题目描述】

根据某城市普通出租车收费标准编写程序对车费进行计算。具体标准如下：起步里程为3km，起步费10元；10km以内超过起步里程部分，每千米2元，超过10km以上的部分，每千米3元。

【输入】

行驶里程数（单位千米，整数）。

【输出 】

乘客应支付的车费（单位元），结果四舍五入到元。

例如:

**输入：**

```text
1
```

**输出：**

```text
10
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long km, cost;
    scanf("%lld", &km);
    if (km <= 3) cost = 10;
    else if (km <= 10) cost = 10 + (km - 3) * 2;
    else cost = 10 + 7 * 2 + (km - 10) * 3;
    printf("%lld\n", cost);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-31.c)

## 讲解

1. 前3公里无论用了多少公里，都收起步价10元。
2. 从3到10公里的部分每公里2元；超过10公里时，前10公里已花10+7*2=24元，再加超出部分每公里3元。
3. 例如11公里收费24+1*3=27元，不是把11公里全部按3元计算。

## 知识点总结

- 分段累进计算：后一段必须包含前面已经产生的固定费用。
- else if：3和10两个端点分别属于前一个收费段。
- long long：输入是整数公里，所有单价也是整数，所以金额可用整数精确计算。

## 易错点

- 超过10公里后只有超出部分按3元，不能把全部里程都乘3。
- 因为本题里程和单价都是整数，最终金额本来就是整数，无需额外做四舍五入。
