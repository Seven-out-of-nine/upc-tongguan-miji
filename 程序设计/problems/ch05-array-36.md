# 8.36 百灯熄灭【★★】

[学习首页](../README.md) · [本章目录](../chapters/ch05-array/README.md) · [知识点索引](../知识点索引.md)

来源：【测验】第5章 part1数组.html，第36题。

## 题目

【题目描述】

有n盏灯，编号为1~n，分别由相应的n个开关控制。开始时全部开关朝上（朝上为开，灯亮），然后进行以下操作：编号凡是1的倍数的灯反方向拨一次开关；是2的倍数的灯再反方向拨一次开关；是3的倍数的灯又反方向拨一次开关，......，直到是n的倍数的灯又反方向拨一次开关。

【输入】

仅一行。一个整数n（1≤n≤100），代表灯的数量。

【输出】

有两行。第1行是熄灭状态的灯的数量；第2行是最后为熄灭状态的灯的编号（每个数据以4列的域宽显示）。

例如:

**输入：**

```text
100
```

**输出：**

```text
10
   1   4   9  16  25  36  49  64  81 100
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, off[101] = {0}, count = 0;
    scanf("%d", &n);
    for (int step = 1; step <= n; ++step)
        for (int lamp = step; lamp <= n; lamp += step) off[lamp] = !off[lamp];
    for (int lamp = 1; lamp <= n; ++lamp)
        if (off[lamp]) ++count;
    printf("%d\n", count);
    for (int lamp = 1; lamp <= n; ++lamp)
        if (off[lamp]) printf("%4d", lamp);
    putchar('\n');
    return 0;
}
```

## 讲解

1. off[lamp]=0表示灯初始亮着，1表示灯熄灭。
2. 第step轮从step开始，每次加step，逐个翻转step的倍数位置的状态。
3. 操作全部完成后，先统计状态为1的灯数，再按编号从小到大输出。
4. 例如n=4，1号翻转1次、2号2次、3号2次、4号3次，最后1号和4号熄灭。

## 知识点总结

- 逻辑非!：0变1、非0变0，off[lamp]=!off[lamp]实现开关翻转。
- 内层lamp+=step：直接访问倍数，避免对每盏灯额外判断整除。
- 编号从1开始：数组开101格，0号不用，1到100号均能访问。
- %4d：每个熄灭灯的编号占至少4列。

## 易错点

- 题目初始全部亮着，不能按初始全部熄灭的另一种灯题来理解。
- 输出的是最终熄灭的灯，恰好为完全平方数位置，可用于检查模拟结果。
