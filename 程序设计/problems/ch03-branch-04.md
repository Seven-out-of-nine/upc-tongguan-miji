## 题目

**描述**

通信系统是有一定的寿命的，因此，计算通信系统的建设时间是十分关键的，要求程序能够实现通过输入系统建立时的年月日，和当前的年月日，计算出建立的时间长短，只用具体到年就行（不足一年不累计在内）。

**输入**

1990 1 1 2016 10 15

**输出**

26

例如:

**输入：**

```text
1990 1 1 2016 10 15
```

**输出：**

```text
26
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int start_year, start_month, start_day;
    int year, month, day;
    scanf("%d %d %d %d %d %d", &start_year, &start_month, &start_day,
          &year, &month, &day);
    int years = year - start_year;
    if (month < start_month || (month == start_month && day < start_day)) {
        years--;
    }
    printf("%d\n", years);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-04.c)

## 讲解

1. 先用当前年份减建立年份，得到一个暂时的年数。
2. 如果今年还没有到建立时的月日，说明最后这一年没有满，要减1。
3. 例如2020年6月10日建立，到2023年6月9日，年份差为3，但还差一天满3年，结果应为2。

## 知识点总结

- ||：逻辑“或”，当前月份较小或者同月但日期较小，都表示周年尚未到。
- &&：逻辑“且”，只有月份相同并且日期较小，才满足后一种情况。
- years--：把完整年数减少1，等价于years=years-1。

## 易错点

- 只减年份会把未满的一年也算进去。
- 假定两个日期有效且当前日期不早于建立日期。
