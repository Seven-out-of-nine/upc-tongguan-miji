## 题目

**描述**

C语言考试要对成绩进行评判，60分以下为D；大于等于60分且小于80分为C；大于等于80分且小于90分为B，大于等于90分为A。试编写一个程序判断成绩区间，若输入大于100或小于0的数，则输出"error"。

**输入**

输入分数。

**输出**

输出成绩区间。

例如:

**输入：**

```text
60
```

**输出：**

```text
C
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double score;
    scanf("%lf", &score);
    if (score < 0 || score > 100) puts("error");
    else if (score < 60) puts("D");
    else if (score < 80) puts("C");
    else if (score < 90) puts("B");
    else puts("A");
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-20.c)

## 讲解

1. 先排除不在0到100之间的分数。
2. 合法分数按从低到高检查60、80、90三个分界点，落在哪一段就输出对应等级。
3. 例如60不是“60分以下”，会进入C；90不小于90，所以进入A。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 成绩0和100都合法，错误判断不能写成<=0或>=100。
- 等级使用大写字母，error使用小写。
