## 题目

**描述**

从键盘上输入一个两位整数，计算个位和十位的值，求和，然后输出

**输入**

一行，输入一个两位的整数。

**输出**

一行，分离个位十位的值，求和输出。

提示：通过什么数学运算能得到个位和十位的数字？

例如:

**样例 1**

**输入：**

```text
45
```

**输出：**

```text
9
```

**样例 2**

**输入：**

```text
35
```

**输出：**

```text
8
```

### 题目与实现说明

- 题面没有明确负数数字和的含义；本解把负号当作符号而非数字，例如-45按4+5处理；样例均为非负数。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    if (n < 0) n = -n;
    int tens = n / 10;
    int ones = n % 10;
    printf("%d\n", tens + ones);
    return 0;
}
```

[下载完整源码](../solutions/ch02-10.c)

## 讲解

1. 两位数可以写成“十位×10+个位”；先把它分成这两部分。
2. n/10 得到十位，n%10 得到个位，再把两者相加。
3. 例如45/10=4，45%10=5，因此结果为4+5=9。

## 知识点总结

- 整数除法 /：45/10 只取整数部分4，对应十位。
- 取余 %：45%10 取除以10后剩下的5，对应个位。
- if：若输入为负数先取相反数，后续按不含符号的十进制数字处理。

## 易错点

- 不要写成 n/10+n/100，个位应由取余得到。
