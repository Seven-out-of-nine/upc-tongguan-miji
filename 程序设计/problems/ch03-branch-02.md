## 题目

**描述**

在复杂的环境下，无线信号特征变化受环境因素是比较明显的，假设，在一个特定的环境下，当距离信源小于6公里时，信号强度的变化函数是：y=6x-4，当距离信源大于等于6小于15时，信号强度的变化函数是：y=9x-5，当距离信源大于等于15时，信号强度的变化函数是：y=15x-5。从键盘上输入一个整数x，输出对应的y值。

**输入**

1

**输出**

2

例如:

**输入：**

```text
1
```

**输出：**

```text
2
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long x, y;
    scanf("%lld", &x);
    if (x < 6) {
        y = 6 * x - 4;
    } else if (x < 15) {
        y = 9 * x - 5;
    } else {
        y = 15 * x - 5;
    }
    printf("%lld\n", y);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-02.c)

## 讲解

1. 把输入距离分成小于6、从6到不足15、至少15三个区间。
2. 按从小到大的顺序判断；进入第二个判断时，已经知道x不小于6，所以只需再检查x<15。
3. 例如x=6不能用第一段，应计算9*6-5=49；x=15用第三段，得到220。

## 知识点总结

- **else-if多分支链**：if/else if/else从上到下只执行第一个成立的分支，else处理前面全部不成立的情况。进入后一条件时已知之前条件为假，因此依次检查x<6、x<15即可划分三个互斥区间，不必重写下界。

## 易错点

- 区间端点6、15必须归到后一段，不能把<误写成<=。
