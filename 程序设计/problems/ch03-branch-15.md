## 题目

**描述**

某同学想知道到本月今天已经跑操的次数。已知星期一到星期五需要跑操，周末休息；假设该月一日是星期一。请你设计一个程序帮助她，输入今天的日期，计算该月截止到今天跑操结束后的总跑操次数。

**输入**

日期数n

**输出**

本月跑操总次数

例如:

**输入：**

```text
1
```

**输出：**

```text
1
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    int count = n / 7 * 5;
    int remaining = n % 7;
    if (remaining > 5) remaining = 5;
    count += remaining;
    printf("%d\n", count);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-15.c)

## 讲解

1. 月初是星期一，每完整7天恰好跑操5次，因此完整周贡献n/7*5。
2. 剩下n%7天仍从星期一算起，前5天跑操，多出的周末不增加次数。
3. 例如第13天，已经过1个完整周加6天，次数是5+5=10。

## 知识点总结

- 整数除法与取余：n/7分出完整周，n%7取不足一周的天数。
- 上限限制：remaining超过5时改成5，表达“每周最多跑5次”。
- +=：count+=remaining等价于count=count+remaining。

## 易错点

- 要把今天算进去，输入1时答案是1，不是0。
- 第6、7天都是周末，跑操次数仍是5。
