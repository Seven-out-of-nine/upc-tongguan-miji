## 题目

F11.06 字符串匹配【★★】【函数+字符数组+指针】【改错】

【题目描述】
给定程序中函数fun的功能是: 计算s所指字符串中含有t所指字符串的数目, 并作为函数值返回。
请改正函数fun中指定部位的错误, 使它能得出正确的结果。
【输入】
有两行。第一行表示s指定字符串，第二行表示t所指字符串。
【输出】
一个整数，表示s所指字符串中含有t所指字符串的数目。
【提示】

**只能改 /\*\*\*\*\*\*\*\*\*found\*\*\*\*\*\*\*\*\*\*/ 的下一行。****不要改动main函数, 不得增行或删行, 也不得更改程序的结构。**

例如:

**样例 1**

**输入：**

```text
abababcabababc
ab
```

**输出：**

```text
m=6
```

**样例 2**

**输入：**

```text
abcabaab12123
12
```

**输出：**

```text
m=2
```

### 题目与实现说明

- 该改错题完整程序保留原题 main 和数组大小以符合改错限制，练习输入应不超过79个非空白字符。自行编写新程序时应把原 main 的 %s 改为 %79s。

## 解答

```c
#include <stdio.h>
#include <string.h>
#define N 80
int fun(char *s, char *t)
{
    int n;
    char *p, *r;
    n=0;
    while ( *s )
    {
        p=s;
        /*********found**********/
        r=t;
        while(*r)
            if(*r==*p)
            {
                r++;
                p++;
            }
            else break;
        /*********found**********/
        if(*r==0)
            n++;
        s++;
    }
    return n;
}
int main()
{
    char a[N],b[N];
    int m;
    scanf("%s",a);
    scanf("%s",b);
    m=fun(a, b);
    printf("m=%d\n",m);
    return 0;
}
```

## 讲解

1. 每次外层 while 固定一个候选起点 s，让 p 从该位置开始比较。
2. 第一个 found 后应写 r=t：每换一个候选起点，都要让模式串指针重新回到子串开头。
3. 内层逐字符比较，匹配时 p 与 r 一起右移；如果不同就跳出。
4. 第二个 found 后应写 if (*r==0)：r 到达子串结束符，才表示子串全部匹配。
5. 每轮 s 只移动一格，所以 aaaa 中的 aa 有三个匹配起点，允许重叠。

## 知识点总结

- **指针移动与数组位置**：char *p保存字符位置，*p访问该位置的字符；p++让指针指向下一个char，(*p)++才是把当前位置的字符值加1。一般T*加1移动一个T元素，不是固定移动一个字节；只能在同一数组范围及允许的尾后位置内移动，尾后位置不能解引用。

## 易错点

- 判断整个子串是否匹配必须看 r，不能只看 p 是否走到原串末尾。
- 题目限制只能改 found 下一行，不能用另一段算法替代整个函数。
