# \[4.08\]旅行时间和花费★

## 题目

**描述**

五一期间小通和朋友自驾游去外地玩。已知旅行的距离和汽车平均速度，以及每公升汽油可以行驶的公里数及每公升汽油的价格，求小通这趟驾驶汽车旅游所花费的时间和购买汽油的钱数。

**输入**

仅一行。4个数据，依次分别表示旅行的距离（单位：公里）、汽车平均速度（公里/小时）、每公升汽油可以行驶的公里数（单位：公里）、每公升汽油价格（元/公升）。

**输出**

汽车旅游所花费的时间（单位：小时）和购买汽油的钱数（单位：元），以空格分隔，数据都保留1位小数。

例如:

**输入：**

```text
1300 110 14.5 7.16
```

**输出：**

```text
11.8 641.9
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double distance, speed, km_per_liter, price;
    scanf("%lf %lf %lf %lf", &distance, &speed, &km_per_liter, &price);
    double hours = distance / speed;
    double cost = distance / km_per_liter * price;
    printf("%.1f %.1f\n", hours, cost);
    return 0;
}
```

[下载完整源码](../solutions/ch02-21.c)

## 讲解

1. 按顺序读入路程、平均速度、每升油能走的公里数、每升油的价格。
2. 时间=路程/速度；先用路程/每升行程求用油升数，再乘油价求费用。
3. 例如行驶100公里，速度50公里/小时，每升走10公里、每升7元，就需要2小时、70元。

## 知识点总结

- double变量：路程、速度和油价都可能带小数，不能用整型截断。
- 除法和乘法：distance/km_per_liter*price按从左到右算，先算升数再算金额。
- %.1f：题目要求两个结果都只保留1位小数。

## 易错点

- 每公升行驶公里数不是“百公里油耗”，不要套用另一个单位的公式。
- 有效输入中速度和每升行程都应大于0。
