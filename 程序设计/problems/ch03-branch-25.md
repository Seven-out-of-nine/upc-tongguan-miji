# \[5.25\] 最大值★

## 题目

【题目描述】

从键盘输入任意两个整数m和n，编程计算并输出m和n的最大值。

【输入】

整数m和n。

【输出】

m和n的最大值。注意测试用例的输出格式。

例如:

**输入：**

```text
5 10
```

**输出：**

```text
max=10
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int m, n;
    scanf("%d %d", &m, &n);
    int maximum = m;
    if (n > maximum) maximum = n;
    printf("max=%d\n", maximum);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-25.c)

## 讲解

1. 先把第一个数m当作当前最大值maximum。
2. 再比较n，如果n更大就更新maximum，否则保持不变。
3. 例如输入5和10，maximum从5变成10，按样例输出max=10。

## 知识点总结

- 变量初始化：maximum=m给最大值一个来自真实输入的起点。
- if与比较>：只有后一个数更大时才更新最大值。
- printf固定前缀：max=必须与%d放在同一个输出格式中。

## 易错点

- 不要把maximum初始化成0，否则两个数都为负数时容易错误输出0。
