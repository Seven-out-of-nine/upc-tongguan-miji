## 题目

10.08 单词译码【★★】

【题目描述】

最近网络上又爆出很多关于信息泄露的事情，看来信息时代的保密问题非常关键。怎样才能隐藏你的关键信息呢？作为程序设计的菜鸟一族，你可以先尝试做一些简单的译码工作。对输入的一个任意的单词进行译码输出。

译码规律是：用原来字母后面的第4个字母代替原来的字母，并能循环译码。例如，字母A后面第4个字母是E，用E代替A；同理，字母y用c代替。则单词”China”应译为”Glmre”,”Today”应译为”Xshec”。

【输入】

一个单词，长度不超过26。输入内容全部都是英文字母，不存在其他字符。

【输出】

译码后的结果。

例如:

**输入：**

```text
Helloz
```

**输出：**

```text
Lippsd
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char s[27]; scanf("%26s", s);
    for (int i = 0; s[i]; ++i) {
        char base = s[i] >= 'a' && s[i] <= 'z' ? 'a' : 'A';
        s[i] = base + (s[i] - base + 4) % 26;
    }
    puts(s); return 0;
}
```

[下载完整源码](../solutions/ch05-string-08.c)

## 讲解

1. 先判断当前字母是小写还是大写，选取对应的起点a或A。
2. 减去起点得到序号，序号加4后模26，再加回起点。
3. 例如y的序号24，加4模26是2，因此变成c。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 保持原字母大小写；不能让Z加4直接成为标点。
