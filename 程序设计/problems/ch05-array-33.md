## 题目

【题目描述】

小明最近要负责图书馆的管理工作，需要记录下每天读者的到访情况，每位读者有一个编号，每条记录用读者的编号来表示，给出读者的来访纪录，请问每一条记录中的读者是第几次出现。

【输入】

有两行。第1行包含一个整数n（1≤n≤1000），表示小明的记录数。第2行包含n个整数，依次表示小明的记录中每位读者的编号（不超过n）。

【输出】

仅一行。包含n个整数，依次表示每条记录中读者编号是第几次出现，数据间用一个空格分开。

例如:

**输入：**

```text
5
1 2 1 1 3
```

**输出：**

```text
1 1 2 3 1
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, reader, count[1001] = {0};
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &reader);
        ++count[reader];
        if (i) putchar(' ');
        printf("%d", count[reader]);
    }
    putchar('\n');
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-33.c)

## 讲解

1. 用count[reader]保存该读者在当前记录之前已经出现的次数，全部初始为0。
2. 每读到一个编号，先把对应次数加1，再输出更新后的次数，这就是本次是第几次来访。
3. 例如1、2、1、1、3依次使对应次数变为1、1、2、3、1，正好得到样例输出。

## 知识点总结

- 计数数组的下标是读者编号，内容是来访次数，两者不要混淆。
- ++count[reader]：只增加当前编号对应的次数，不影响其他读者。
- 逐条读取逐条处理：本题答案只依赖当前与之前记录，无需保存整个来访数组。

## 易错点

- 必须先加1再输出，否则第一次来访会被输出为0。
- 读者编号可等于1000，数组需要1001个位置才能用编号直接作下标。
