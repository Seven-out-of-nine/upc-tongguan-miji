## 题目

描述

某通信系统，发射系统和接收系统可以一起买，也可以分开买。若买的不少于50套，每套800元；不足50套的每套900元，只买发射系统每个装置600元，只买接收系统每个装置450元。编写程序，输入计划购买的发射系统数量 a 和接收系统的数量 b ，计算并输出应该付的最小金额 m 。

输入

输入：发射系统的数目和接受设备的数目（两位整数）

输出

输出：需要的最小金额

例如:

**输入：**

```text
1 1
```

**输出：**

```text
900
```

### 题目与实现说明

- 按恰好购买计划数量解释，不允许额外购买不需要的设备以凑折扣；保存页参考行为也采用该解释。

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long transmitters, receivers;
    scanf("%lld %lld", &transmitters, &receivers);
    long long pairs = transmitters;
    if (receivers < pairs) pairs = receivers;
    long long price = 900;
    if (pairs >= 50) price = 800;
    long long cost = pairs * price + (transmitters - pairs) * 600
                   + (receivers - pairs) * 450;
    printf("%lld\n", cost);
    return 0;
}
```

## 讲解

1. 一套包含一台发射系统和一台接收系统，因此能配成的套数是两种数量的较小值。
2. 单买一对要600+450=1050元，成套无论900还是800都更便宜，所以先尽可能配套。
3. 例如要11台发射、9台接收，配9套共8100元，再单买2台发射1200元，总额9300元。

## 知识点总结

- 求较小值：用if更新pairs，确保套数不超过任何一种设备的需求。
- 分支选择单价：pairs>=50时整批套装每套800，否则每套900。
- 剩余数量：transmitters-pairs、receivers-pairs分别得到仍需单买的数量。

## 易错点

- 优惠看的是配套数量，不是两种设备数量之和。
- 多出的发射系统按600计价，多出的接收系统按450计价，不要混淆。
