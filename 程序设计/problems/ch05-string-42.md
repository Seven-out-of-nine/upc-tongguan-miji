## 题目

【题目描述】

国际标准书号（International Standard Book Number），简称ISBN，是专门为识别图书等文献而设计的国际编号。每一本正式出版的图书都有一个ISBN号码与之对应，旧版ISBN码包括9位数字、1位识别码和3位分隔符，其规定格式如“x-xxx-xxxxx-x”，其中符号“-”就是分隔符（键盘上的减号），最后一位是识别码，例如7-309-04547-5就是一个标准的ISBN码。ISBN码的首位数字表示书籍的出版语言；第一个分隔符“-”之后的三位数字代表出版社；第二个分隔符后的五位数字代表该书在该出版社的编号；最后一位为识别码。

识别码的计算方法如下：首位数字乘以1加上次位数字乘以2……以此类推，用所得的结果mod 11，所得的余数即为识别码，如果余数为10，则识别码为大写字母X。例如ISBN号码0-670-82162-4中的识别码4是这样得到的：对067082162这9个数字，从左至右分别乘以1，2，...，9，再求和，即0×1+6×2+……+2×9=158，然后取158 mod 11的结果4作为识别码。

你的任务是编写程序判断输入的ISBN号码中识别码是否正确，如果正确，则仅输出“Right”；如果错误，则输出你认为是正确的ISBN号码。

【输入】

仅一行，是一个字符序列，表示一本书的ISBN号码（保证输入符合ISBN号码的格式要求）。

【输出】

仅一行，假如输入的ISBN号码的识别码正确，那么输出“Right”；否则，按照规定的格式，输出正确的ISBN号码（包括分隔符“-”）。

例如:

**输入：**

```text
0-670-82162-4
```

**输出：**

```text
Right
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char s[14]; scanf("%13s", s);
    int sum = 0, weight = 1;
    for (int i = 0; i < 12; ++i) if (s[i] != '-') sum += (s[i] - '0') * weight++;
    int remainder = sum % 11;
    char expected = remainder == 10 ? 'X' : '0' + remainder;
    if (s[12] == expected) puts("Right");
    else { s[12] = expected; puts(s); }
    return 0;
}
```

## 讲解

1. 扫描校验码之前的字符，跳过三个短横线。
2. 九个数字分别乘1到9，求和后模11，余数10映射为X。
3. 例如0-670-82162-4的和为158，余数4与末位相同，输出Right。
4. 若不相同，只修改末位，保留原分隔符输出正确ISBN。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 计算时不包括末尾识别码。
- 余数10不是字符冒号，而是大写X。
