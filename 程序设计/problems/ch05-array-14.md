# 8.14 找鞍点【★★★】

[学习首页](../README.md) · [本章目录](../chapters/ch05-array/README.md) · [知识点索引](../知识点索引.md)

## 题目

**【题目描述】**

在微分方程中，沿着某一方向是稳定的，另一条方向是不稳定的奇点，叫做鞍点。在泛函中，既不是极大值点也不是极小值点的临界点，叫做鞍点。在矩阵中，一个数在所在行中是最大值，在所在列中是最小值，则被称为鞍点。在物理上要广泛一些，指在一个方向是极大值，另一个方向是极小值的点。编写一个程序，找出n×m的矩阵a的鞍点，若存在必唯一，不存在则输出“Not Found”。

**【输入】**

有多行。第1行是两个整数n（n≤10）和m（m≤10），表示矩阵有n行m列。接下来n行，每行包含m个整数，表示矩阵值。

**【输出】**

仅一行。如果鞍点存在，则按指定格式输出鞍点；否则，输出“Not Found”。

例如:

**输入：**

```text
3 4
1 2 13 4
7 8 10 6
3 5 9 7
```

**输出：**

```text
a[2][2]=9
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, m, matrix[10][10];
    scanf("%d%d", &n, &m);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j) scanf("%d", &matrix[i][j]);
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            int ok = 1;
            for (int k = 0; k < m; ++k)
                if (matrix[i][k] > matrix[i][j]) ok = 0;
            for (int k = 0; k < n; ++k)
                if (matrix[k][j] < matrix[i][j]) ok = 0;
            if (ok) { printf("a[%d][%d]=%d\n", i, j, matrix[i][j]); return 0; }
        }
    }
    puts("Not Found");
    return 0;
}
```

## 讲解

1. 依次把每个元素当作候选鞍点，先假设它合格，令ok=1。
2. 扫描它所在行，只要有更大的数，它就不是行最大；扫描所在列，只要有更小的数，它就不是列最小。
3. 两个扫描都没有否定它时就输出位置和值；全部元素都不合格才输出Not Found。
4. 样例9是第2行最大且第2列最小，所以输出a[2][2]=9。

## 知识点总结

- 二维数组matrix[i][j]：固定i、改变列号扫描一行；固定j、改变行号扫描一列。
- 标志变量ok：1表示暂时合格，发现反例就赋0。
- return 0：在main中找到唯一鞍点后直接结束整个程序。

## 易错点

- 行取最大、列取最小，方向不能弄反。
- 相等的同行或同列元素不会否定极值，应使用严格的>和<进行排除。
