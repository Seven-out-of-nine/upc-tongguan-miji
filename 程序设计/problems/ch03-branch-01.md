# \[5.01\]选择最佳的通信线路★

## 题目

**描述**

在通信线路中，节点越少转发所用的时间越少，说明该线路越优，根据两条线路的节点数，选择最优的那条通信线路。

**输入**

3 10

**输出**

3

例如:

**样例 1**

**输入：**

```text
3 10
```

**输出：**

```text
3
```

**样例 2**

**输入：**

```text
6 5
```

**输出：**

```text
5
```

**样例 3**

**输入：**

```text
8 10
```

**输出：**

```text
8
```

**样例 4**

**输入：**

```text
0 0
```

**输出：**

```text
0
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    scanf("%d %d", &a, &b);
    int best = a;
    if (b < best) best = b;
    printf("%d\n", best);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-01.c)

## 讲解

1. 节点越少线路越优，因此问题就是求两个节点数中的较小值。
2. 先假定第一条线路最好，令best=a；若b更小，就改为b。
3. 例如输入6和5，b<best成立，best从6变成5，最后输出5；相等时输出任意一个数值都一样。

## 知识点总结

- if语句：只有条件b<best成立，后面的赋值才执行。
- 比较运算符<：比较两个数的大小，结果用于决定走哪条分支。
- 赋值语句：best=b会更新best保存的数，不会改变b。

## 易错点

- 题目要较小值，不是线路编号，也不是较大值。
