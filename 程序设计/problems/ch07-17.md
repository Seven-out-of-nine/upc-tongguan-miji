## 题目

3.15 定义一个复数类，实现复数的加减乘除【★★★】

定义一个复数类，实现复数的加减乘除

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class complex {
private:
    double real;  
    double imag;  
public:
    
    complex(double r = 0, double i = 0) : real(r), imag(i) {}

    
    complex add(complex& c) {
        return complex(real + c.real, imag + c.imag);
    }

    
    complex sub(complex& c) {
        return complex(real - c.real, imag - c.imag);
    }

    
    complex mul(complex& c) {
        double r = real * c.real - imag * c.imag;
        double i = real * c.imag + imag * c.real;
        return complex(r, i);
    }

    
    complex div(complex& c) {
        double denominator = c.real * c.real + c.imag * c.imag; 
        double r = (real * c.real + imag * c.imag) / denominator;
        double i = (imag * c.real - real * c.imag) / denominator;
        return complex(r, i);
    }

    
    void print() {
        cout << real << (imag >= 0 ? "+" : "-") << abs(imag) << "i" << endl;
    }
};

int main()
{
	complex c1(2.3,4.6),c2(3.6,2.8),c3,c4,c5,c6;
	c3=c1.add(c2);
	c3.print();
	c4=c1.sub(c2);
	c4.print();
	c5=c1.mul(c2);
	c5.print();
	c6=c1.div(c2);
	c6.print();
	return 0;
}
```

## 讲解

1. 把复数a+bi拆成实部real与虚部imag两个double成员。
2. 加减法分别对实部与虚部运算；例如(2.3+4.6i)+(3.6+2.8i)=5.9+7.4i。
3. 乘法展开后用i*i=-1合并，实部ac-bd、虚部ad+bc。
4. 除法把分子分母同乘除数的共轭，分母c*c+d*d，实部(ac+bd)/分母，虚部(bc-ad)/分母。
5. 显示时根据虚部符号输出+或-，后面再输出其绝对值，避免出现+-。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 复数除法的分母不是c+d；除数为0+0i时不允许除法，本演示除数非零。
