## 题目

【题目描述】

天气太冷，外面冷得像冰库，真郁闷！小明实在无聊，冻得哪儿都去不了，只能玩玩字符游戏，他想把ab变成aba，把123变成12321，你来帮帮他的忙吧。

【输入】

若干行。每行一个字符串，最长为200位，最短为2位。

【输出】

镜像文字，如输入124，则输出12421。

例如:

**输入：**

```text
124
```

**输出：**

```text
12421
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int main(void) {
    char s[203];
    while (fgets(s, sizeof s, stdin)) {
        int n = 0;
        while (s[n] && s[n] != '\n' && s[n] != '\r') ++n;
        s[n] = '\0';
        printf("%s", s);
        for (int i = n - 2; i >= 0; --i) putchar(s[i]);
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 先输出原字符串。
2. 再从倒数第二个字符开始向前输出，最后一个字符充当镜像中心，不再重复。
3. 例如124先输出124，再倒着输出2、1，得到12421。

## 知识点总结

- n-2：跳过已经作为中心输出过的末字符。
- i--：从右向左移动到首字符。
- while(fgets(...))：一行一组，处理到文件结束。

## 易错点

- 结果长度是2n-1，不能把整个原串反转再拼接。
