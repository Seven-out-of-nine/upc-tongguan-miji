## 题目

【题目描述】

编程求大于整数m且紧靠m的k个素数。

【输入】

仅一行。两个整数m（0≤m≤1000）和k（0&lt;k≤1000）。

【输出】

仅一行。k个素数，数据间以空格分隔。

**前置代码：**

```text
#include <stdio.h>
#include <math.h>
#define N 100
#include <bits/stdc++.h>
using namespace std;
```

**后置代码：**

```text
int main()
{
    int i, m, k, zz[N + 5], cnt = 0; //统计素数的变量cnt赋初值0
    scanf("%d%d", &m, &k);
    for(i = m + 1; cnt < k; i++)  //cnt累加到k-1即可
    {
        if(Prime(i))           //如果返回值为1，将素数存入zz数组
        {
            zz[cnt++] = i;    //统计变量cnt可以用作数组下标
        }
    }
    for(i = 0; i < k; i++)        //控制输出数据间以空格分隔
    {
        if(i)
        {
            printf(" ");
        }
        printf("%d", zz[i]);
    }
    printf("\n");
    return 0;
}
```

例如:

**输入：**

```text
17 5
```

**输出：**

```text
19 23 29 31 37
```

### 题目与实现说明

- 平台要求只提交 Prime；若使用题目所示原main测试 k>105，还须由平台把 zz 数组扩为至少1000项，函数本身无法修复调用者容量。

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
int Prime(int x) {
    if (x < 2) return 0;
    for (int d = 2; d <= x / d; d++) {
        if (x % d == 0) return 0;
    }
    return 1;
}
```

<details>
<summary>展开完整本地运行程序</summary>

```c
#include <stdio.h>
#include <string.h>

int Prime(int x) {
    if (x < 2) return 0;
    for (int d = 2; d <= x / d; d++) {
        if (x % d == 0) return 0;
    }
    return 1;
}

int main(void) {
    int m, k, count = 0, primes[1000];
    scanf("%d%d", &m, &k);
    for (int x = m + 1; count < k; x++) {
        if (Prime(x)) primes[count++] = x;
    }
    for (int i = 0; i < k; i++) printf("%s%d", i ? " " : "", primes[i]);
    printf("\n");
    return 0;
}
```

</details>

## 讲解

1. 先写 Prime：小于2不是素数；其余数试着用2到平方根之间的整数去除。
2. 从 m+1 开始逐个检查，每找到一个素数就存入数组。
3. 一直找够 k 个才结束，所以得到的正是紧靠 m 的后续 k 个素数。
4. 例如 m=0、k=3，先排除1，再保留2、3、5。
