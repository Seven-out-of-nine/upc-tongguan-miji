## 题目

**【题目描述】**

小明比较喜欢图形，而且总是喜欢把图形倒过来欣赏。有一次，他看到了杨辉三角形，觉得很新鲜，于是就把它们大大小小地摆列出来了，好不得意哦。图形的摆布小明都是手工完成的，效率太低了，请你编程帮他实现吧！

**【输入】**

仅一行。一个正整数n（3≤n≤10），表示构造n行n列的倒立的杨辉三角。

**【输出】**

n行n列的倒立的杨辉三角（每个数据以4列的域宽显示）。

例如:

**输入：**

```text
5↵
```

**输出：**

```text
   1   4   6   4   1
     1   3   3   1
       1   2   1
         1   1
           1
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, triangle[10][10] = {{0}};
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        triangle[i][0] = triangle[i][i] = 1;
        for (int j = 1; j < i; ++j)
            triangle[i][j] = triangle[i - 1][j - 1] + triangle[i - 1][j];
    }
    for (int i = n - 1; i >= 0; --i) {
        for (int k = 0; k < 2 * (n - 1 - i); ++k) putchar(' ');
        for (int j = 0; j <= i; ++j) printf("%4d", triangle[i][j]);
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 先按正常顺序生成n行杨辉三角：两端设1，中间为上一行相邻两数之和。
2. 输出时从最后一行向第一行倒着打印，每个数占4列。
3. 越往下每行少一个数，为保持样例的居中效果，每下一行多输出2个开头空格。
4. 例如n=3，先输出1 2 1，再以2个额外空格输出1 1，最后以4个额外空格输出1。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 样例的前导空格来自额外缩进与%4d自身补空格两部分。
- 本题n≤10可用int，不应直接把该容量或类型用于100行的另一道杨辉三角题。
