# \[3.05\]简单实数求和运算★

## 题目

**描述**

从键盘上输入一个实数，再输入一个实数，求和，然后输出

**输入**

一行，输入两个实数，用空格符分隔。

**输出**

一行，输出两个实数的和，结果保留两位小数。

例如:

**输入：**

```text
1.1 2.2
```

**输出：**

```text
3.30
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double a, b;
    scanf("%lf %lf", &a, &b);
    printf("%.2f\n", a + b);
    return 0;
}
```

[下载完整源码](../solutions/ch02-08.c)

## 讲解

1. 用两个 double 变量保存输入的实数。
2. 直接计算 a+b，不要先转成整数。
3. 例如 1.1+2.2 得到3.3，%.2f 会补齐末尾的0，显示3.30。

## 知识点总结

- double：用来保存1.1、2.2这样的实数。
- scanf 的 %lf：读取 double，需要传入变量地址 &a、&b。
- printf 的 %.2f：把浮点结果按两位小数显示，位数不足时补0。

## 易错点

- scanf 读取 double 要用 %lf，不能误写成读取 float 的 %f。
- 不要用 int 接收实数，否则会丢失小数部分。
