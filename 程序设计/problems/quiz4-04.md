## 题目

6002 谁是猪

题目描述

拱猪是四人一副扑克的经典游戏，游戏有特殊的计分方法，若是同学们编过这个游戏，一定痛不欲生。好啦！这回老师降低难度，玩家数量随意N（1&lt;=N&lt;=10），只要谁手里最后最后握有Q，谁就是猪！

输入

输入有多组数据，代表每个玩家最后持有的牌(2~9,A,J,Q,K，大王用空格表示，小王用\*表示，不考虑小写字符和10)。每人持牌总数不超过52，且至少持有一张。每组测试用例保证必有且只有一张Q。

输出

一个整数，表示第几个玩家是猪，从1开始。

例如:

**输入：**

```text
234AJK7788QA
K 78
*J
```

**输出：**

```text
1
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int main(void) {
    char s[56]; int player = 0, answer = 0;
    while (fgets(s, sizeof s, stdin)) {
        ++player;
        for (int i = 0; s[i]; ++i) if (s[i] == 'Q') answer = player;
    }
    printf("%d\n", answer); return 0;
}
```

## 讲解

1. 每一行代表一个玩家，读入一行就将玩家编号加1。
2. 扫描该行所有牌，若看到Q就记录这个玩家的编号。
3. 例如第一行没有Q、第二行是K Q，记录并输出2；空格大王牌仍属于这一行。

## 知识点总结

- fgets：读取包括空格在内的完整手牌。
- player从0起：先加1后处理，第一行编号为1。
- s[i]=='Q'：只寻找题意指定的大写Q。

## 易错点

- 没有单独输入N，玩家数量由实际输入行数决定。
- 不能用%s，否则空格会把同一玩家手牌拆开。
