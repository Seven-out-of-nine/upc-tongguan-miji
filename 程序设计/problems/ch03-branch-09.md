# \[5.09\]判断闰年★

来源：【测验】第3章 part1分支.html，第9题。

## 题目

**描述**

输入一年分，判断是否是闰年。如果是，输出：yes，如果过不是，输出no

**输入**

输入年份

**输出**

输出yes 或者 no

例如:

**输入：**

```text
2000
```

**输出：**

```text
yes
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int year;
    scanf("%d", &year);
    if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0)) {
        puts("yes");
    } else {
        puts("no");
    }
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-09.c)

## 讲解

1. 普通年份能被4整除就是闰年，但整百年份还必须能被400整除。
2. 把规则合起来：能被400整除，或者能被4整除但不能被100整除。
3. 例如2000能被400整除，是闰年；1900虽能被4整除，但能被100整除又不能被400整除，所以不是。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 只判断能否被4整除会把1900这样的年份误判为闰年。
