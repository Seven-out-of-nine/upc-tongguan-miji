## 题目

**描述**

顺序读入浮点数1、整数、字符、浮点数2，其间以1个空格作为分隔符。再按照字符、整数、浮点数1、浮点数2的顺序输出，其中浮点数保留小数点后2位。

**输入**

仅一行。按顺序输入浮点数1、整数、字符、浮点数2。

**输出**

仅一行。按顺序输出字符、整数、浮点数1、浮点数2。

例如:

**输入：**

```text
2.12 88 c 4.7
```

**输出：**

```text
c 88 2.12 4.70
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double first, second;
    int number;
    char ch;
    scanf("%lf %d %c %lf", &first, &number, &ch, &second);
    printf("%c %d %.2f %.2f\n", ch, number, first, second);
    return 0;
}
```

[下载完整源码](../solutions/ch02-18.c)

## 讲解

1. 按输入顺序建立“实数、整数、字符、实数”四个变量。
2. 读取完成后，按“字符、整数、第一个实数、第二个实数”重新输出。
3. 例如2.12 88 c 4.7变成c 88 2.12 4.70，最后一个数由输出格式补齐0。

## 知识点总结

- **scanf中的空白匹配**：scanf格式里的空白表示跳过一段输入空白，不只匹配一个空格。%c本身不跳过空白，因此" %c"可跳过数字后的分隔空格；若要判断的就是空格，应使用"%c"或getchar。

## 易错点

- %c前不要漏掉分隔空格，否则可能读到上一个数后面的空格。
- 输出的四项之间各一个空格，实数都要保留两位小数。
