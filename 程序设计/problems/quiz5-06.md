## 题目

20108 胡恼的邮箱密码

胡恼有个烦恼，就是给邮箱设置密码。邮箱系统为了安全考虑，要求密码必须包含大写字母、小写字母和数字，还要求每月一换。大家都知道，起名什么的可难了，更何况是改密码。胡恼原本的密码很简单，就是他的名字（或名字缩写）+空格+生日，现在他要编一个程序，将这个密码自动转换成符合邮箱系统要求的密码。转换规则如下：

1）将空格变成数字‘0’；

2）检查一下原密码中是否包含大写字母，如果有则不变，如果没有则将首字母变成大写，测试用例保证首字符是字母。

例如：“hunao 19990909”转换成“Hunao019990909”；而“huN 19990909”会转换成“huN019990909”。

【输入】

一个字符串，含空格，长度不超过20。

【输出】

转换后的字符串

例如:

**输入：**

```text
hunao 19990909
```

**输出：**

```text
Hunao019990909
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int main(void) {
    char s[23]; read_line(s, sizeof s);
    int upper = 0;
    for (int i = 0; s[i]; ++i) {
        if (s[i] >= 'A' && s[i] <= 'Z') upper = 1;
        if (s[i] == ' ') s[i] = '0';
    }
    if (!upper) s[0] = s[0] - 'a' + 'A';
    puts(s); return 0;
}
```

## 讲解

1. 读入含空格的整行密码，扫描原有大写字母是否存在。
2. 同时把每个空格改为数字字符0。
3. 如果原串没有大写字母，再把首字符改大写；例如hunao 1得到Hunao01，而huN 1得到huN01。

## 知识点总结

- char数组：可以原位修改密码字符。
- upper：只记录是否至少出现过一个大写，不必计数。
- s[i]='0'：写入数字字符，不是字符串结束符\0。

## 易错点

- 只在整个原密码没有大写时修改首字母。
- 不能用%s读取含空格的密码。
