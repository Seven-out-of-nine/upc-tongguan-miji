## 题目

F11.02 最值问题【★】【函数+整型数组+指针】

【题目描述】
请编写函数 Fun ，其功能是求出数组的最大元素在数组中的下标并存放在 k 所指的存储单元中。
【输入】
仅一行。10个整数。
【输出】
两个整数，第1个整数表示最大值的下标，第2个整数是最大值，以逗号分隔。
【提示】
**注意：本题只需提交Fun函数即可**

预设代码

前置代码

```text
#include <stdio.h>
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main( )
{
    int a[10], k ,i;
    for(i=0;i<10;i++)
       scanf("%d",&a[i]);
    Fun(a, 10, &k) ;
    printf("%d,%d\n", k, a[k]) ;
    return  0;
}
```

例如:

**输入：**

```text
876 675 896 101 301 401 980 431 451 777
```

**输出：**

```text
6,980
```

### 题目与实现说明

- 原题未约定最大值重复时选哪一个，本题沿用保存答案的>=规则，选择最后一个位置；改为>则选择第一个。

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(int a[], int n, int *k) {
    *k = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] >= a[*k]) *k = i;
    }
}
```

<summary>展开完整本地运行程序</summary>

```c
#include <stdio.h>
#include <string.h>

void Fun(int a[], int n, int *k) {
    *k = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] >= a[*k]) *k = i;
    }
}

int main(void) {
    int a[10], k;
    for (int i = 0; i < 10; i++) scanf("%d", &a[i]);
    Fun(a, 10, &k);
    printf("%d,%d\n", k, a[k]);
    return 0;
}
```

## 讲解

1. 先把第0个元素当作当前最大值，k=0。
2. 从第1个元素开始，若当前元素不小于已有最大值，就更新最大值下标。
3. 例如[-5,-2,-9]从-5开始比较，最终下标为1，最大值为-2；不能把最大值初始化为0。

## 知识点总结

- 用 a[*k] 读取当前记录的最大元素，比另外保存最大值更直接。
- >= 会在相等时更新，所以这里保留最后一个最大值的下标。
- 下标从0开始，因此样例中的980位于下标6。

## 易错点

- 原答案把最大值初始为0，全为负数时可能不赋值，必须修正。
