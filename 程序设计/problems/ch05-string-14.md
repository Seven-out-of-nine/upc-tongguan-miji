## 题目

10.14 合法标识符【★★】

【题目描述】

所谓标识符就是C语言中的变量名、函数名、数组名、文件名、类型名等。C语言合法标识名的命名规则是：（1）标识符由字母、数字或下划线组成；（2）第一个字符不能是数字只能是字母或下划线；（3）区分大小写。（4）不能和C语言的关键字冲突。（5）长度不宜太长。

【输入】

一个长度不超过20的字符串，不是C语言的关键字。

【输出】

如果输入数据是合法的C语言标识符，则输出YES；否则，输出NO。

例如:

**输入：**

```text
fi8x_a
```

**输出：**

```text
YES
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int letter(char c) { return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z'); }
int main(void) {
    char s[23]; read_line(s, sizeof s);
    int valid = letter(s[0]) || s[0] == '_';
    for (int i = 0; s[i]; ++i)
        if (!letter(s[i]) && !(s[i] >= '0' && s[i] <= '9') && s[i] != '_') valid = 0;
    puts(valid ? "YES" : "NO"); return 0;
}
```

## 讲解

1. 首字符只能是字母或下划线，先检查这一条。
2. 再检查每个字符，只允许字母、数字和下划线。
3. 例如2abc虽然字符种类都合法，但首字符为数字，所以输出NO。
