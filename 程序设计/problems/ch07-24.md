## 题目

5.09 动态多态性的应用【★★】

写一个程序，定义基类Container，由它派生出3个派生类：Sphere（球体）、Cylinder（圆柱体）、Cube（正方体）。利用多态性实现各自方法，分别计算几种图形的表面积和体积。

例如:

**输出：**

```text
The Surface area of the Sphere is 314
The Volume of the Sphere is 523.333
The Surface area of the Cylinder is 345.4
The Volume of the Cylinder is 471
The Surface area of the Cube is 150
The Volume of the Cube is 125
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Container
{
protected:
    int r;
public:
    Container(int r):r(r){}
   virtual ~Container() = default;
   virtual double surface_area()
    {
       return 0.0;
    }
    virtual double volume()
    {
        return 0.0;
    }
};
class Sphere : public Container
{
public :
    Sphere(int r):Container(r){}
    double surface_area()
    {
        return 3.14*4*r*r;
    }
    double volume()
    {
        return 4.0/3.0*3.14*r*r*r;
    }
};
class Cylinder : public Container
{
private:
    int l;
public :
   Cylinder(int r,int l):Container(r)
   {
       this->l=l;
   }
    double surface_area()
    {
        return 2*3.14*r*r+2*3.14*r*l;
    }
    double volume()
    {
        return 3.14*r*r*l;}
};
class Cube : public Container
{

public :
 Cube (int r):Container(r){}
    double surface_area()
    {
        return 6*r*r;
    }
    double volume()
    {
        return r*r*r;
    }
};
int main()
{
	Container *p;
	Sphere s(5);
	Cylinder c(5,6);
	Cube cu(5);
	p=&s;
	cout<<"The Surface area of the Sphere is "<<p->surface_area()<<endl;
	cout<<"The Volume of the Sphere is "<<p->volume()<<endl;
	p=&c;
	cout<<"The Surface area of the Cylinder is "<<p->surface_area()<<endl;
	cout<<"The Volume of the Cylinder is "<<p->volume()<<endl;
	p=&cu;
	cout<<"The Surface area of the Cube is "<<p->surface_area()<<endl;
	cout<<"The Volume of the Cube is "<<p->volume()<<endl;
	return 0;
}
```

## 讲解

1. 基类Container把表面积和体积声明为virtual方法，三个派生类分别实现自己的公式。
2. 球用4πr²与4πr³/3，圆柱用2πr²+2πrh与πr²h，正方体用6a²与a³。
3. 同一个Container*p先指向球，再指向圆柱和正方体；p->调用会根据实际对象选择正确方法。
4. 例如边长5的正方体表面积为150、体积为125，指针类型仍然是Container*。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 只写三个独立类并分别调用不体现动态多态；必须保留基类指针与virtual方法。
