## 题目

**描述**

输入三个数a,b,c，从小到大输出，并保留一位小数。

**输入**

a,b,c(三个数保证不同)

**输出**

从小到大，用逗号隔开，并保留一位小数。

## 解答

```c
#include <stdio.h>

int main(void)
{
    double a, b, c, temp;
    scanf("%lf,%lf,%lf", &a, &b, &c);
    if (a > b) { temp = a; a = b; b = temp; }
    if (a > c) { temp = a; a = c; c = temp; }
    if (b > c) { temp = b; b = c; c = temp; }
    printf("%.1f,%.1f,%.1f\n", a, b, c);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-18.c)

## 讲解

1. 先比较a和b，保证a不大于b；再比较a和c，把最小值留在a中。
2. 此时只剩b、c之间的顺序可能错误，再比较一次即可。
3. 例如3,1,2：第一步变为1,3,2，第二步不变，第三步变为1,2,3，输出1.0,2.0,3.0。

## 知识点总结

- double：题目输入的是实数，需要保留小数信息。
- 比较交换：只有前一个数比后一个大才通过temp交换，逐步建立从小到大的顺序。
- %.1f：输出一位小数，三个数间的英文逗号直接写在格式字符串中。

## 易错点

- 做完前两次交换后，不要漏掉最后对b、c的比较。
- scanf要求输入带逗号，不能直接使用空格格式读取题目数据。
