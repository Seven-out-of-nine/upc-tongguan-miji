## 题目

|【问题描述】|
|---|
|    我叫郭大锤，是一个刚找到工作的程序员。万万没想到，刚开始工作的第一天，就发生了大事。某市高校P大与T大由于长期矛盾的积累，终于在这天爆发了全面战争。 <br>    T大的导弹是突破了次元之壁的导弹，它会先在n维空间中运动，抵达目标后出现在P大相应的位置。P大及时的发明了在n维空间中阻截的方法，并找到了导弹的方向，现在我需要做的是计算出导弹的速度大小。 <br>    P大找到了我所在的公司，而这个任务竟然落到了刚加入公司的我身上。现在公司的谍报人员已经获知，T大的导弹的速度大小是由先发出的两颗信号弹的速度矢量决定的，他们还顺便帮我捕获到了最终发射出的导弹的速度大小与信号弹速度矢量之间的关系为v(-)=v1·v2（v1，v2分别为2颗信号弹的速度矢量，v(-)为导弹的速度大小，·为矢量内积）。 <br>    我的同事们会告知我信号弹的速度信息，展现我高深莫测的专业技术的时刻到了！计算出导弹的速度吧！ <br><br>    矢量内积公式： <br>        （a1,...,an）·（b1,...,bn）= a1b1 + ... + anbn|
|【输入】|
|    第一行一个整数n(1&lt;=n&lt;=1000)，表示导弹所在空间的维度 <br>    第二行n个整数，表示第一颗信号弹的速度矢量 <br>    第三行n个整数，表示第二颗信号弹的速度矢量|
|【输出】|
|    一个整数，表示导弹的速度大小，结果保证在int表示范围之内(结果可为负，此时表示导弹在远离P大)|

例如:

**输入：**

```text
3
1 1 1
1 1 1
```

**输出：**

```text
3
```

### 题目与实现说明

- 分块累加用于覆盖int分量存在大量正负抵消的情况；如另有“所有中间和在long long内”的限制，也可直接用long long总和累加。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, first[1000], second;
    const long long base = 1000000000LL;
    long long high = 0, low = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) scanf("%d", &first[i]);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &second);
        long long product = (long long)first[i] * second;
        high += product / base;
        low += product % base;
        high += low / base;
        low %= base;
    }
    printf("%lld\n", high * base + low);
    return 0;
}
```

## 讲解

1. 向量内积是对应分量相乘再相加，先存下第一组分量，读到第二组第i项时就计算first[i]*second。
2. 乘法前先转换成long long，避免两个int相乘先溢出。
3. 题目只保证最终答案在int内，没有保证中间总和；用high*10⁹+low表示总和，分别累加每个乘积的商和余数。
4. 每次把low中超过10⁹的部分转入high，让low始终较小；两组分量最多1000项，high也不会接近long long上限。
5. 例如(1,2)与(3,4)内积为1×3+2×4=11，最终按整数输出；结果为负也保留符号。

## 知识点总结

- (long long)first[i]*second：强制转换在乘法之前进行，让乘积使用64位整数计算。
- const long long base：定义不会修改的十进制分块基数。
- 商与余数恒等式：product=(product/base)*base+product%base，负数也成立。
- high+=low/base与low%=base：将低块进位或借位到高块，保持总值不变。
- %lld：输出long long，虽然最终保证在int内，表示过程使用更宽类型。

## 易错点

- 不能把两组向量分量先分别相加再相乘，那不是内积。
- 只有最终结果在int范围不代表中间乘积、部分和也在int范围。
