## 题目

6006 神奇的魔镜

题目描述

某某国王（不是萨拉克门托！）有一个神奇的魔镜，它可以把东西变为原来的两倍(可惜是反的)。某日，他感到很无聊，于是把皇后的一串珠子变了不知道几次，皇后回来之后不是很高兴，她还是喜欢原来那串珠子，现在告诉你改变之后珠子的形状，请你告诉她，原来的珠子是什么样子的。

【注意：奇数个珠子不被认为是对称的】

输入

输入有多组测试用例，每组一行，每行一串字符，表示现在的珠串，长度小于100。

输出

输出对应有多行，每行输出原来的珠串。

提示

注意：若左右对称则保留左边的一节

例如:

**输入：**

```text
1232232112322321
121121
abba
```

**输出：**

```text
1232
121
ab
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int main(void) {
    char s[103];
    while (fgets(s, sizeof s, stdin)) {
        int n = 0; while (s[n] && s[n] != '\n' && s[n] != '\r') ++n;
        s[n] = '\0';
        while (n > 0 && n % 2 == 0) {
            int symmetric = 1;
            for (int i = 0; i < n / 2; ++i) if (s[i] != s[n - 1 - i]) symmetric = 0;
            if (!symmetric) break;
            n /= 2; s[n] = '\0';
        }
        puts(s);
    }
    return 0;
}
```

## 讲解

1. 镜子变换后的串由原串和原串的反序拼成，长度一定是偶数且左右对称。
2. 若当前串满足这两条，就只保留左半段，继续尝试恢复上一轮。
3. 例如abba是偶数回文，保留ab；ab不对称，停止并输出ab。
4. 121虽然回文但长度是奇数，不可再缩短。

## 知识点总结

- n%2==0：检查能否平分成两半。
- s[i]与s[n-1-i]：比较两端对称字符。
- `s[n] = '\0'`：缩短后给新末尾补结束符。

## 易错点

- 要反复缩短直到不能继续，而不是只删一次。
- 奇数回文不允许被当成一次镜像结果。
