## 题目

20103 胡恼的黑猪标签

胡恼是国内某顶尖大学的软件工程专业毕业生，毕业后下岗海养猪，因为他觉得养猪比编程有趣有钱途，何况他养的还是蜀山纯种黑背卷鬃短尾野香猪。目前他麾下有1龄和2龄两栏猪，现在他准备给每头猪评级并且打个标签。对于1龄猪，如果体重小于等于200斤，评级为B；如果体重大于200斤且小于等于300斤，评级为A；如果体重大于300斤，评级为S。对于2龄猪，如果体重小于等于300斤，评级为B；如果体重大于300斤且小于等于400斤，评级为A；如果体重大于400斤，评级为S。

标签由3位组成，第一位为年龄（1或2），第二位为体重（小于999）的百位数字，第三位为该猪的评级。例如某头1龄猪，体重250斤，则其标签为“12A”。胡恼决定编个程序来自动打标签，他对来访的记者感慨到：编程是第一生产力，这年头为了养猪也要好好学编程啊！

【输入】

两个整数，分别为猪的年龄和体重，以逗号分隔。

【输出】

猪的标签

例如:

**输入：**

```text
1,250
```

**输出：**

```text
12A
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int age, weight; scanf("%d,%d", &age, &weight);
    int lower = age == 1 ? 200 : 300;
    char grade;
    if (weight <= lower) grade = 'B';
    else if (weight <= lower + 100) grade = 'A';
    else grade = 'S';
    printf("%d%d%c\n", age, weight / 100, grade);
    return 0;
}
```

## 讲解

1. 按年龄选B级上界：1龄200斤，2龄300斤。
2. 不超过上界是B，超过上界但不超过再加100是A，更重则S。
3. 例如1龄250斤为A，百位为2，把年龄1、百位2、等级A拼成12A。

## 知识点总结

- ?:：用年龄在200和300两个阈值之间选择。
- weight/100：取小于999重量的百位数字。
- %d%d%c：连续输出标签三部分，不插入空格。

## 易错点

- 200、300、400等边界要按小于等于划分。
- 输入两个整数之间是逗号，scanf需匹配它。
