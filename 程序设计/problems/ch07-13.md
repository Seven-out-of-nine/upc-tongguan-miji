## 题目

3.09 This指针及其用法【★】

构建一个类Stock，含字符数组stockcode\[\]及整型数据成员quan、双精度型数据成员price。构造函数含3个参数：字符数组na\[\]及q、p。当定义Stock的类对象时，将对象的第1个字符串参数赋值给数据成员stockcode，第2个和第3个参数分别赋给quan、price。未设置第2和第3个参数时，quan的值为1000，price的值为8.98。成员函数print没有形参，**需使用this指针，显示对象数据成员的内容**。假设类Stock第1个对象的三个参数分别为："600001"，3000和5.67，第2个对象的第1个数据成员的值为"600002"，第2个和第3个数据成员的值取默认值。要求编写程序分别显示这两个对象数据成员的值。

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Stock {
private:
    char stockcode[20];
    int quan;
    double price;
public:
    Stock(const char na[], int q = 1000, double p = 8.98) : quan(q), price(p) {
        strcpy(stockcode, na);
    }
    void print() const {
        cout << this->stockcode << '\n' << this->quan << '\n' << this->price << '\n';
    }
};
int main() {
    Stock st1("600001", 3000, 5.67);
    st1.print();
    Stock st2("600002");
    st2.print();
    return 0;
}
```

## 讲解

1. Stock保存代码、数量和单价；字符数组用strcpy复制代码，不能用等号整体赋值。
2. 第一个对象传入三个参数，保存600001、3000、5.67。
3. 第二个对象只给代码，所以数量和单价分别采用默认值1000和8.98。
4. print使用this->访问当前对象的成员，因此同一个方法能显示不同对象的数据。

## 知识点总结

- **this与指针访问成员**：非静态成员函数内，this是指向当前对象的指针；this->quan明确指当前对象的quan。p->member等价于(*p).member，箭头先通过指针找到对象再访问成员；当前形参也叫quan时可用this->quan区分。
- **默认实参**：Stock构造参数q=1000、p=8.98允许调用者省略右侧实参；Stock("600002")使用两个默认值。只能从最右边开始省略，不能留下中间空位；默认值负责补齐调用参数，不是函数重载。

## 易错点

- 题目明确要求print使用this指针，不能只获得相同输出就忽略这一语法要求。
