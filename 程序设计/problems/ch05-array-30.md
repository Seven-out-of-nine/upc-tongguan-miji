## 题目

【题目描述】

某石油公司计划建造一条由东向西的主输油管道。该管道要穿过一个有n口油井的油田。从每口油井都要有一条输油管道沿着最短路经（或南或北）与主管道相连。

如果给定n口油井的位置，即它们的x坐标（东西向）和y坐标（南北向），应如何确定主管道的最优位置，使得各油井到主管道之间的输油管道长度总和最小。至于管道怎么切割你就不用操心了，小明在2015年第十四届“挑战杯”山东省大学生课外学术科技作品获得特等奖第一名的作品《海底管道切割机器人》用来切陆地上的管道照样也是棒棒滴。

现在给定n口油井的位置，编程计算各油井到主管道之间的输油管道最小长度总和。

【输入】

有多行。第1行是一个整数n，表示油井的数量（1≤ n≤10000）。接下来n行是油井的位置，每行两个整数x和y（-10000≤x,y≤10000）。

【输出】

仅一行。一个整数，表示各油井到主管道之间的输油管道最小长度总和。

例如:

**输入：**

```text
5
1 2
2 2
1 3
3 -2
3 3
```

**输出：**

```text
6
```

### 题目与实现说明

- 原参考答案取四舍五入后的平均数，不能保证最优，本解使用中位数。

## 解答

```c
#include <stdio.h>
#include <stdlib.h>

int CompareInt(const void *left, const void *right)
{
    int a = *(const int *)left, b = *(const int *)right;
    return (a > b) - (a < b);
}

int main(void)
{
    int n, x, y[10000];
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) scanf("%d%d", &x, &y[i]);
    qsort(y, n, sizeof y[0], CompareInt);
    int median = y[n / 2];
    long long total = 0;
    for (int i = 0; i < n; ++i) {
        long long difference = (long long)y[i] - median;
        if (difference < 0) difference = -difference;
        total += difference;
    }
    printf("%lld\n", total);
    return 0;
}
```

## 讲解

1. 主管道东西向延伸，每口井只需南北连接，所以长度只取决于y坐标，x不影响答案。
2. 把所有y排序，选择中位数作为主管道的y坐标，再求每口井到它的绝对距离之和。
3. 原因是将最小和最大y配成一对，主管道位于它们之间时，这对的总距离最小；向内继续配对，所有区间共同包含中位数。
4. 例如y为0、0、100，取中位数0总长100；若误取平均数约33，总长133，反而更大。

## 知识点总结

- **指针保存地址与*读取对象**：指针变量保存对象所在的地址。比较函数的left、right不是整数本身；将left转为const int*后，*(const int*)left才读取该地址处的整数。这里的*是解引用，和乘法中的*由位置区分；读取对象前，地址及所指类型必须正确。
- **void*与通用元素地址**：void*可以接收不同对象类型的地址，但单凭它不知道对象的大小和类型，所以不能直接把它当整数读取。qsort把元素地址传为const void*，比较器再转回与数组元素一致的const int*，才能正确解引用。
- **sizeof取得对象占用字节数**：sizeof y[0]得到单个数组元素占用的字节数，sizeof y得到这里整个真实数组的字节数。这是存储容量信息，不是字符串内容长度；数组作为函数形参后不再保留完整数组大小，不能用sizeof形参代替传入的有效长度。
- **qsort排序与比较回调**：qsort(y,n,sizeof y[0],CompareInt)依次给出数组起始地址、元素个数、每个元素的字节数、比较函数。排序过程中库会调用CompareInt；比较结果小于0、等于0、大于0分别表示左元素应在前、等价、应在后。
- **中位数使绝对距离和最小**：把坐标排序后，将最小与最大配对；目标点处在这两个数之间时，这一对到目标的距离和最小。继续向内配对，所有允许区间都包含中位数，所以选择中位数可使绝对距离总和最小；偶数个点时中间两数之间任一点都可。

## 易错点

- 绝对距离和的最优位置是中位数，不是平均值。
- n为偶数时中间两值之间任一点都最优，取y[n/2]也正确。
