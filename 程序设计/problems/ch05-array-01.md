## 题目

**【题目描述】**

小明平日喜欢自己种一些东西，并以此为写程序和看电影之外的最大爱好。最近，小明种的一棵苹果树到了采摘的时候，但是由于小明身高的限制，有些苹果太高摘不到。于是小明借来了一个凳子，踩在上面可以摘到更多的苹果。

小明是一个懒于行动的人，他想在摘苹果之前知道自己能摘到多少苹果，如果实在太少（苹果树很茂盛，主要是由于身高原因），他宁可坐在树下等苹果自己掉下来砸到头上。

**【输入】**

有两行。第1行先是一个整数n（1≤n≤1000），表示苹果的个数，接着是n个整数，分别表示n个苹果的高度（不超过1000的正整数）。第2行是两个整数，分别表示小明的身高和凳子的高度。

**【输出】**

仅一行。一个整数m，表示小明最多能摘到m个苹果。

例如:

**输入：**

```text
10 180 151 152 193 168 255 278 303 211 217
177 40
```

**输出：**

```text
7
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, height[1000], person, stool, count = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) scanf("%d", &height[i]);
    scanf("%d%d", &person, &stool);
    for (int i = 0; i < n; ++i)
        if (height[i] <= person + stool) ++count;
    printf("%d\n", count);
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-01.c)

## 讲解

1. 先保存n个苹果高度；身高和凳高在这些数据之后输入，所以稍后再判断。
2. 能够达到的最大高度是person+stool；逐个比较苹果高度，不超过它就把count加1。
3. 例如身高177、凳高40，能够到217，样例中正好有7个苹果不高于217。

## 知识点总结

- int height[1000]：预留最多1000个整数，下标0到n-1分别对应输入的苹果。
- scanf("%d",&height[i])：&取得第i个数组元素的地址，让输入写入该位置。
- count初值0；++count在每次找到能摘的苹果时增加1。

## 易错点

- 等于可达高度的苹果也能摘，条件应写<=。
- 苹果高度输入完后才是身高、凳高，不要把第一行末尾两个苹果当作这两个高度。
