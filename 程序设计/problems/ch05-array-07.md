## 题目

**【题目描述】**

电视台举办“超级学生”才艺大赛，由于报名人数狂多，所以要先进行分组预赛。按规定，每10名学生为一个预赛小组，评委打出分数（0~100分），各小组第一名可以进入下一轮；如果有多名学生得分相同都是第一名，则可同时进入下一轮。

**【输入】**

有多行。按顺序给出一个小组10个人的最后得分（均为整数），每行一个得分。

**【输出】**

能够出线的学生序号（0~9），每行一个序号。

例如:

**输入：**

```text
98
98
99
97
95
99
90
94
93
92
```

**输出：**

```text
2
5
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int score[10], maximum = 0;
    for (int i = 0; i < 10; ++i) {
        scanf("%d", &score[i]);
        if (score[i] > maximum) maximum = score[i];
    }
    for (int i = 0; i < 10; ++i)
        if (score[i] == maximum) printf("%d\n", i);
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-07.c)

## 讲解

1. 先读完10个分数，并找到其中最高分maximum。
2. 第二次从头扫描数组，凡是等于最高分的学生都输出其下标。
3. 例如样例最高分99，出现在下标2和5，因此分别输出2、5两行；并列第一都不能漏。

## 知识点总结

- 固定长度数组score[10]：合法下标是0到9，恰与题目学生序号一致。
- 两次循环：第一次确定比较标准，第二次输出全部满足标准的位置。
- ==用于相等比较，=用于赋值，两者含义不同。

## 易错点

- 不能只在更新最大值时输出，这会把后来被超过的分数也输出。
- 每个序号占一行，不是把所有序号放在同一行。
