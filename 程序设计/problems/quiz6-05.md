## 题目

20206 夏边是逃课小王子

【题目描述】

夏边在大学里是出了名的“逃课小王子”，甭管是数学英语还是体育文艺，甭管是不是自己感兴趣的课程，夏边逢课必逃，这不，不分周末的暑期实习开始了，惯犯夏边又开始了他的逃课之旅，誓言捍卫“逢课必逃”、“逃课小王子”的江湖名号！带队的实习老师久闻夏边大名，每天都特别关照夏边，记录了他每周出现的日子，包括1~7七个编号，分别代表周一至周日。老师希望能从数据中分析出夏边习惯星期几逃课，不过，老师显然低估了夏边的天赋，最后分析得到的规律是“没有规律”。现在，你来编个程序分析一下吧！

【输入】

若干整数，不超过20个，以空格分隔，每个数都在1~7之间（含1和7）；

每个数代表星期几，7代表星期日，注意可能重复。

【输出】

若干行，每行一个整数，代表夏边曾经在星期几出现。结果为空则无输出。

例如:

**输入：**

```text
3 4 5 6 7 7
```

**输出：**

```text
1
2
```

### 题目与实现说明

- 原题输出段写“曾经在星期几出现”，但样例和原程序均输出“从未出现”的星期；本解采用样例所示规则，按1到7升序输出缺失星期。

## 解答

```c
#include <stdio.h>

int main(void) {
    int appeared[8] = {0}, day;
    while (scanf("%d", &day) == 1) appeared[day] = 1;
    for (int i = 1; i <= 7; ++i) if (!appeared[i]) printf("%d\n", i);
    return 0;
}
```

[下载完整源码](../solutions/quiz6-05.c)

## 讲解

1. 将读到的星期编号标记为曾到课，重复出现只需保持标记。
2. 从星期1到7检查标记，未标记的就是从未出现、应输出的星期。
3. 例如输入3、4、5、6、7、7，只缺1和2，因此依样例输出1和2。

## 知识点总结

- appeared[8]：使用1到7下标，0位置不用。
- appeared[day]=1：只记录存在性，不必统计次数。
- !appeared[i]：值为0意味着该星期没有输入记录。

## 易错点

- 原输出文字与样例相反，本解按样例输出未出现的星期。
- 重复出现某星期不会抵消已出现的事实。
