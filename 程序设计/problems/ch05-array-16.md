## 题目

【题目描述】

已知一个数组a存有n个整数，要求把下标从0到p的数组元素平移到数组的最后。

【输入】

有两行。第1行是两个整数n（n≤1000）和p（p≤n-1），分别表示数组元素个数和下标p。第2行是数组中的n个整数。

【输出】

仅一行。元素平移后的数组a，数据间以空格分隔。

例如:

**输入：**

```text
5 2
2 4 7 1 5
```

**输出：**

```text
1 5 2 4 7
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, p, value[1000];
    scanf("%d%d", &n, &p);
    for (int i = 0; i < n; ++i) scanf("%d", &value[i]);
    for (int k = 0; k < n; ++k) {
        if (k > 0) putchar(' ');
        printf("%d", value[(p + 1 + k) % n]);
    }
    putchar('\n');
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-16.c)

## 讲解

1. 下标0到p一共有p+1个元素，要把这一整段放到末尾。
2. 新顺序从原下标p+1开始，走到末尾后再从0继续，直到输出n个元素。
3. 例如p=2时，2 4 7这三个元素移到最后，得到1 5 2 4 7。

## 知识点总结

- **取余实现循环下标**：要从下标start开始循环访问n个元素，可依次取(start+k)%n，k为0到n-1。达到n时余数回到0，因此访问顺序能从末尾接回开头，且恰好经过每个位置一次。

## 易错点

- 移动的是下标0到p，包含p；起点是p+1，不是p。
- p=n-1时整段移动后顺序不变，不能访问value[n]。
