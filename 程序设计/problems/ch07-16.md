## 题目

3.12 类的组合的应用【★★】

定义一个线段类Line，实现根据起点坐标和终点坐标计算线段的长度。坐标点又包含X坐标值和Y坐标值，因此定义坐标点类Point，其对象作为线段类的数据成员。试编程实现根据坐标点计算线段长度的功能。

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Point {
private:
    double x; 
    double y; 
public:
    
    Point(double x_val = 0, double y_val = 0) : x(x_val), y(y_val) {}

    
    double getX() { return x; }
    
    double getY() { return y; }
};


class Line {
private:
    Point start; 
    Point end;   
public:
    
    Line(Point s, Point e) : start(s), end(e) {}

    
    double getLen() {
        double dx = end.getX() - start.getX();
        double dy = end.getY() - start.getY();
        return sqrt(dx * dx + dy * dy);
    }
};

int main()
{
	Point p1(1,1),p2(4,5);
	Line line1(p1,p2);
	Line line2(line1);
	cout<<"The length of the line1 is:"<<line1.getLen()<<endl;
	cout<<"The length of the line2 is:"<<line2.getLen()<<endl;
	return 0;
}
```

## 讲解

1. Point负责保存一个点的横纵坐标，Line把两个Point对象作为成员保存。
2. 求线段长度时，先计算横坐标差dx与纵坐标差dy，再用sqrt(dx*dx+dy*dy)。
3. (1,1)到(4,5)的差是3与4，因此长度为5。
4. Line line2(line1)复制了起点和终点，所以两条线段长度相同。

## 知识点总结

- **以对象为成员的类组合**：Line把Point start、Point end作为自己的成员，表示一条线段拥有两个点。构造Line时必须先构造这两个Point成员，再执行Line构造函数体；初始化列表start(s),end(e)指定各自初始值，属于拥有关系，不是继承的种类关系。
- **拷贝构造与逐成员复制**：Line line2(line1)用已有对象初始化一个新对象，这是拷贝构造；它不同于对象创建之后的赋值。没有自定义相应特殊成员且可逐成员复制时，编译器生成的拷贝构造会复制各个成员，因此两条线初始端点相同；若类手工持有动态资源，不能据此假定浅复制总是正确。

## 易错点

- 这是“线段有两个点”的组合关系，不需要让Line继承Point。
