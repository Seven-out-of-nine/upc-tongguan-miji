## 题目

描述

编程实现简单的计算器功能来计算两个整数的算术，要求用户按如下格式从键盘输入算式：

操作数1（空格）运算符（空格）操作数2

计算并输出表达式的值，其中算术运算符包括：加减乘除。（要求除法结果保留3位小数且不考虑除数为零）

输入

操作数1（空格）运算符（空格）操作数2

输出

操作数1运算符操作数2=？

例如:

**输入：**

```text
1 + 1
```

**输出：**

```text
1+1=2
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long a, b;
    char op;
    scanf("%lld %c %lld", &a, &op, &b);
    switch (op) {
        case '+': printf("%lld+%lld=%lld\n", a, b, a + b); break;
        case '-': printf("%lld-%lld=%lld\n", a, b, a - b); break;
        case '*': printf("%lld*%lld=%lld\n", a, b, a * b); break;
        case '/': printf("%lld/%lld=%.3f\n", a, b, (double)a / b); break;
    }
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-19.c)

## 讲解

1. 用两个整数变量接收操作数，用字符op接收+、-、*、/。
2. switch按照运算符选择计算；加减乘仍输出整数，除法先转换成double再计算。
3. 例如输入7 / 2，实数除法得到3.5，输出7/2=3.500；若不转换会先得到整数3。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 只在除法结果上保留3位小数，加减乘不需要补.000。
- 原题已说明不考虑除数为0，输入运算符也按四种合法运算处理。
