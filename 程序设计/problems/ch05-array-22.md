## 题目

【题目描述】

幼儿园的老师每天都会教小班的孩子们学习认识100以内的数字，一学期结束了，老师出了一道题想看看孩子们认识数字的效果。老师给出了多张数字卡片，想让孩子们自己找出其中的重复数字，并按给出的顺序排好，最后说出数字是几，如果没有重复数字，孩子们要说出“Not Found”。请你编程实现孩子们寻找数字的过程吧！

【输入】

仅一行。先是一个正整数n（≤100），表示老师给出了n张数字卡片，接着是n个整数（不超过100的正整数），分别表示n张卡片上的数字，其间以空格分隔。

【输出】

仅一行。如果存在重复的数字则依次输出，数字之间用空格间隔，如果不存在重复的数字，则输出“Not Found”。

例如:

**输入：**

```text
7 5 4 3 2 1 2 4
```

**输出：**

```text
4 2
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, value[100], count[101] = {0}, printed = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) { scanf("%d", &value[i]); ++count[value[i]]; }
    for (int i = 0; i < n; ++i) {
        int x = value[i];
        if (count[x] > 1) {
            if (printed) putchar(' ');
            printf("%d", x); printed = 1; count[x] = 0;
        }
    }
    if (!printed) printf("Not Found");
    putchar('\n');
    return 0;
}
```

## 讲解

1. 先读入卡片数组，并用count[x]统计数字x一共出现几次。
2. 再按原卡片顺序扫描，第一次遇到出现次数超过1的数字时输出它。
3. 输出后把count[x]设0，表示已经输出，之后遇到相同数字便不再输出。
4. 例如5 4 3 2 1 2 4中，4先于2首次出现，所以输出4 2，而不是2 4。

## 知识点总结

- **用计数数组统计频次**：数值范围小且非负时，可用数字本身作下标，让count[x]保存x的出现次数，每读到一次就加1。先统计完整频次，再按原序检查并把已输出值的次数清零，可在保留首次出现顺序的同时只输出一次。
- **逻辑非!**：!把一个条件的真假取反：操作数为0时结果是1，非0时结果是0。本题if(!printed)表示“还没有输出过数字”。它是作用于一个操作数的逻辑非，与比较两个值是否不等的!=不同。

## 易错点

- 要按首次出现顺序，不是按从小到大顺序输出。
- 同一个重复数字只输出一次，不能每次遇到都输出。
