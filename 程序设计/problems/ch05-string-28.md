## 题目

【题目描述】

判断一个字符串是否可以由另一个字符串通过重排字符而得到。注意，此处区分字符大小写！

【输入】

仅一行，为两个字符串，字符串之间以一个空格分隔，每个字符串的长度不超过40。

【输出】

如果两个字符串由同一组字符组成（且每一个字符出现次数相同），则输出“YES”，否则输出“NO”。

例如:

**输入：**

```text
dare read
```

**输出：**

```text
YES
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char a[41], b[41]; int count[256] = {0}; scanf("%40s%40s", a, b);
    for (int i = 0; a[i]; ++i) ++count[(unsigned char)a[i]];
    for (int i = 0; b[i]; ++i) --count[(unsigned char)b[i]];
    int equal = 1;
    for (int i = 0; i < 256; ++i) if (count[i] != 0) equal = 0;
    puts(equal ? "YES" : "NO"); return 0;
}
```

[下载完整源码](../solutions/ch05-string-28.c)

## 讲解

1. 重排只改变顺序，不会改变任何字符的出现次数。
2. 对第一串每个字符计数加1，对第二串同一字符计数减1。
3. 例如aab与aba全部抵消，而aab与abb会留下a的差1和b的差-1，不能重排得到。

## 知识点总结

- count[256]：按字节值分别统计，大小写自然分开。
- ++和--：分别增加第一串数量、扣除第二串数量。
- 所有count为0：表示每个字符的次数完全一致。

## 易错点

- 仅判断两串包含同样的字符种类还不够，次数也要相等。
