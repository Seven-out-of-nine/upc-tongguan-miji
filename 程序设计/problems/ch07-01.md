## 题目

1.01 用C++实现日历功能【★】

用面向对象程序设计方法设计一个日期类，该类包括年、月、日数据，还有设置日期、显示日期的方法。

然后在main函数中调用相应函数从键盘读入日期到该日期类对象中，然后输出日期。

例如:

**样例 1**

**输入：**

```text
2017 5 1
```

**输出：**

```text
2017-5-1
```

**样例 2**

**输入：**

```text
2017 4 18
```

**输出：**

```text
2017-4-18
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Date {
private:
    int year, month, day;
public:
    void setDate(int y, int m, int d) {
        year = y; month = m; day = d;
    }
    void showDate() const {
        cout << year << '-' << month << '-' << day << '\n';
    }
};
int main() {
    int y, m, d;
    cin >> y >> m >> d;
    Date date;
    date.setDate(y, m, d);
    date.showDate();
    return 0;
}
```

[下载完整源码](../solutions/ch07-01.cpp)

## 讲解

1. 把同一个日期的年、月、日放进Date类，避免三个数据各自散落。
2. 输入后调用setDate，把输入值存到日期对象内部。
3. 调用showDate输出对象里的日期，例如2026 1 2输出2026-1-2。

## 知识点总结

- class定义类，类描述一类对象拥有哪些数据和操作。
- private中的成员只能由类内部直接访问，public方法可以从main调用。
- date.setDate(...)用对象名和点号调用该对象的方法。
- 成员函数末尾的const表示此方法不修改对象的数据。

## 易错点

- 按样例直接输出月日，不补成两位；类定义结束的大括号后需要分号。
