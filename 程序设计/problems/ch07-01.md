## 题目

1.01 用C++实现日历功能【★】

用面向对象程序设计方法设计一个日期类，该类包括年、月、日数据，还有设置日期、显示日期的方法。

然后在main函数中调用相应函数从键盘读入日期到该日期类对象中，然后输出日期。

例如:

**样例 1**

**输入：**

```text
2017 5 1
```

**输出：**

```text
2017-5-1
```

**样例 2**

**输入：**

```text
2017 4 18
```

**输出：**

```text
2017-4-18
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Date {
private:
    int year, month, day;
public:
    void setDate(int y, int m, int d) {
        year = y; month = m; day = d;
    }
    void showDate() const {
        cout << year << '-' << month << '-' << day << '\n';
    }
};
int main() {
    int y, m, d;
    cin >> y >> m >> d;
    Date date;
    date.setDate(y, m, d);
    date.showDate();
    return 0;
}
```

## 讲解

1. 把同一个日期的年、月、日放进Date类，避免三个数据各自散落。
2. 输入后调用setDate，把输入值存到日期对象内部。
3. 调用showDate输出对象里的日期，例如2026 1 2输出2026-1-2。

## 知识点总结

- **类、对象与成员函数**：class Date声明一个把数据和操作放在一起的类型；Date date创建这个类型的对象。对象各自保存year等非静态数据，date.setDate(...)用点号调用该对象的成员函数，函数里直接使用year指该对象自己的成员。类定义结束的右花括号后要写分号。
- **public与private封装**：private成员只允许本类成员函数及获授权的友元直接访问，同类成员函数也可访问另一同类对象的private成员；main不能直接读写它。public成员构成外部可调用接口，所以本题用setDate写入、showDate显示，而不让main直接改year。
- **const成员函数**：void showDate() const中参数列表后的const修饰当前对象，表示这个成员函数不通过它修改普通数据成员。只读显示和get方法适合这样声明；const对象或const引用只能调用相应的const成员函数。

## 易错点

- 按样例直接输出月日，不补成两位；类定义结束的大括号后需要分号。
