## 题目

**【题目描述】**

给定正整数n，输出一个有规律变化的n行n列的图形，具体格式参看输出样例。

**【输入】**

仅一行。一个正整数n（1&lt;n≤100），表示输出的图形有n行n列。

**【输出】**

n行n列有规律变化的图形。

例如:

**输入：**

```text
5↵
```

**输出：**

```text
10000
11000
11100
11110
11111
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    for (int row = 0; row < n; ++row) {
        for (int col = 0; col < n; ++col)
            putchar(col <= row ? '1' : '0');
        putchar('\n');
    }
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-03.c)

## 讲解

1. 观察样例：第1行有1个1，第2行有2个1，其余位置都是0。
2. 下标从0开始时，列号col不大于行号row的位置输出1，否则输出0。
3. 例如n=3时三行分别是100、110、111；每行输出完再换行。

## 知识点总结

- **嵌套循环表示行与列**：外层循环选择当前行，内层循环从该行第0列扫描到最后一列；内层完成后才进入下一行。n行n列要执行n*n次内层输出，每行末尾的换行应放在内层循环外面。
- **条件运算符?:**：条件?值1:值2是一个会产生值的表达式：条件成立取值1，否则取值2。本题col<=row ? '1' : '0'根据位置选出要打印的字符，再交给putchar。

## 易错点

- 每行数字之间没有空格。
- 边界含对角线，应使用col<=row而不是col<row。
