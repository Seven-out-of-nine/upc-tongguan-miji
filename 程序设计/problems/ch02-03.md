## 题目

**描述**

小通已经开始学习程序设计了。他想做的第一件事情就是我做什么，计算机也做什么。小通会从键盘输入任意两个整数，希望计算机能把这两个整数原样输出到屏幕上。

**输入**

一行，两个整数。

**输出**

一行，两个整数，中间用空格分隔。

例如:

**输入：**

```text
-9 10
```

**输出：**

```text
-9 10
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

[下载完整源码](../solutions/ch02-03.c)

## 讲解

1. 准备两个整数变量 a、b，分别保存输入的两个数。
2. scanf 按输入顺序把第一个数放进 a，第二个数放进 b。
3. 例如输入 -9 10 后，输出 a、一个空格、b，就得到 -9 10。

## 知识点总结

- int：整数类型，可保存本题的正整数、0和负整数。
- scanf("%d %d", &a, &b)：%d 读取整数，&a 表示把结果写入 a 所在的位置。
- printf("%d %d", a, b)：按占位符顺序代入数值，两个 %d 之间的空格会输出。

## 易错点

- scanf 读变量时要写 &a；printf 输出变量时不写 &。
