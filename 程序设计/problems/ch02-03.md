## 题目

**描述**

小通已经开始学习程序设计了。他想做的第一件事情就是我做什么，计算机也做什么。小通会从键盘输入任意两个整数，希望计算机能把这两个整数原样输出到屏幕上。

**输入**

一行，两个整数。

**输出**

一行，两个整数，中间用空格分隔。

例如:

**输入：**

```text
-9 10
```

**输出：**

```text
-9 10
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

[下载完整源码](../solutions/ch02-03.c)

## 讲解

1. 准备两个整数变量 a、b，分别保存输入的两个数。
2. scanf 按输入顺序把第一个数放进 a，第二个数放进 b。
3. 例如输入 -9 10 后，输出 a、一个空格、b，就得到 -9 10。

## 知识点总结

- **变量声明与赋值**：int a, b;声明两个有名字的变量，通过变量名可读取当前值。赋值写作a=表达式;，先计算右侧再存入左侧变量；scanf成功读取也会更新指定变量。
- **int整数类型**：int保存整数，可表示负整数、0和正整数，不保存小数。它的范围有限，不是任意精度整数；选择类型要结合输入与计算结果的范围。
- **格式占位符与参数对应**：格式字符串里的%d是int的十进制占位符。printf("%d %d",a,b)中两个%d依次使用a、b，固定空格原样输出；占位符的类型、数量和参数必须对应。
- **scanf格式化输入**：scanf("%d %d",&a,&b)按格式读取两个整数并保存到指定位置。整数转换会跳过分隔空白，因此两个整数通常可以用空格或换行分隔。
- **取地址运算符&**：表达式&a取得变量a的地址。scanf需要知道把输入放到哪里，所以读取普通整数变量时传&a；printf只读取值，传a本身，不加&。地址的更多用途将在指针部分学习。

## 易错点

- scanf 读变量时要写 &a；printf 输出变量时不写 &。
