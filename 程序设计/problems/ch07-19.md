## 题目

4.02 利用派生类实现求图形面积【★】

定义一个基类Shape，在此基础上派生出Rectangle和Circle，二者都有getArea()函数计算对象的面积。使用Rectangle类创建一个派生类Square。

例如:

**输出：**

```text
The area of the Circle is 78.5
The area of the Rectangle is 24
The area of the Square is 25
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

#define PI 3.14159
class Shape {
public:
    virtual ~Shape() = default;
    virtual void getArea() = 0;
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}

    void getArea() override {
        double area = PI * radius * radius;
        
        cout << fixed << setprecision(1) << "The area of the Circle is " << area << endl;
        
        cout.unsetf(ios::fixed);
        cout.precision(6);
    }
};

class Rectangle : public Shape {
protected:
    double width;
    double height;
public:
    Rectangle(double w, double h) : width(w), height(h) {}

    void getArea() override {
        double area = width * height;
        cout << "The area of the Rectangle is " << area << endl;
    }
};

class Square : public Rectangle {
public:
    Square(double side) : Rectangle(side, side) {}

    void getArea() override {
        double area = width * height;
        cout << "The area of the Square is " << area << endl;
    }
};

int main()
{
    Circle c(5);
    c.getArea();
    Rectangle r(4,6);
    r.getArea();
    Square s(5);
    s.getArea();
    return 0;
}
```

## 讲解

1. Shape抽象出所有图形共有的求面积接口。
2. Circle使用圆面积公式，Rectangle使用长乘高；Square再从Rectangle派生，让宽高都等于边长。
3. 半径5的圆面积按1位小数输出78.5；4*6的矩形为24，边长5的正方形为25。
4. 各派生类自己的getArea负责与自身图形匹配的公式和输出标签。

## 知识点总结

- virtual允许派生类替换同名方法；override让编译器检查确实重写了虚函数。
- =0把方法声明为纯虚函数，含纯虚函数的Shape不能直接建立对象。
- Square继承Rectangle属于多层继承，初始化时把边长传两次。
- fixed配合setprecision(1)指定小数点后一位，用完后恢复默认输出精度。

## 易错点

- 圆的1位小数设置会持续影响后续输出，要恢复，否则矩形会变成24.0。
