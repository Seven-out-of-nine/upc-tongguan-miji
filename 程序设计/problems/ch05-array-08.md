## 题目

**【题目描述】**

青年歌手大奖赛中，评委会给参赛选手打分（0~100分）。选手得分规则为去掉一个最高分和一个最低分，然后计算平均得分，请编程输出某选手的得分。

**【输入】**

有两行。第1行是一个整数n（2&lt;n&lt;100），表示评委的人数。第2行是n个整数，分别表示n个评委的打分。

**【输出】**

仅一行。选手的得分，结果保留两位小数。

例如:

**输入：**

```text
4 100 99 98 97
```

**输出：**

```text
98.50
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, score, sum = 0, minimum = 100, maximum = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &score);
        sum += score;
        if (score < minimum) minimum = score;
        if (score > maximum) maximum = score;
    }
    printf("%.2f\n", (sum - maximum - minimum) / (n - 2.0));
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-08.c)

## 讲解

1. 累计所有分数sum，同时记录最高分与最低分。
2. 从sum减去一个最高分和一个最低分，再除以剩余人数n-2。
3. 例如100、99、98、97总分394，减去100与97后197，除以2得到98.50。

## 知识点总结

- sum+=score：读一个分数就把它加入总和。
- n-2.0包含浮点常量，使除法保留小数部分。
- %.2f：按两位小数输出最终平均分。

## 易错点

- 相同最高分或最低分可能出现多次，但题目只去掉各一个。
- n>2保证分母大于0，不能误除以n。
