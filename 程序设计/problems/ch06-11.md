## 题目

F11.01 统计字符【★】 【函数+字符数组+指针】

【题目描述】
请编写函数 Fun ，它的功能是：统计形参 s 所指字符串中数字字符出现的次数，并存放在形参t中。

【输入】
仅一行。一个字符串，长度小于80。
【输出】
一个整数，表示数字字符的出现次数。

**注意：本题只需提交Fun函数即可**

预设代码

前置代码

```text
#include <stdio.h>
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{  
      char  s[80];
      int t;
      fgets(s,sizeof(s),stdin);
      Fun(s,&t);
      printf("%d\n",t);
      return 0;
}
```

例如:

**输入：**

```text
abcdef35adgh3kjsdf7
```

**输出：**

```text
4
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char s[], int *t) {
    *t = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= '0' && s[i] <= '9') (*t)++;
    }
}
```

```c
#include <stdio.h>
#include <string.h>

void Fun(char s[], int *t) {
    *t = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= '0' && s[i] <= '9') (*t)++;
    }
}

int main(void) {
    char s[81];
    int t;
    fgets(s, sizeof s, stdin);
    Fun(s, &t);
    printf("%d\n", t);
    return 0;
}
```

## 讲解

1. 先把 *t 清零，表示还没发现数字。
2. 从左向右检查每个字符，只要位于 '0' 到 '9' 之间就让计数增加 1。
3. 例如 a1b20 中有 1、2、0 三个数字字符，因此返回的计数是 3。

## 知识点总结

- **指针输出参数写回调用者**：main调用Fun(s,&t)把变量t的地址交给函数，形参int *t保存该地址；函数里的*t=0和(*t)++修改的是main的那个整数。普通int参数接收的是值的副本，直接修改副本不会写回；多个指针参数可分别写回多个结果。

## 易错点

- *t++ 会移动指针，和 (*t)++ 的含义不同。
