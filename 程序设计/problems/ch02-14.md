## 题目

**描述**

printf和scanf是两个重要的函数，我们要熟练掌握。

**输入**

仅一行。整型变量x的值。

**输出**

仅一行。x对应的十进制、八进制、十六进制形式。

例如:

**样例 1**

**输入：**

```text
-1
```

**输出：**

```text
x=-1,x=37777777777,x=ffffffff
```

**样例 2**

**输入：**

```text
0
```

**输出：**

```text
x=0,x=0,x=0
```

### 题目与实现说明

- 负数样例按32位 unsigned int 展示；例如-1转为4294967295后输出八/十六进制。常见评测环境和本项目校验环境均为32位int。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int x;
    scanf("%d", &x);
    unsigned int u = (unsigned int)x;
    printf("x=%d,x=%o,x=%x\n", x, u, u);
    return 0;
}
```

[下载完整源码](../solutions/ch02-14.c)

## 讲解

1. 只需读入一个整数 x，不需要手工做除8或除16的进制转换。
2. 同一个数分别使用%d、%o、%x输出，就能得到十进制、八进制、十六进制写法。
3. 例如输入10，三种写法是10、12、a，输出 x=10,x=12,x=a。

## 知识点总结

- **八进制和十六进制输出**：printf的%o、%x把unsigned int显示成八进制和小写十六进制，%d显示int的有符号十进制。输出表示改变，不必为每种进制另存一份，也不必手工拼数位。
- **显式类型转换**：(类型)表达式显式转换值，如(unsigned int)x、(double)a。转成无符号整数时按目标范围取模，负数的八、十六进制不是简单加负号；整数转浮点会改变后续除法，浮点转整数去掉小数且要求结果可表示。

## 易错点

- 十六进制 %x 输出小写字母，不要换成大写的 %X。
- 负数的八、十六进制样例体现的是无符号转换结果，不是在数字前简单加负号。
