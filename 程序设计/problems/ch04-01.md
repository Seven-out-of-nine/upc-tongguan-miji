## 题目

**描述**

输入两个正整数m和n，求它们的最大公约数和最小公倍数。

**输入**

两个正整数

**输出**

它们的最大公约数和最小公倍数

提示：你的算法是否可能溢出？

例如:

**输入：**

```text
14 21
```

**输出：**

```text
the greatest common divisor is 7
the least common multiple is 42
```

### 题目与实现说明

## 解答

```c
#include <stdio.h>
int main(void) {
    long long m, n;
    scanf("%lld%lld", &m, &n);
    long long a = m, b = n;
    while (b != 0) {
        long long remainder = a % b;
        a = b;
        b = remainder;
    }
    long long gcd = a;
    long long lcm = (m / gcd) * n;
    printf("the greatest common divisor is %lld\n", gcd);
    printf("the least common multiple is %lld\n", lcm);
    return 0;
}
```

## 讲解

1. 先保留输入m、n，再用a、b计算最大公约数，以免循环改变原值后无法计算最小公倍数。
2. 反复用(a,b)替换为(b,a%b)，直到b为0，此时a就是最大公约数。
3. 例如14和21依次变为(21,14)、(14,7)、(7,0)，最大公约数为7。
4. 最小公倍数=m/gcd*n，样例为14/7*21=42；先除后乘降低中间溢出风险。

## 知识点总结

- **最大公约数与最小公倍数的关系**：对正整数m、n，最小公倍数等于m/gcd(m,n)*n。求公约数时循环会改写工作变量，所以保留原m、n；先除公约数再乘另一个数，可降低中间乘积溢出的风险，但最终结果仍须在类型范围内。

## 易错点

- 不能直接用已经被循环改过的m、n计算最小公倍数。
- 先除后乘只能降低中间溢出风险，最后结果仍须能由long long表示。
