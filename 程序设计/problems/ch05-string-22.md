## 题目

【题目描述】

小明参加学校每年一度的大学生科技节活动的游戏，这次遇到的题目是字符接龙。主持人拿出2张卡片，每张卡片上都有一个顺序字符串，即字符串是按ASCII码顺序编排的。现在要求小明把2个字符串连接成一个字符串，而且连接以后的字符串内容还是按ASCII码顺序排列的。（假设每张卡片上的字符串都不包含空格）。

【输入】

有两行。分别为两个不包含空格的字符串，每个字符串长度不超过1000。

【输出】

连接后的顺序字符串（按ASCII码顺序排列）。

例如:

**输入：**

```text
acd
br
```

**输出：**

```text
abcdr
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char a[1001], b[1001]; scanf("%1000s%1000s", a, b);
    int i = 0, j = 0;
    while (a[i] && b[j]) {
        if ((unsigned char)a[i] <= (unsigned char)b[j]) putchar(a[i++]);
        else putchar(b[j++]);
    }
    while (a[i]) putchar(a[i++]);
    while (b[j]) putchar(b[j++]);
    putchar('\n'); return 0;
}
```

## 讲解

1. 两串已经各自有序，只需比较尚未输出的两个首字符。
2. 输出较小者并让对应下标前进；一串耗尽后复制另一串剩余部分。
3. 例如acd与br先比较a/b输出a，再比较c/b输出b，最后得到abcdr。

## 知识点总结

- i和j：分别记录两个串的扫描位置。
- <=：相等字符也各自保留，题目没有要求去重。
- while(a[i])：以结束符为界处理剩余字符。

## 易错点

- 不能简单先输出整个第一串再输出第二串，否则整体可能无序。
