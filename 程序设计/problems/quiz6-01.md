## 题目

20201 夏边的菜园保卫战

【题目描述】

夏边迷上了一款“种菜”小游戏，在这个虚拟的菜地里可以随心所欲的种植自己喜爱的花花草草、水果蔬菜。夏边每天都定时浇水施肥，看着自己的植物一天天长大，在这个过程中他收获了难以言喻的满足感，他有个心愿，让自己的小小菜园一天天成长为小庄园~~然而好景不长，游戏中也有“敌人”——其他的玩家。这些敌人可不会等着水果蔬菜成熟了被夏边采摘走，经常会提前下手，把菜园糟蹋的一片狼藉。为了尽量减少损失，夏边编了个程序分析他的敌人们经常在哪些时间出现。游戏系统日志里不会记录敌人出现的确切时刻，但是会告诉玩家“XX小时XX分钟之前遭到XXX玩家的入侵”，程序需要根据当前的时刻与系统记录的时间差计算敌人出现的确切时刻。

【输入】

输入数据有一行，格式为“hh:mm hh:mm”（hh表示小时，mm表示分钟，两个时刻之间有一个空格）。

第一对hh，mm为两位整数，表示当前时刻；

第二对hh，mm为两位整数，表示系统记录的时间差；

【输出】

仅一行，格式为“hh:mm”，表示敌人出现的确切时刻。

注意：采用24小时制。若小时为个位数，前面不需要补零。例如：“2:01”，另外没有24:00

例如:

**输入：**

```text
18:55 11:00
```

**输出：**

```text
7:55
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int h, m, dh, dm; scanf("%d:%d %d:%d", &h, &m, &dh, &dm);
    int minutes = ((h * 60 + m - dh * 60 - dm) % 1440 + 1440) % 1440;
    printf("%d:%02d\n", minutes / 60, minutes % 60);
    return 0;
}
```

## 讲解

1. 把当前时刻和经过时长都换算为总分钟，当前时刻减去时长。
2. 一天有1440分钟，把差值归到0到1439区间，处理跨越午夜。
3. 例如0:10减0:20得到-10分钟，回到前一天23:50。
4. 总分钟除60得到小时，模60得到分钟，小时不补零、分钟补两位。

## 知识点总结

- %1440：把多天跨度归到一天之内。
- 加1440再取模：修正C负数取余可能为负的结果。
- %d:%02d：小时自然宽度，分钟至少两位并补0。

## 易错点

- 00:00应输出0:00，而不是24:00。
- 仅直接相减小时和分钟容易漏掉借位和跨日。
