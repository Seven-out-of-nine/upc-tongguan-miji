## 题目

F11.09 统计子串【★★★】【函数+字符数组+指针】

【题目描述】

编写函数Fun，其功能是：统计指定子字符串substr在字符串str中出现的次数。

【输入】

有两行。第1行是字符串str（长度不超过1000）。第2行是子串substr（长度不大于原串的长度）。

【输出】

仅一行。一个整数，表示子串在原字符串中出现的次数。

预设代码

前置代码

```text
#include <stdio.h>
#include <string.h>
#define N 1000
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    char str[N + 5], substr1[N + 5];
    int count1;
    fgets(str,N+6,stdin);
    fgets(substr1,N+6,stdin);
    Fun(str, substr1, &count1);
    printf("%d\n", count1);
    return 0;
}
```

例如:

**输入：**

```text
aaas lkaaas
as
```

**输出：**

```text
2
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char str[], char sub[], int *count) {
    str[strcspn(str, "\r\n")] = '\0';
    sub[strcspn(sub, "\r\n")] = '\0';
    int n = (int)strlen(str), m = (int)strlen(sub);
    *count = 0;
    if (m == 0) return;
    for (int i = 0; i + m <= n; i++) {
        int j = 0;
        while (j < m && str[i+j] == sub[j]) j++;
        if (j == m) (*count)++;
    }
}
```

    str[strcspn(str, "\r\n")] = '\0';

        if (j == m) (*count)++;
    }
}

int main(void) {
    char s[1002], sub[1002];
    int count;
    fgets(s, sizeof s, stdin);
    fgets(sub, sizeof sub, stdin);
    Fun(s, sub, &count);
    printf("%d\n", count);
    return 0;
}

## 讲解

1. 去掉两个输入行的换行，分别计算原串长度 n 和子串长度 m。
2. 枚举每个可能起点 i，只尝试能放得下完整子串的位置，即 i+m<=n。
3. 从子串下标 j=0 开始比较，直到出现不同字符或 j==m。
4. 若 j==m，说明该起点完整匹配，次数加 1；下一个起点仍只右移一格。
5. 例如 aaaa 中查找 aa，起点 0、1、2 都成立，共 3 次。

## 知识点总结

- 双层比较用 str[i+j] 对应 sub[j]，i 是起点，j 是偏移。
- 用指针参数 count 把统计值写回 main。
- 长度为 m 的子串从 i 开始时，最后下标为 i+m-1，不能超过 n-1。
- 空子串单独处理，避免把每个位置都计为匹配。

## 易错点

- 原预设代码用 N+6 读入 N+5 的数组存在越界风险；完整练习版改为 sizeof 数组。
