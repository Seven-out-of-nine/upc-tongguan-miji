## 题目

20102 胡恼的大胃王比赛

胡恼每逢年底就会碰到“饥荒”，没有办法，他是宿舍老大，老大就是小弟们用来欺负的嘛！平时小弟们经常忽悠老大请客吃鸡腿，老大有求必应，生活费能撑到年底已经是万幸了。如今，他已经饿了三天了，宿舍的小弟都不敢洗脚了，老大会直勾勾的盯着，露出森森白齿，吞咽着口水，念念有词：“猪蹄子……猪蹄子……”。怎么办？正好学校旨在拯救“灾民”的年度“大胃王”比赛开始了！规则很简单：吃完指定数量的汉堡，谁吃的快谁就赢！比赛分成两组，中午是“眼冒金星组”（Level1），给定3个汉堡，记录开始和完成时间；晚上是“地狱饿鬼组”（Level2），给定6个汉堡，记录开始和完成时间。那么，胡恼要参加哪场比赛？当然是全！都！参！加！现在数据统计出来了，请你算一下他哪一场比赛的成绩最好？（比赛成绩为平均吃1个汉堡的耗时，单位为分钟，小数点后保留2位）

注：时间采用24小时制，测试用例中的时间都在一天之内。

【输入】

共两行，分别代表参加Level1组和Level2组的开始时间和完成时间，格式见示例输入。

【输出】

成绩最好的那一组的组名（Level1或Level2，如果成绩相等，输出“Equal”），以及比赛成绩，以空格分隔。

例如:

**输入：**

```text
11:00 11:10
17:30 17:45
```

**输出：**

```text
Level2 2.50
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int h1, m1, h2, m2, h3, m3, h4, m4;
    scanf("%d:%d %d:%d", &h1, &m1, &h2, &m2);
    scanf("%d:%d %d:%d", &h3, &m3, &h4, &m4);
    int first = (h2 - h1) * 60 + m2 - m1;
    int second = (h4 - h3) * 60 + m4 - m3;
    if (2 * first < second) printf("Level1 %.2f\n", first / 3.0);
    else if (2 * first > second) printf("Level2 %.2f\n", second / 6.0);
    else printf("Equal %.2f\n", first / 3.0);
    return 0;
}
```

## 讲解

1. 把开始与结束时刻统一换算为分钟差。
2. Level1吃3个，平均用时first/3；Level2吃6个，平均用时second/6。
3. 比较2×first与second即可准确比较两组平均成绩，较小者更好。
4. 例如两场分别用10、15分钟，平均3.33和2.50分钟，输出Level2 2.50。

## 知识点总结

- scanf中的冒号：匹配输入时刻中的字面分隔符。
- 小时差×60+分钟差：可以自动处理分钟借位。
- 3.0和6.0：保证输出成绩用浮点除法。
- 交叉相乘：避免直接比较浮点数是否相等。

## 易错点

- 不能只比较总耗时，两场汉堡数量不同。
- 本题保证同一天，不需要跨日加24小时。
