## 题目

【题目描述】

任意输入一个自然数，输出该自然数的各位数字组成的最大数。例如，输入1593 ，则输出为9531。

【输入】

仅一行。自然数 n（0&lt;n≤10<sup>18</sup>）。

【输出】

仅一行。各位数字组成的最大数。

例如:

**输入：**

```text
1593
```

**输出：**

```text
9531
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    unsigned long long n;
    int count[10] = {0};
    scanf("%llu", &n);
    do { ++count[n % 10]; n /= 10; } while (n > 0);
    for (int digit = 9; digit >= 0; --digit)
        for (int i = 0; i < count[digit]; ++i) putchar('0' + digit);
    putchar('\n');
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-26.c)

## 讲解

1. 取余10得到一个个位数字，除以10去掉它；不断重复，统计0到9各有多少个。
2. 想组成最大数，越大的数字越应该放在前面，所以按9到0输出各数字的全部次数。
3. 例如1593中1、5、9、3各一次，降序输出9531；1002输出2100，零也必须保留。

## 知识点总结

- unsigned long long与%llu：可以读入题目最大值10¹⁸，不能使用32位int。
- count[n%10]：余数一定在0到9之间，适合直接作为计数数组下标。
- do...while：先处理一次再判断，即使扩展到输入0也能记录一个0。

## 易错点

- 不要把重排后的数再放入int，否则大数会溢出；直接打印数位即可。
- 数字0也属于原数位，不能丢弃尾部的0。
