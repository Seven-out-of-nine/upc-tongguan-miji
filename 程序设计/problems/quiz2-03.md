## 题目

3001 青岛大虾

Description

2015年国庆佳节，普天同庆之时，青岛大虾扬名海内外，38元一只，席卷全中国。胶南某楼盘在开盘时，为了吸引顾客的眼球，直接标出均价为170只青岛大虾/平米的价格。那么，现在对于每套住房，需要你根据给出的每平米的价格和住房的建筑面积计算出住房的总价。楼盘的老总李老板非常大方，总价中百元以下的零头就直接不收了。

Input

输入包含多组数据。每组包含两个数据，占一行。第一个数是一个浮点数area(30&lt;=area&lt;=800)，表示每套住房的建筑面积，第二个数是一个整数N(100&lt;= N &lt;=1000)，表示每套住房每平米的价格值多少只大虾，大虾38元/只。

Output

对应每组输入数据，输出购买该住房需要实际花费的总价（单位：元）

例如:

**输入：**

```text
90.12 170
120 130
204.51 200
```

**输出：**

```text
582100
592800
1554200
```

## 解答

```c
#include <stdio.h>

int main(void) {
    double area; int n;
    while (scanf("%lf%d", &area, &n) == 2) {
        int hundreds = (int)(area * n * 38 / 100 + 1e-9);
        printf("%d\n", hundreds * 100);
    }
    return 0;
}
```

[下载完整源码](../solutions/quiz2-03.c)

## 讲解

1. 每平方米价格为大虾数量n乘38元，再乘建筑面积得到总价。
2. 老板免掉不足100元的部分，所以先除以100向下取整，再乘回100。
3. 例如90.12×170×38=582175.2，留下5821个整百元，实际付款582100。

## 知识点总结

- double和%lf：面积可能有小数，必须用浮点类型读取。
- (int)：对本题正数截去小数部分，得到完整的百元个数。
- 1e-9：避免本应整百的值因浮点表示误差略小于整数。
- int：最大总价800×1000×38为30400000，可用int保存。

## 易错点

- 不是去掉小数部分就结束，还必须免除十位和个位。
- 需每组读两个数，处理至输入结束。
