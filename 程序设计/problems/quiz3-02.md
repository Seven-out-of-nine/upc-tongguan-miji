## 题目

3022 优良学风班

Description

优良学风班是指全班学生学习效果显著：各门必修课程考试及格率大于等于95%，优良率大于等于60%。优良指的是分数大于等于80分。

Input

第一行一个整数n，接下来一行n个百分制的整数成绩。

Output

如果符合条件输出Yes，否则输出No。

Hint

精度不超过0.000001

例如:

**样例 1**

**输入：**

```text
10
91 92 97 85 72 94 82 62 84 84
```

**输出：**

```text
Yes
```

**样例 2**

**输入：**

```text
20
71 88 83 72 91 69 87 59 90 90 99 100 62 93 60 90 75 75 83 80
```

**输出：**

```text
Yes
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int n, pass = 0, excellent = 0; scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        int score; scanf("%d", &score);
        if (score >= 60) ++pass;
        if (score >= 80) ++excellent;
    }
    puts(100LL * pass >= 95LL * n && 100LL * excellent >= 60LL * n ? "Yes" : "No");
    return 0;
}
```

## 讲解

1. 每个成绩达到60就增加及格人数，达到80再增加优良人数。
2. 及格率至少95%且优良率至少60%才输出Yes。
3. 例如20人中19人及格、12人优良，正好达到95%和60%，应通过。

## 知识点总结

- 两个独立if：优良学生同时也属于及格学生。
- 100LL*pass>=95LL*n：交叉相乘比较比例，避免整数除法截断。
- LL后缀：让乘法用long long计算，减少乘法溢出风险。

## 易错点

- 两项条件都要满足。
- 60分计及格，80分计优良，边界都包含。
