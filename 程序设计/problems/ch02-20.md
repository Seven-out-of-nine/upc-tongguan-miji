# \[4.07\]鸡兔同笼★★

[学习首页](../README.md) · [本章目录](../chapters/ch02/README.md) · [知识点索引](../知识点索引.md)

来源：【测验】第2章 程序设计基础.html，第20题。

## 题目

**描述**

已知笼中有头h个，有脚f条，问笼中鸡兔各有多少只？

**输入**

头和脚的数目。

**输出**

兔子和鸡的数目。

例如:

**输入：**

```text
10 20
```

**输出：**

```text
rabbit=0,chicken=10
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long heads, feet;
    scanf("%lld %lld", &heads, &feet);
    long long rabbits = (feet - 2 * heads) / 2;
    long long chickens = heads - rabbits;
    printf("rabbit=%lld,chicken=%lld\n", rabbits, chickens);
    return 0;
}
```

[下载完整源码](../solutions/ch02-20.c)

## 讲解

1. 先假设所有动物都是鸡，那么总脚数是2*heads。
2. 真实脚数比这个数多出的部分，来自每只兔子比鸡多的2只脚，因此兔数=(feet-2*heads)/2。
3. 例如10个头、20只脚，多出的脚是0，所以兔子0只，鸡10只。

## 知识点总结

- 变量建模：heads和feet保存题目给的数量，rabbits、chickens保存要计算的答案。
- 算式中的括号：(feet-2*heads)/2必须先做减法，再除以2。
- 格式化输出：两个数量前的rabbit=、chicken=和中间逗号必须按样例写。

## 易错点

- 兔子和鸡的输出顺序不能交换。
- 本解按数据确实能组成鸡兔数量的有效输入处理，不自行设计错误提示。
