## 题目

3002 具有abcd=(ab+cd)^2性质的四位数

Description

求具有abcd=(ab+cd)^2性质的四位数。比如，3025这个数具有一种独特的性质：将它平分为二段，即30和25，使之相加后求平方，即(30+25)^2，恰好等于3025本身。根据输入求所有具有该性质的四位数abcd。

Input

输入数据为K1、K2，表示所求四位数的数据范围在K1和K2之间。(包含K1和K2，且K1和K2都在1000到9999之间，K2&gt;K1)

Output

输出所有满足题目要求的四位数，每个输出数据后面换行（\\n）。

例如:

**输入：**

```text
2000 3500
```

**输出：**

```text
2025
3025
```

## 解答

```c
#include <stdio.h>

int main(void) {
    int lo, hi; scanf("%d%d", &lo, &hi);
    for (int x = lo; x <= hi; ++x) {
        int left = x / 100, right = x % 100;
        int sum = left + right;
        if (sum * sum == x) printf("%d\n", x);
    }
    return 0;
}
```

[下载完整源码](../solutions/quiz2-04.c)

## 讲解

1. 遍历闭区间K1到K2中的每个四位数。
2. 除以100得到前两位，模100得到后两位，再判断两段和的平方是否等于原数。
3. 例如3025拆成30和25，55²=3025，应该输出。

## 知识点总结

- x/100：整数除法保留前两位。
- x%100：取最后两位对应的数值。
- sum*sum：C中用乘法求平方，^表示按位异或。
- x<=hi：上界本身也必须检查。

## 易错点

- 不能写(sum)^2来求平方。
- 某两位是00时，数值就是0，不影响计算。
