## 题目

**8.11 矩阵最大值【★】**

**【题目描述】**

有一个m行n列的矩阵，编程求出其中值最大的那个元素，以及其所在的行号和列号。（如果最大数有多个，则显示第一个出现的数据的信息）。

**【输入】**

有多行。第1行是两个整数，m（m≤10）和n（n≤10），分别表示矩阵有m行n列。接下来是m行整数，每行n个整数，表示矩阵值。

**【输出】**

仅一行。包含3个整数，分别是矩阵中的最大值，以及其所在的行号和列号。如有多个最大值，则显示第1个出现的，数据间以空格分隔。

例如:

**输入：**

```text
3 4
1 2 9 3
5 3 4 2
0 6 9 1
```

**输出：**

```text
9 0 2
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int m, n, value, maximum = 0, best_row = 0, best_col = 0;
    scanf("%d%d", &m, &n);
    for (int row = 0; row < m; ++row) {
        for (int col = 0; col < n; ++col) {
            scanf("%d", &value);
            if ((row == 0 && col == 0) || value > maximum) {
                maximum = value; best_row = row; best_col = col;
            }
        }
    }
    printf("%d %d %d\n", maximum, best_row, best_col);
    return 0;
}
```

## 讲解

1. 按行从左到右读入矩阵，第一项直接作为当前最大值。
2. 只有读到更大的数时才更新最大值与行列号，遇到相同最大值不更新。
3. 这样扫描结束保留的就是最早出现的最大元素。
4. 例如样例两个9中，先读到第0行第2列的9，后来第2行第2列的9不会覆盖它。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 使用>=会把第一个最大值替换成最后一个。
- 全负矩阵的最大值也是负数，不能只用0作初始最大值且不处理第一项。
