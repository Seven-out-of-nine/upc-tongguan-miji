# \[4.02\]不同国家日期写法★

[学习首页](../README.md) · [本章目录](../chapters/ch02/README.md) · [知识点索引](../知识点索引.md)

来源：【测验】第2章 程序设计基础.html，第15题。

## 题目

**描述**

对于年、月、日的写法，不同的国家有不同的描述形式。请按年、月、日的顺序读入日期，然后分别输出中国式写法（年/月/日），英国式写法（日/月/年）和美国式写法（月/日/年）。

**输入**

从键盘按年、月、日顺序输入日期。（输入数据都在合法范围内）。

**输出**

中、美、英式的日期写法。每个输出占一行。

例如:

**输入：**

```text
2011 12 31
```

**输出：**

```text
中国式写法为：2011/12/31
英国式写法为：31/12/2011
美国式写法为：12/31/2011
```

### 题目与实现说明

- 原题“输出”段写“中、美、英”，而描述和样例为“中、英、美”；本解遵循样例。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int year, month, day;
    scanf("%d %d %d", &year, &month, &day);
    printf("中国式写法为：%d/%d/%d\n", year, month, day);
    printf("英国式写法为：%d/%d/%d\n", day, month, year);
    printf("美国式写法为：%d/%d/%d\n", month, day, year);
    return 0;
}
```

[下载完整源码](../solutions/ch02-15.c)

## 讲解

1. 输入时始终按年、月、日保存到 year、month、day。
2. 三种日期写法只改变输出变量的排列顺序，不改变变量本身。
3. 例如输入2011 12 31，中国式是2011/12/31，英国式把日放在最前面，得到31/12/2011。

## 知识点总结

- 多个变量：year、month、day 为三个独立的int，分别对应日期的三个部分。
- printf 参数顺序：三个%d依次使用它们后面列出的三个变量。
- 中文字符串：提示文字和全角冒号照样例原样写入字符串，源码采用UTF-8。

## 易错点

- 题干输出段的国家顺序有笔误，按样例使用中国、英国、美国的顺序。
- 本题不要求补零，1月2日应输出1/2而不是01/02。
