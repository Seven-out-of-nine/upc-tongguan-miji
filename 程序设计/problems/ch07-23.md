## 题目

4.07 多继承的应用【★★】

定义类Time，包含小时、分钟、秒三个私有数据成员，一个display函数用于输出小时、分钟和秒的数据，定义构造函数对三个数据成员进行初始化。定义类Date，包含年、月、日三个私有数据成员，一个display函数用于输出年、月、日的数据，定义构造函数对三个数据成员进行初始化。设计并定义一个派生类Birthtime，它继承类Time和Date，并且增加一个数据成员Childname用于表示小孩的名称，在主程序中显示一个小孩的出生时间和姓名。

例如:

**输出：**

```text
姓名：皮皮
出生年月：2000年12月21日
出生时间：10时15分25秒
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Time {
private:
    int hour, minute, second;
public:
    Time(int h,int m,int s) : hour(h),minute(m),second(s) {}
    void display() const { cout << hour << "时" << minute << "分" << second << "秒"; }
};
class Date {
private:
    int year, month, day;
public:
    Date(int y,int m,int d) : year(y),month(m),day(d) {}
    void display() const { cout << year << "年" << month << "月" << day << "日"; }
};
class Birthtime : public Time, public Date {
private:
    string Childname;
public:
    Birthtime(int y,int mo,int d,int h,int mi,int s,string n)
        : Time(h,mi,s),Date(y,mo,d),Childname(n) {}
    void display() const {
        cout << "姓名：" << Childname << '\n' << "出生年月：";
        Date::display();
        cout << '\n' << "出生时间：";
        Time::display();
    }
};
int main() {
    Birthtime boy(2000,12,21,10,15,25,"皮皮");
    boy.display();
    return 0;
}
```

## 讲解

1. Time保存时分秒，Date保存年月日，两个类都提供自己的display。
2. Birthtime同时继承Time与Date，再加入姓名Childname。
3. 输出姓名后，分别用Date::display和Time::display选择要显示的基类部分。
4. 例如演示对象输出2000年12月21日和10时15分25秒。

## 知识点总结

- **多继承与基类同名成员选择**：Birthtime : public Time, public Date同时继承两个基类；构造时按继承声明的基类次序，而不是初始化列表的书写次序。两个基类都有display时，用Date::display()或Time::display()明确选择来源，避免同名成员歧义。

## 易错点

- 不能把两套数据都移到Birthtime里而省略Time/Date的构造和显示方法，否则失去题目要练习的多继承。
