# 随堂2-1 平均分树苗

## 题目

Description

某学校植树节开展植树活动，已知树苗有m株，参加植树的同学有n人（且m&gt;n），请问每位同学平均可以植树几株？还有几株剩余？

Input

输入两个整数m和n，分别表示树苗的数量和学生的人数（m&gt;n）。

Output

输出两个整数，分别表示每位同学平均植树的数量及剩余的树苗数量。

例如:

**样例 1**

**输入：**

```text
163 32
```

**输出：**

```text
5 3
```

**样例 2**

**输入：**

```text
1000 33
```

**输出：**

```text
30 10
```

## 解答

```c
#include <stdio.h>

int main(void) {
    long long m, n; scanf("%lld%lld", &m, &n);
    printf("%lld %lld\n", m / n, m % n);
    return 0;
}
```

[下载完整源码](../solutions/quiz2-01.c)

## 讲解

1. 每人必须分到相同的整数株树苗，使用整数除法得到每人株数。
2. 总株数除以人数的余数就是无法平均分掉的株数。
3. 例如163除以32，商5、余3，因此输出5 3。

## 知识点总结

- long long：保存树苗数和人数，比int容纳更大整数。
- m/n：整数除法舍去不足一株的部分。
- m%n：取余数，得到剩余株数。
- %lld：与long long的输入输出类型匹配。

## 易错点

- 人数必须是正数，不能用0作除数。
- 不要用浮点除法输出小数株数。
