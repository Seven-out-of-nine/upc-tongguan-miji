## 题目

4.03 派生类的构造函数与析构函数【★★】

定义一个哺乳动物类Mammal，包含年龄和重量两个私有数据成员，有设置和获取这些私有成员的公有成员函数，以及叫声（speak）成员函数。再由此派生出狗类Dog，增加颜色私有数据成员，有设置和获取颜色数据成员的公有成员，以及摇尾巴（wagtail）成员函数。定义一个Dog类的对象，分析基类与派生类的构造函数与析构函数的调用顺序。

例如:

**输出：**

```text
Mammal constructor......
Dog constructor......
Mammal sound!
Tail wagging......
jack is 2 years old, 20 pounds, grown.
Dog destructor......
Mammal destructor......
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Mammal {
private:
    int age;    
    int weight; 
public:
    
    Mammal(int a, int w) : age(a), weight(w) {
        cout << "Mammal constructor......" << endl;
    }

    
    ~Mammal() {
        cout << "Mammal destructor......" << endl;
    }

    
    void setAge(int a) { age = a; }
    void setWeight(int w) { weight = w; }
    int getAge() const { return age; }
    
    int getWeight() const { return weight; }

    
    void speak() const {
        cout << "Mammal sound!" << endl;
    }
};


class Dog : public Mammal {
private:
    string color; 
public:
    
    Dog(int a, int w, string c) : Mammal(a, w), color(c) {
        cout << "Dog constructor......" << endl;
    }

    
    ~Dog() {
        cout << "Dog destructor......" << endl;
    }

    
    void setColor(string c) { color = c; }
    string getColor() const { return color; }

    
    void wagtail() const {
        cout << "Tail wagging......" << endl;
    }
};

int main()
{
      Dog jack(2,20,"grown");
      jack.speak();
      jack.wagtail();
      cout<<"jack is "<<jack.getAge()<<" years old, "<<jack.getWeight()<<" pounds, "<<jack.getColor()<<"."<<endl;
      return 0;
}
```

[下载完整源码](../solutions/ch07-20.cpp)

## 讲解

1. 建立Dog前，必须先建立它所包含的Mammal基类部分，所以先输出Mammal constructor，再输出Dog constructor。
2. Dog通过继承使用speak、getAge、getWeight，同时提供自己的颜色和wagtail。
3. main执行完毕时局部对象jack被销毁，顺序与构造相反：先Dog析构，再Mammal析构。
4. 本题jack为2岁、20磅、颜色字符串grown，按原演示逐项输出。

## 知识点总结

- **继承对象的构造与析构顺序**：创建Dog时先构造Mammal基类部分，再构造Dog自身；销毁顺序相反，先Dog后Mammal。成员子对象也先于外层构造函数体构造、在外层析构函数体结束后按相反顺序销毁；因此输出构造或析构提示可以观察嵌套对象的生命周期。

## 易错点

- 不要在main里手动调用析构函数，否则离开作用域还会再次析构。
