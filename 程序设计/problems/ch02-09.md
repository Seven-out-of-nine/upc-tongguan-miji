## 题目

**描述**

从键盘上输入一个整数，再输入一个整数，求商和余数，把商和余数输出到屏幕上

**输入**

一行。输入两个整数，用空格符分隔。

**输出**

两行。每个结果占一行。

例如:

**输入：**

```text
11 3
```

**输出：**

```text
11/3=3
11%3=2
```

### 题目与实现说明

- 原题没有说明除以0时如何输出，本解按除数非0的有效输入处理。

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long a, b;
    scanf("%lld %lld", &a, &b);
    printf("%lld/%lld=%lld\n", a, b, a / b);
    printf("%lld%%%lld=%lld\n", a, b, a % b);
    return 0;
}
```

[下载完整源码](../solutions/ch02-09.c)

## 讲解

1. 读入被除数 a 和除数 b。
2. 用 a/b 求整数商，用 a%b 求余数。
3. 例如11=3*3+2，因此11/3=3，11%3=2；按样例把两个等式各占一行输出。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 输出包含两个操作数、运算符和等号，不是只输出3和2。
- 除数必须非0。
