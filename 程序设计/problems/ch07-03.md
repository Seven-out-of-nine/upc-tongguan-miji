## 题目

1.03 用面向对象程序设计求长方形的周长和面积【★】

用C++语言编写长方形类，实现输入长和宽（都为整型），求周长和面积等操作。

例如:

**样例 1**

**输入：**

```text
6,4
```

**输出：**

```text
perimeter:20,area:24
```

**样例 2**

**输入：**

```text
12,9
```

**输出：**

```text
perimeter:42,area:108
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Rectangle {
private:
    int length, width;
public:
    void setData(int l, int w) { length = l; width = w; }
    long long perimeter() const { return 2LL * (length + (long long)width); }
    long long area() const { return 1LL * length * width; }
};
int main() {
    int l, w;
    char comma;
    cin >> l >> comma >> w;
    Rectangle r;
    r.setData(l, w);
    cout << "perimeter:" << r.perimeter() << ",area:" << r.area() << '\n';
    return 0;
}
```

[下载完整源码](../solutions/ch07-03.cpp)

## 讲解

1. 用Rectangle保存长length和宽width。
2. 周长是2*(长+宽)，面积是长*宽，各写成一个成员函数。
3. 例如输入3,4，周长14、面积12，输出perimeter:14,area:12。

## 知识点总结

- 数据成员保存对象状态，方法使用当前对象保存的长宽计算。
- char变量comma读取输入中的逗号。
- 1LL让乘法从long long开始计算，减小int乘法溢出的风险。
- const成员函数用于只读计算，明确不修改长宽。

## 易错点

- 注意输入样例使用逗号，输出中的冒号与逗号也要保持一致。
