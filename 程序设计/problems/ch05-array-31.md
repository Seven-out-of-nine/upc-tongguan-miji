# 8.31 顺序编号【★★】

## 题目

【题目描述】

对数组a\[10\]中的十个整数从小到大进行连续编号，输出各个元素的编号。要求不能改变数组 a 中元素的顺序，并且相同的整数要具有相同的编号。

【输入】

仅一行。10个整数，表示10个数的编号。

【输出】

仅一行。10个整数，按输入顺序输出每个整数对应的编号（每个数据以3列的域宽显示）。

例如:

**输入：**

```text
5 3 4 7 3 5 6 8 9 10
```

**输出：**

```text
  4  1  3  7  1  4  6  8  9 10
```

### 题目与实现说明

- 题干写“连续编号”，但样例明确采用1+较小元素总数的编号方式，存在跳号；本解按样例与保存答案解释。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int value[10];
    for (int i = 0; i < 10; ++i) scanf("%d", &value[i]);
    for (int i = 0; i < 10; ++i) {
        int rank = 1;
        for (int j = 0; j < 10; ++j)
            if (value[j] < value[i]) ++rank;
        printf("%3d", rank);
    }
    putchar('\n');
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-31.c)

## 讲解

1. 数组不能改变顺序，因此对每个原元素单独计算它应有的名次。
2. 某元素的编号等于1加上严格小于它的元素数量；相同值面对的较小元素数量相同，所以编号相同。
3. 例如样例有两个3都编号1；4前面有两个3比它小，因此编号3；5前面有3、3、4共3个元素，编号4。
4. 按原输入顺序输出每个编号，用%3d保证最小3列宽。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 按样例是竞赛排名，重复值后会跳号，不是给不同值连续编号1、2、3。
- 不应直接排序原数组后输出，否则会丢失原元素顺序。
