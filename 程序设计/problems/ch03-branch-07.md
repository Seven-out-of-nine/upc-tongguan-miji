## 题目

**描述**

钟表上的时钟分针和时针之间的夹角总是在0～359度之间，通过输入现在是几点几分，来判断此时时针和分针的夹角。（12小时制），输出的度数，小数点后保留一位。

注意：有两个夹角时取较小的。

**输入**

输入时和分，以空格隔开。

**输出**

夹角度数，格式为"At %d:%02d the angle is %.1f degrees."

提示：公式为 角度 = |5.5\*分钟 - 30\*小时|

例如:

**输入：**

```text
12 0
```

**输出：**

```text
At 12:00 the angle is 0.0 degrees.
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int hour, minute;
    scanf("%d %d", &hour, &minute);
    double angle = 5.5 * minute - 30 * (hour % 12);
    if (angle < 0) angle = -angle;
    if (angle > 180) angle = 360 - angle;
    printf("At %d:%02d the angle is %.1f degrees.\n", hour, minute, angle);
    return 0;
}
```

## 讲解

1. 分针每分钟走6度；时针每小时30度、每分钟再走0.5度，所以角度差是5.5*minute-30*hour的绝对值。
2. 把12点看作0点，先求绝对角度差，再在差值超过180度时改取360-差值。
3. 例如3:00两针差90度；12:30时针已走到15度、分针180度，较小夹角是165度。

## 知识点总结

- hour%12：将12点映射到0点，其余小时保持对应位置。
- double：分钟引起时针每分钟移动0.5度，角度可能有小数。
- %02d与%.1f：分钟不足两位补0，夹角固定显示一位小数。

## 易错点

- 时针不是整小时后才移动，不能忽略0.5*minute这一项。
- 题目要求较小夹角，结果应在0到180度之间。
