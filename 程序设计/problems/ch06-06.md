## 题目

【函数+字符数组】F10.8 字符串转换成整数【★★】

【题目描述】

编写一个函数Fun，其功能是：将一个数字字符串转换为一个整数。

【输入】

仅一行。一个数字字符串（长度不超过8）。

【输出】

仅一行。转换为的整数。

**前置代码：**

```text
#include <stdio.h>
#define N 10
#include <bits/stdc++.h>
using namespace std;
```

**后置代码：**

```text
int main()
{
    char s[N];
    int n;
    scanf("%s",s);
    n = Fun(s);
    printf("%d\n", n);
    return 0;
}
```

例如:

**输入：**

```text
-1234
```

**输出：**

```text
-1234
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
int Fun(char s[]) {
    int i = 0, sign = 1, value = 0;
    if (s[i] == '-' || s[i] == '+') {
        if (s[i] == '-') sign = -1;
        i++;
    }
    for (; s[i] != '\0'; i++) value = value * 10 + s[i] - '0';
    return sign * value;
}
```

## 讲解

1. 先检查第一个字符是不是正负号，并记住结果的符号。
2. 从第一位数字开始，每来一位，就把已有结果乘 10，再加上新数字。
3. 例如 123：先得到 1，再得到 1*10+2=12，最后得到 12*10+3=123。
4. 把最后的数乘以 sign 后返回，-1234 就能得到负整数。

## 知识点总结

- 字符 '3' 和整数 3 不同，'3'-'0' 才得到整数 3。
- 十进制数每向右补一位，原来的各位整体提高一位，所以要乘 10。
- return 把计算结果交回 main；函数返回类型为 int。

## 易错点

- 不能把负号也放进数字转换公式；输入按题意保证是合法数字字符串。
