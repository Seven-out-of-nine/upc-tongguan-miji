## 题目

**描述**

定义一个实型变量，赋初始值为3.65，把这个实型变量的值输出

**输入**

无

**输出**

3.65

例如:

**输入：**

```text
无
```

**输出：**

```text
3.65
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double value = 3.65;
    printf("%.2f\n", value);
    return 0;
}
```

[下载完整源码](../solutions/ch02-06.c)

## 讲解

1. 用 double 保存带小数的数值3.65。
2. 用 %.2f 输出变量，规定小数点后显示两位。
3. 例如 value 为3.65时，输出就是3.65，而不会额外显示3.650000。

## 知识点总结

- double：保存实数，能够表示小数部分，本题不能把变量写成 int。
- 初始化：double value = 3.65 在定义时给变量赋初值。
- %.2f：printf 输出浮点数，并保留小数点后两位。

## 易错点

- int value = 3.65 会丢掉小数部分，结果只剩3。
