## 题目

**描述**

定义一个实型变量，赋初始值为3.65，把这个实型变量的值输出

**输入**

无

**输出**

3.65

例如:

**输入：**

```text
无
```

**输出：**

```text
3.65
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double value = 3.65;
    printf("%.2f\n", value);
    return 0;
}
```

[下载完整源码](../solutions/ch02-06.c)

## 讲解

1. 用 double 保存带小数的数值3.65。
2. 用 %.2f 输出变量，规定小数点后显示两位。
3. 例如 value 为3.65时，输出就是3.65，而不会额外显示3.650000。

## 知识点总结

- **double实数类型与输入格式**：double用浮点近似保存3.65等带小数的数，int会丢失小数部分。scanf读取double用%lf，printf输出double用%f，两类函数的格式不能混淆。
- **固定小数位数输出**：printf的%.2f把double按小数点后2位显示，不足补0，显示时舍入但不修改变量。%.1f、%.3f、%.6f只是同一规则选择不同位数；小数精度与最小列宽不是同一设置。

## 易错点

- int value = 3.65 会丢掉小数部分，结果只剩3。
