## 题目

**【题目描述】**

编写一个程序，求出n×m的二维数组周边元素之和。

**【输入】**

有多行。第1行是两个整数n（≤10）和m（≤10），分别表示二维数组共n行m列元素。接下来是n行m列的二维数组元素。

**【输出】**

仅一行。一个整数，表示周边元素之和。

例如:

**输入：**

```text
4 5
1 3 5 7 9
2 9 9 9 4
6 9 9 9 8
1 3 5 7 0
```

**输出：**

```text
61
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, m, value;
    long long sum = 0;
    scanf("%d%d", &n, &m);
    for (int row = 0; row < n; ++row) {
        for (int col = 0; col < m; ++col) {
            scanf("%d", &value);
            if (row == 0 || row == n - 1 || col == 0 || col == m - 1) sum += value;
        }
    }
    printf("%lld\n", sum);
    return 0;
}
```

## 讲解

1. 矩阵周边包括第一行、最后一行、第一列、最后一列。
2. 逐个读取元素，用四个边界条件判断它是否至少位于一条边上，是就累加一次。
3. 例如2行矩阵中的每个数都在边上；样例中间的6个9不在边上，所以不计入。

## 知识点总结

- 逻辑或||：四个边界条件任意一个成立即可，一次if只累加一次。
- 下标n-1、m-1：数组从0开始，最后一行列不是n、m。
- long long与%lld：最多100个int求和可能超出int，用更宽整数保存。

## 易错点

- 不能分别加四条边而不去重，否则四个角会重复累加。
- 一行或一列时同样每个元素只计算一次。
