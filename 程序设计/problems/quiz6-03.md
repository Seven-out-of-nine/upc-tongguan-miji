## 题目

20204 夏边的奇偶数之恋

【题目描述】

夏边今年五岁啦，他可喜欢数字了，要问为什么的话，夏边会告诉你：因为汉字太难学了啊~~不过，他的巴巴告诉他，数字虽然写起来简单，但是老神秘老神秘了，包含着太多太多科学知识，像素数、整数、小数、虚数……夏边没记住那么多知识，只是明白了啥叫奇偶数，而且他只认识10以内的个位偶数。今天，巴巴要考考他，给出若干个整数（每个整数不超过9位），让他数数每个整数里有几个偶数。你能帮夏边检查答案是否正确吗？

【输入】

输入数据有多行，每行一个整数

【输出】

对每行整数，输出其中包含多少个偶数（个位数），末尾换行。

例如:

**输入：**

```text
1234560
11
```

**输出：**

```text
4
0
```

## 解答

```c
#include <stdio.h>

int main(void) {
    long long number;
    while (scanf("%lld", &number) == 1) {
        if (number < 0) number = -number;
        int count = 0;
        do {
            int digit = number % 10;
            if (digit % 2 == 0) ++count;
            number /= 10;
        } while (number > 0);
        printf("%d\n", count);
    }
    return 0;
}
```

## 讲解

1. 取整数绝对值后，逐位检查个位，再去掉个位。
2. 个位为0、2、4、6、8都算偶数字符，每遇到一个就计数。
3. 例如1234560里偶数位是2、4、6、0，共4个。
4. 使用do-while保证输入0也检查一次，结果为1。

## 知识点总结

- number%10：取出当前个位。
- number/=10：删除已经检查过的个位。
- do-while：先执行再判断，对0至少执行一次。
- digit%2==0：偶数的判断条件。

## 易错点

- 0是偶数，不能遗漏。
- 本题统计每一位中偶数的个数，不是只判断整个整数是否为偶数。
