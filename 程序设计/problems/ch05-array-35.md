## 题目

【题目描述】

进入石油大学南大门，长度为L的马路东边有一排树，每两棵相邻的树之间的间隔都是1米。如果把马路看成一个数轴，马路的一端在数轴0的位置，另一端在L的位置；数轴上的每个整数点，即0，1，2，……，L都种有一棵树。

由于马路上有一些区域要用来修建停车场。这些区域用它们在数轴上的起始点和终止点表示。已知任一区域的起始点和终止点的坐标都是整数，区域之间可能有重合的部分。现在要把这些区域中的树（包括区域端点处的两棵树）移走。你的任务是计算将这些树都移走后，马路上还有多少棵树。

【输入】

有多行。的第1行有两个整数L（1 ≤ L ≤ 1000）和 M（1 ≤ M ≤ 10），L代表马路的长度，M代表区域的数目，L和M之间用一个空格隔开。接下来的M行每行包含两个不同的整数，用一个空格隔开，表示一个区域的起始点和终止点的坐标（起始点坐标&lt;终止点坐标）。

【输出】

仅一行。只包含一个整数，表示马路上剩余的树的数目。

例如:

**输入：**

```text
500 3
150 300
100 200
470 471
```

**输出：**

```text
298
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int length, regions, removed[1001] = {0};
    scanf("%d%d", &length, &regions);
    for (int i = 0; i < regions; ++i) {
        int start, end;
        scanf("%d%d", &start, &end);
        for (int position = start; position <= end; ++position) removed[position] = 1;
    }
    int remaining = 0;
    for (int position = 0; position <= length; ++position)
        if (!removed[position]) ++remaining;
    printf("%d\n", remaining);
    return 0;
}
```

## 讲解

1. 道路上0到L每个整数点都有树，一共有L+1棵。
2. 用removed[position]表示该位置是否要移走，对每个闭区间把起点到终点的标记都设为1。
3. 所有区域处理完，再统计标记仍为0的位置；重叠区域反复设1不会重复扣除。
4. 例如L=5，移走[1,3]与[2,4]，实际移走1、2、3、4四棵，剩0和5两棵。

## 知识点总结

- **闭区间标记与重叠去重**：闭区间[start,end]包含两个端点，故扫描条件要用position<=end。多个待删除区间合起来表示它们的并集：重叠位置只属于同一份被删除对象，不能按各区间长度直接相减。全部区间处理完，再统一统计并集之外的位置。

## 易错点

- 原有树数是L+1，不能按道路长度L计算。
- 数组需容纳下标1000，应开1001个位置。
