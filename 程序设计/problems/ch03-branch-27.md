## 题目

【题目描述】

有一分段函数，y=f(x)。当x小于6时，y=x-12；当x大于等于6且小于15时，y=3x-1；当x大于等于15时，y=5x+9.从键盘上输入一个整数x，输出对应的y值。

【输入】

一个整数。

【输出】

函数值。

例如:

**输入：**

```text
1
```

**输出：**

```text
-11
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long x, y;
    scanf("%lld", &x);
    if (x < 6) y = x - 12;
    else if (x < 15) y = 3 * x - 1;
    else y = 5 * x + 9;
    printf("%lld\n", y);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-27.c)

## 讲解

1. 三个区间分别使用三个不同的算式，先判断x属于哪一段。
2. 从x<6开始，再检查x<15；进入第二段时已经隐含x>=6。
3. 例如x=6代入第二段得到17；x=15代入第三段得到84。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 两道分段函数题的区间相同，但公式不同，不能把信号题的6x-4直接套来。
