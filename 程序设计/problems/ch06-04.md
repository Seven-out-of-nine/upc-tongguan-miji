## 题目

【函数+字符数组】F10.5 列优先存放【★】

【题目描述】

编写函数Fun, 其功能是: 将m行n列的二维数组中的字符数据，按列的顺序依次放到一个字符串中。

所有字符串保证不包含空格。

前置代码：

```text
#include <stdio.h>
#define M 10
#define N 100
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    char a[N * M + 5], w[M + 5][N + 5];
    int m, n, i;
    scanf("%d%d", &m, &n);  
    for( i = 0; i < m; i++ )
    {
        scanf("%s",w[i]);
    }
    Fun(w, m, n, a);
    puts(a);
    return 0;
}
```

【输入】

有多行。第1行包含两个整数m（m≤10）和n（n≤100），分别表示二维数组的m行和n列。接下来包含m行字符串，每个字符串n个字符（字符间没有空白字符）。

【输出】

仅一行。按列的顺序依次存放的字符串。

例如:

**输入：**

```text
3 4
TTTT
SSSS
HHHH
```

**输出：**

```text
TSHTSHTSHTSH
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char w[M+5][N+5], int m, int n, char a[]) {
    int k = 0;
    for (int col = 0; col < n; col++) {
        for (int row = 0; row < m; row++) {
            a[k++] = w[row][col];
        }
    }
    a[k] = '\0';
}
```

## 讲解

1. 外层循环决定当前读第几列，内层循环依次读这一列的每一行。
2. 每读到一个字符就放在 a[k]，再增加 k。
3. 例如两行 ab、cd，先读第一列 a、c，再读第二列 b、d，得到 acbd。

## 易错点

- 把行作为外层循环就变成行优先，输出会不同。
