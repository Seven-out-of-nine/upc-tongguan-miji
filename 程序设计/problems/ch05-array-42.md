## 题目

**【问题描述】**

上学期，海油14级两个班同学的C语言考试成绩（人数最多不超过70人）比较理想。现要求从键盘输入学生的成绩，编程将成绩按从高到低顺序进行排序输出，并同时输入指定学生的学号和成绩。

**【输入】**

有多行。从第一行开始，每行输入两个空格分隔的整数，分别表示每个学生的学号和成绩，当输入负值时，表示输入结束。
最后一行输入需要查找的学生学号。

**【输出】**

有两行。第一行是按由高到低排好序的学生成绩。第二行输出查找到的学生学号和成绩，若没有找到指定学生，则输出“not find!”。

例如:

**样例 1**

**输入：**

```text
1301 87
1302 79
1303 90
1304 68
-1 -2
1302
```

**输出：**

```text
90 87 79 68
1302 79
```

**样例 2**

**输入：**

```text
13121 88
13122 77
13123 99
13125 66
13126 100
13128 55
-2 -10
13127
```

**输出：**

```text
100 99 88 77 66 55
not find!
```

### 题目与实现说明

- 按题干“当输入负值时”解释为本行任一字段为负即结束，样例的结束行两个字段均为负。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int id[70], score[70], sorted[70], n = 0, number, mark;
    while (scanf("%d%d", &number, &mark) == 2) {
        if (number < 0 || mark < 0) break;
        id[n] = number; score[n] = sorted[n] = mark; ++n;
    }
    int target;
    scanf("%d", &target);
    for (int i = 1; i < n; ++i) {
        int key = sorted[i], j = i - 1;
        while (j >= 0 && sorted[j] < key) { sorted[j + 1] = sorted[j]; --j; }
        sorted[j + 1] = key;
    }
    for (int i = 0; i < n; ++i) { if (i) putchar(' '); printf("%d", sorted[i]); }
    putchar('\n');
    for (int i = 0; i < n; ++i)
        if (id[i] == target) { printf("%d %d\n", id[i], score[i]); return 0; }
    puts("not find!");
    return 0;
}
```

## 讲解

1. 成对读取学号与成绩，遇到负值结束学生输入，负值这对数据不保存；随后再读待查学号。
2. 用id和score保持原始学号成绩对应关系，另复制成绩到sorted供排序。
3. 插入排序把sorted按从高到低排列，每轮把当前成绩插到前面已排序的部分中。
4. 例如学号1成绩0、学号2成绩90，输出排序成绩90 0；查询学号1仍能得到1 0，零分不能当成无效记录。

## 知识点总结

- scanf返回2：表示成功读入了两个整数，可防止到文件结尾仍反复处理旧值。
- 平行数组：id[i]和score[i]始终属于同一学生，单独排序sorted不会破坏它们。
- while(j>=0&&sorted[j]<key)：把较低成绩右移，给当前较高成绩腾出位置。
- n记录实际人数：遍历到n即可，不应扫描未使用的70个位置。

## 易错点

- 不能通过成绩是否为0来判断某位置是否存在学生，0分也是合法成绩。
- 排序原成绩时如果没有同步交换学号，查找会把学生与成绩配错。
