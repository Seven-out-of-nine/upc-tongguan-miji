## 题目

**描述**

从键盘上输入一个整数A，再输入一个整数B，求和，然后输出

**输入**

一行，输入两个整数，用空格符分隔。

**输出**

一行。输出两个整数的和。

例如:

**输入：**

```text
3 4
```

**输出：**

```text
7
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long a, b;
    scanf("%lld %lld", &a, &b);
    long long sum = a + b;
    printf("%lld\n", sum);
    return 0;
}
```

[下载完整源码](../solutions/ch02-07.c)

## 讲解

1. 用 a、b 接收两个输入的整数。
2. 计算 a+b，把结果保存到 sum。
3. 例如输入3和4，sum 等于7，最后只输出7。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 样例只要和，不要输出“a+b=”等额外文字。
