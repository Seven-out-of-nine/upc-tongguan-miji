## 题目

3.02 设计一个矩形类Rectangle，根据其左上角和右下角坐标计算矩形面积【★】

设计一个名为Rectangle的矩形类，其属性为矩形的左上角与右下角两个点的坐标，根据坐标能计算矩形的面积。要求该矩形类包含设置坐标点值和获取坐标点值的成员函数。

例如:

**输出：**

```text
Area: 4000
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Rectangle {
private:
    int x1, y1, x2, y2;
public:
    Rectangle(int a, int b, int c, int d) { setPoints(a,b,c,d); }
    void setPoints(int a, int b, int c, int d) { x1=a; y1=b; x2=c; y2=d; }
    int getX1() const { return x1; }
    int getY1() const { return y1; }
    int getX2() const { return x2; }
    int getY2() const { return y2; }
    long long getArea() const { return 1LL * (x2-x1) * (y1-y2); }
};
int main() {
    Rectangle rect(100,80,200,40);
    cout << "Area: " << rect.getArea() << '\n';
    return 0;
}
```

[下载完整源码](../solutions/ch07-08.cpp)

## 讲解

1. 两个点(100,80)和(200,40)分别是左上角与右下角。
2. 矩形宽为200-100=100，高为80-40=40，面积为4000。
3. 类提供设置坐标与获取坐标的成员函数，再用getArea计算面积。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 坐标按左上和右下的题意使用，高是y1-y2，写反会得到负面积。
