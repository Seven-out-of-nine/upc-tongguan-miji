## 题目

**【题目描述】**

小明的发廊距开张已经有10年之久了！由于小明以及其他理发师傅洗剪吹技术娴熟，发廊有了许多常客，连毕业多年的学生也会不时回来学校, 到小明的发廊做洗剪吹。常客们都有自己喜欢理发师，然而随着运营规模的扩张, 理发师的分配时常会出现问题。现在你的任务就是为顾客们交换理发师傅。

假设有0...n-1共n名顾客，他们的理发师傅恰巧安排反了。也就是说n-1的理发师傅安排给了0，n-2的理发师傅安排给了1…请帮助他们找到喜欢的理发师傅吧！

**【输入】**

有两行。第1行是一个整数n（1≤n≤1000），表示顾客的人数。第2行是n个整数，分别表示现在安排给每位顾客的理发师傅的编号。

**【输出】**

仅一行。n个整数，表示为n位顾客正确安排理发师傅之后的编号，每个师傅们的编号由空格隔开。

例如:

**输入：**

```text
5
2 4 7 1 5
```

**输出：**

```text
5 1 7 4 2
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, value[1000];
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) scanf("%d", &value[i]);
    for (int i = n - 1; i >= 0; --i) {
        if (i != n - 1) putchar(' ');
        printf("%d", value[i]);
    }
    putchar('\n');
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-17.c)

## 讲解

1. 第一个位置应接收最后一个位置的理发师编号，第二个位置接收倒数第二个，整个数组反过来即可。
2. 先保存全部编号，再从下标n-1递减到0输出，原数组无需改动。
3. 例如2 4 7 1 5逆序后是5 1 7 4 2；中间的7位置不变。

## 知识点总结

- **数组逆序的位置对应**：n个元素逆序时，原下标i对应新下标n-1-i；若只需要显示结果，也可以直接从n-1递减到0输出，不必另建反转数组。这里反转的是输入顺序，不是按数值大小排序。

## 易错点

- 交换的是位置，不是把编号按数值大小排序。
- 只有一个元素时直接输出它；偶数个元素时同样全部逆序。
