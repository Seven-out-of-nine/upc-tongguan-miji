## 题目

**8.24 二分查找【★★】**

【题目描述】

在某一国度里流行着一种游戏。游戏规则为：在一堆球中，每个球上都有一个整数编号i（0≤i≤100000000），编号可重复，现在说一个随机整数k（0≤k≤100000100），判断编号为k的球是否在这堆球中（存在为“YES”，否则为“NO”），先答出者为胜。 现在有一个人想玩玩这个游戏，但他又很懒。他希望你能帮助他取得胜利！

【输入】

有多行。第1行有两个整数m，n(0&lt;n≤10000，0&lt;m≤100000)，m表示这堆球里有m个球（编号由小到大已排好序），n表示这个游戏进行n次。接下来有m+n个整数，前m个分别表示这m个球的编号i，后n个分别表示每次游戏中的随机整数k。

【输出】

仅一行。“YES”或“NO”。

例如:

**输入：**

```text
6 4
23 34 46 343 343 768
2 23 4 343
```

**输出：**

```text
NO
YES
NO
YES
```

### 题目与实现说明

- 输出说明写“仅一行”，但存在n次询问，原样例为每次询问一行，本解按样例输出n行。

## 解答

```c
#include <stdio.h>

static int ball[100000];

int main(void)
{
    int m, n;
    scanf("%d%d", &m, &n);
    for (int i = 0; i < m; ++i) scanf("%d", &ball[i]);
    for (int query = 0; query < n; ++query) {
        int target, left = 0, right = m - 1, found = 0;
        scanf("%d", &target);
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (ball[mid] == target) { found = 1; break; }
            if (ball[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        puts(found ? "YES" : "NO");
    }
    return 0;
}
```

## 讲解

1. 球号已经从小到大排好，可用左右端点表示尚未排除的搜索区间。
2. 检查中间位置mid：若等于目标就成功；若中间值较小，目标只能在右半边，否则只能在左半边。
3. 每次舍弃至少一半候选，区间为空仍未找到时输出NO。
4. 例如23 34 46 343 343 768中查343，检查中间值后转向右半区即可找到；有重复球号也不影响存在性判断。

## 知识点总结

- **有序数组的二分查找**：在已升序的数组中，用left、right保留尚未排除的闭区间，每轮检查mid。中间值小于目标就令left=mid+1，大于目标就令right=mid-1，相等即成功；left>right表示没有候选。每次至少排除一半，查询约需log₂n轮。

## 易错点

- 二分查找依赖有序输入，不能直接用于乱序数组。
- 每次查询都要重置left、right、found；应每次输出一行。
