## 题目

10.01 不带空格的字符串输入输出【★】

【题目描述】

输入一个不带空格的字符串，并按照原样输出。

【输入】

一个不带空格的字符串（不超过80字符）。

【输出】

原样输出。

例如:

**输入：**

```text
HelloUPC
```

**输出：**

```text
HelloUPC
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char s[81];
    if (scanf("%80s", s) == 1) puts(s);
    return 0;
}
```

[下载完整源码](../solutions/ch05-string-01.c)

## 讲解

1. 准备81个字符的位置，其中80个保存输入，另一个保存结束标志。
2. 用带宽度的scanf读取这个没有空格的单词。
3. 例如输入HelloUPC，数组保存这些字符，puts原样输出一行。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 数组大小要比允许的字符数至少多1。
- %s会在空格处停止，适用于本题给定的不带空格输入。
