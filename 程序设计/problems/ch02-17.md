## 题目

**描述**

通信过程中加密是比较特殊的一环，可以保护信息免遭泄露。小通已经掌握了一些解密技能，他开始尝试进行简单的加密。现在从键盘输入任意两个字符，要求对它进行加密。加密规则：用原字符后的第3个字符来代替。如果需要将“Hi”加密，H后面第3个字符是K，i后面第3个字符是l，因此“Hi”加密后为“Kl”。

**输入**

任意两个字符，表示信息的原码，字符之间没有空格。

**输出**

加密后的密码，字符间没有空格。

例如:

**输入：**

```text
Hi    
```

**输出：**

```text
Kl
```

### 题目与实现说明

- 按本题ASCII范围内的可表示字符处理；这只是编码平移练习。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int first = getchar();
    int second = getchar();
    printf("%c%c\n", first + 3, second + 3);
    return 0;
}
```

[下载完整源码](../solutions/ch02-17.c)

## 讲解

1. 连续读入两个字符，分别保存它们的编码。
2. 把每个编码加3，再按字符形式输出；两个字符之间不加空格。
3. 例如H变成K，i变成l，因此Hi变成Kl。

## 知识点总结

- **按字符输出编码**：printf的%c把编码按字符显示，%d则显示十进制数值；编码65分别显示为A与65。字符编码加3仍是普通整数加法，选择%c后才显示新编码对应的字符。

## 易错点

- 不要把小写字母i与数字1混淆。
- 题目没有要求字母循环回到a/A，不能擅自做26个字母的环绕。
