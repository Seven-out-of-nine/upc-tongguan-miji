## 题目

20203 夏边当艺术节评委

【题目描述】

夏边所在的高中每年校庆时都会举行艺术节，其中设立了“个人才艺奖”，分成预赛和决赛两个阶段。参赛选手展示个人才艺，评委围绕“内容、技巧、效果”三方面进行评分（百分制），然后计算平均分作为选手的最终成绩。在预赛阶段不会对分数进行排名，而是根据分数给出A~E的评级，最终评级为A的选手会进入决赛。评级规则是：平均成绩90分及以上，则评定为A；80分及以上，90分以下则为B；70分及以上，80分以下则为C；60分及以上，70分以下则为D；60分以下则为E。夏边今年有幸担任评委，因为他去年得了一等奖！（按规定，高中期间得过一等奖的同学不得重复参赛，但是可以担任评委）。现在夏边给出了选手的三项评分，你来编程评定级别吧！

【输入】

输入数据仅一行，包括三个数字，可能为小数，以空格分隔，分别表示内容、技巧和效果的成绩。

【输出】

相应的成绩评定，末尾换行。

注意：本题统一规定，浮点数运算用double类型。

例如:

**输入：**

```text
90 90 90
```

**输出：**

```text
A
```

## 解答

```c
#include <stdio.h>

int main(void) {
    double a, b, c; scanf("%lf%lf%lf", &a, &b, &c);
    double average = (a + b + c) / 3.0;
    char grade;
    if (average >= 90) grade = 'A';
    else if (average >= 80) grade = 'B';
    else if (average >= 70) grade = 'C';
    else if (average >= 60) grade = 'D';
    else grade = 'E';
    printf("%c\n", grade); return 0;
}
```

## 讲解

1. 三项成绩都用double读取，再求算术平均分。
2. 从高到低检查90、80、70、60四个分界，首次满足就确定等级。
3. 例如90、80、70平均80，属于B；平均59.9属于E。

## 知识点总结

- scanf的%lf：读取double变量。
- /3.0：求三项平均，而不是总分评级。
- else if：高等级满足后不再落到较低等级。
- char grade：等级用单个字母保存。

## 易错点

- 边界包括90、80、70、60本身。
- 不要把小数成绩存进int导致截断。
