## 题目

**描述**

判断整数的位数。

**输入**

一个不多于5位的正整数。

**输出**

如果不是符合要求的正整数，输出“Invalid input”；否则输出它是几位数，并逆序打印出各位数字。

例如:

**样例 1**

**输入：**

```text
23
```

**输出：**

```text
2
32
```

**样例 2**

**输入：**

```text
-100
```

**输出：**

```text
Invalid input
```

### 题目与实现说明

- 保存页的已提交代码把上限误写成10000；本解按题意“不多于5位”修正为99999。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    if (n <= 0 || n > 99999) {
        puts("Invalid input");
    } else {
        int copy = n;
        int digits = 0;
        while (copy > 0) {
            digits++;
            copy /= 10;
        }
        printf("%d\n", digits);
        while (n > 0) {
            printf("%d", n % 10);
            n /= 10;
        }
        printf("\n");
    }
    return 0;
}
```

## 讲解

1. 先确认n在1到99999之间，其他值输出Invalid input。
2. 用副本copy反复除以10，每除一次去掉一个数位，计数digits就是位数。
3. 例如100有3位；逆序时依次输出100%10、10%10、1%10，得到001，前面的0必须保留。

## 知识点总结

- **while条件循环**：while(条件)在每轮开始前检查条件，成立才执行循环体，结束后回到条件；一开始不成立则一轮也不执行。循环体需推进状态，例如copy/=10不断去掉数位，否则可能形成死循环。
- **复合赋值运算**：运算符与=组合在原变量上更新：copy/=10相当于copy=copy/10，count+=remaining相当于count=count+remaining。这是赋值而非比较，后续-=、*=等属于同一写法。

## 易错点

- 五位正整数的最大值是99999，不能误限制到10000。
- 若把逆序结果保存成整数，100会变成1而丢掉两个0。
