## 题目

【题目描述】

在西方，星期五和数字13都代表着坏运气，两个不幸的个体最后结合成超级不幸的一天。所以，不管哪个月的13日又恰逢星期五就叫“黑色星期五”。输入某年年号和该年的元旦是星期几（1~7），输出该年所有的“黑色星期五”的日期（年/月/日）。

【输入】

仅一行。包含两个整数，第1个数是一个4位数，表示年份，第2个数表示该年元旦是星期几（1~7）。

【输出】

有多行。所有的 “黑色星期五”的日期（年/月/日），每个日期占一行。

例如:

**输入：**

```text
2006 7
```

**输出：**

```text
2006/1/13
2006/10/13
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int year, weekday, days[12] = {31,28,31,30,31,30,31,31,30,31,30,31};
    scanf("%d%d", &year, &weekday);
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) days[1] = 29;
    for (int month = 0; month < 12; ++month) {
        if ((weekday + 12) % 7 == 5) printf("%d/%d/13\n", year, month + 1);
        weekday = (weekday + days[month]) % 7;
    }
    return 0;
}
```

## 讲解

1. 用days数组保存每月天数，若是闰年把2月改为29天。
2. weekday表示当前月1日的星期；13日比1日晚12天，因此(weekday+12)%7为5时是星期五。
3. 处理当前月后，把weekday增加本月天数再模7，得到下个月1日的星期。
4. 例如2006年1月1日为星期日7，13日星期为(7+12)%7=5，所以输出2006/1/13。

## 知识点总结

- **按月份推进日期状态**：将“当前月1日的星期”作为状态，处理完一个月后加上本月天数再模7，就得到下一月1日的星期。把月长存进数组，按闰年规则调整2月后，可以连续推算全年，不必对12个月分别写公式。

## 易错点

- 13日比1日晚12天，不是13天。
- 不要在闰年仍用28天的2月，否则3月以后星期都会偏移。
