## 题目

【题目描述】

从键盘输入一个不带空格的字符串str，再输入一个特定字符ch。编程输出ch在字符串str中**第一次**出现的位置，如果不存在，则输出0。

【输入】

一个不带空格的字符串str（长度小于等于100）和要查找的特定字符ch。

【输出】

ch在字符串str中第一次出现的位置（从1开始数，不是下标）。

例如:

**输入：**

```text
HelloWorld W
```

**输出：**

```text
6
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char s[101], ch; scanf("%100s %c", s, &ch);
    int position = 0;
    for (int i = 0; s[i]; ++i) if (s[i] == ch) { position = i + 1; break; }
    printf("%d\n", position); return 0;
}
```

[下载完整源码](../solutions/ch05-string-30.c)

## 讲解

1. 把答案先设为0，表示尚未找到。
2. 从左到右扫描，第一次匹配就记录i+1并退出循环。
3. 例如HelloWorld中W下标5，输出题目要求的位置6。

## 知识点总结

- i+1：把从0开始的下标换算为从1开始的位置。
- break：保证保留的是第一次匹配。
- position=0：未找到时直接输出规定的0。

## 易错点

- 不能直接输出下标。
- 找到后必须停止，否则会变成最后一次位置。
