## 题目

**描述**

让我们慢慢适应c语言。定义一个整型变量，赋初始值为5，把这个整型变量的值输出到屏幕上

**输入**

没有输入

**输出**

5

例如:

**输入：**

```text
没有输入
```

**输出：**

```text
5
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int value = 5;
    printf("%d\n", value);
    return 0;
}
```

[下载完整源码](../solutions/ch02-05.c)

## 讲解

1. 题目要求先定义变量，因此用 int value = 5 把5保存起来。
2. printf 读取 value 当前保存的值并输出。
3. 例如把 value 想象成贴着名字的盒子，这次盒子里放着5，所以屏幕显示5。

## 知识点总结

- 变量定义：int value 创建一个名为 value 的整数变量。
- 初始化：定义变量时写 = 5，保证变量从一开始就有确定的值。
- %d：printf 使用它输出 int 类型的十进制整数。

## 易错点

- 不要只输出固定字符串“5”而省略变量，题目练习的就是变量定义和初始化。
