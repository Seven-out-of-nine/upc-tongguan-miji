## 题目

**描述**

小通开始学习通信原理了，但是，他需要回顾小学学习过的整数的+、-、\*、/、%计算。下面出题，给出一个简单的算术表达式，从键盘任意输入两个整数，每个整数之间使用空格分隔，请小通给出结果。

**输入**

仅一行。两个整数。

**输出**

有多行。+、-、\*、/、%的运算结果，每个结果占一行。

提示：学会字符串中如何正确输出'%'符号

例如:

**输入：**

```text
10 3
```

**输出：**

```text
10+3=13
10-3=7
10*3=30
10/3=3
10%3=1
```

### 题目与实现说明

- 原题未给除数为0时的输出规则；这里按整数除法题通常约定，输入的除数非0，且计算结果在 long long 范围内。

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long a, b;
    scanf("%lld %lld", &a, &b);
    printf("%lld+%lld=%lld\n", a, b, a + b);
    printf("%lld-%lld=%lld\n", a, b, a - b);
    printf("%lld*%lld=%lld\n", a, b, a * b);
    printf("%lld/%lld=%lld\n", a, b, a / b);
    printf("%lld%%%lld=%lld\n", a, b, a % b);
    return 0;
}
```

## 讲解

1. 读入 a、b，依次计算加、减、乘、整数除法和余数。
2. 每一行同时输出原来的操作数、运算符和结果，构成题目要求的等式。
3. 例如 10 除以3得到商3、余数1，所以最后两行分别是 10/3=3 和 10%3=1。

## 知识点总结

- **long long与整数范围**：long long提供比常见int更大的整数范围，输入输出格式为%lld。参与运算的操作数也要足够宽；只在计算后把结果放进宽变量，不能补救先前已发生的溢出。
- **加减乘算术运算**：C用+、-、*表示加、减、乘，乘号不能省略。平方可写x*x，^是位运算而非乘方；计算结果可赋给变量，也可直接用于输出。
- **整数除法**：两个整数用/相除，得到向0截断的整数商，不保留小数，例如10/3=3、-7/3=-2。除数不能为0，结果也必须能被所用整数类型表示。
- **取余运算**：%求整数相除的余数。例如10%3=1，可表示的合法运算满足a=(a/b)*b+a%b。余数为0表示整除；判断奇数用n%2!=0以兼容负奇数，%10拆数位也是取余的应用。
- **格式字符串中的百分号**：printf把%当作格式控制起点，所以要在格式字符串里输出一个普通百分号，应写%%。%%不消耗后面的变量参数，例如%lld%%%lld依次输出整数、一个%、另一个整数。

## 易错点

- 合法输入必须保证 b 不为0，整数除法和取余都不能除以0。
- 整数除法向0截断，例如 -7/3 为-2，-7%3 为-1。
