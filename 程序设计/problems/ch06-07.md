## 题目

F11.03 字符移动【★】【函数+字符数组】

【题目描述】
请编一个函数Fun，其功能是把字符串中所有的字符（不包含末尾的换行符和'\\0'）前移一个位置，串中的第一个字符移到最后。

【输入】

仅一行。一行字符串，长度不超过80。

【输出】

移动后的字符串。
【提示】

**注意：本题只需提交Fun函数即可**

预设代码

前置代码

```text
#include <stdio.h>
#include <string.h>
#define N 81
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main( )
{ 
       char a[N];
       fgets(a,sizeof(a),stdin);
       Fun(a);
       printf("%s\n",a);
       return 0;
}
```

例如:

**样例 1**

**输入：**

```text
Mn.123xyz
```

**输出：**

```text
n.123xyzM
```

**样例 2**

**输入：**

```text
Abcde
```

**输出：**

```text
bcdeA
```

### 题目与实现说明

- 本地完整程序给80个字符及换行、结束符留足空间；平台的 Fun 也兼容字符串已经去掉换行的情况。

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char s[]) {
    s[strcspn(s, "\r\n")] = '\0';
    int n = (int)strlen(s);
    if (n <= 1) return;
    char first = s[0];
    for (int i = 0; i < n - 1; i++) s[i] = s[i+1];
    s[n-1] = first;
}
```

## 讲解

1. 先去掉行尾换行，再计算真正要移动的字符个数 n。
2. 保存第一个字符 first，否则左移后就找不回它了。
3. 让下标 1 到 n-1 的字符依次前移一格，再把 first 放入最后一个字符位置。
4. 例如 Abcde 左移后是 bcdeA；空串和单字符不需要移动。

## 知识点总结

- 字符变量 first 用于暂存即将被覆盖的值。
- s[i]=s[i+1] 把右边一个位置的字符复制到左边。
- 有效字符下标是 0 到 n-1，结束符仍位于 n。
- return; 在 void 函数中表示提前结束，不返回数值。

## 易错点

- 不要移动或覆盖结束符；原保存答案依赖读入换行，末行无换行时会出错。
