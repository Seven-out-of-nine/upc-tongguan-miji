## 题目

**描述**

在贝尔兰首都剧院有一个大小为n\*m米的矩形广场。在该市建市一周年之际，决定要为矩形广场铺上正方形花岗岩石板，每个石板的尺寸为a\*a。最少需要多少石板铺设该广场？允许覆盖的表面大于剧院广场，但广场必须得到完全覆盖，要求在铺设过程中不允许切碎石板，并且石板侧面应平行于正方形广场的边。

**输入**

仅一行，三个整数 n, m and a (1 ≤ n, m, a ≤ 105).

**输出**

需要的石板数目。

例如:

**输入：**

```text
6 6 4
```

**输出：**

```text
4
```

### 题目与实现说明

- 原网页上限原样写成“105”，没有上标格式。本解保留原题文字，并使用long long容纳较大的结果。

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long n, m, a;
    scanf("%lld %lld %lld", &n, &m, &a);
    long long rows = (n + a - 1) / a;
    long long columns = (m + a - 1) / a;
    printf("%lld\n", rows * columns);
    return 0;
}
```

[下载完整源码](../solutions/ch02-27.c)

## 讲解

1. 石板不能切割，因此分别看长、宽各需要多少块。
2. 长度n需要向上取整的n/a块，宽度m同理，把两个方向的块数相乘。
3. 例如6×6的广场用4×4石板，长宽各要2块，总数2*2=4，而不是只用面积36/16取整得到3。

## 知识点总结

- 正整数向上取整：(n+a-1)/a在有余数时多算一块，刚好整除时不会多算。
- long long：保存尺寸和行列乘积，乘积可能超过普通int的范围。
- 二维计数：每行columns块，共rows行，总数rows*columns。

## 易错点

- 不能用广场面积除以石板面积再向上取整，那样不能保证边界完全覆盖。
- 两个方向必须分别向上取整。
