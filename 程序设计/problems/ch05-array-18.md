## 题目

**【题目描述】**

一年一度的毕业季，马上要离开校园踏上工作岗位的同学们在拍摄完照片之后，大家有了一个共同的想法——那就是在毕业前互换礼物。到了约定的日子，同学们带来的礼物琳琅满目，都不知道该如何交换了。于是，在经过讨论后一致决定，大家将n个礼物放在一起统一编号为1，2，……，n。交换的规则是：1号礼物与n号礼物互换，2号礼物与n-1号礼物互换，以此类推，请帮助他们找到喜欢的礼物吧！

**【输入】**

有两行。第1行是一个整数n（1≤n≤1000），表示需要交换的礼物数。第2行是n个整数，分别表示现在安排给每位同学的礼物编号。

**【输出】**

仅一行。n个整数，表示n位同学互换礼物后的编号，礼物的编号间由空格分隔。

例如:

**输入：**

```text
10
3 6 5 1 7 4 10 8 2 9
```

**输出：**

```text
9 2 8 10 4 7 1 5 6 3
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, value[1000];
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) scanf("%d", &value[i]);
    for (int i = n - 1; i >= 0; --i) {
        if (i != n - 1) putchar(' ');
        printf("%d", value[i]);
    }
    putchar('\n');
    return 0;
}
```

[下载完整源码](../solutions/ch05-array-18.c)

## 讲解

1. 第一个位置应接收最后一个位置的礼物编号，第二个位置接收倒数第二个，整个数组反过来即可。
2. 先保存全部编号，再从下标n-1递减到0输出，原数组无需改动。
3. 例如2 4 7 1 5逆序后是5 1 7 4 2；中间的7位置不变。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 交换的是位置，不是把编号按数值大小排序。
- 只有一个元素时直接输出它；偶数个元素时同样全部逆序。
