## 题目

**【题目描述】**

杨辉三角形，又称贾宪三角形，帕斯卡三角形，是二项式系数在三角形中的一种几何排列。其实，中国古代数学家在数学的许多重要领域中处于遥遥领先的地位。中国古代数学史曾经有自己光辉灿烂的篇章，而贾宪三角的发现就是十分精彩的一页。

杨辉三角有如下性质：

（1）每行数字左右对称，由1开始逐渐变大，然后变小，回到1。

（2）第n行的数字个数为n个。

（3）每个数字等于上一行的左右两个数字之和。

**【输入】**

仅一行。一个正整数n（3≤n≤100），表示构造n行n列的杨辉三角。

**【输出】**

n行n列的杨辉三角（每个数据以6列的域宽显示）。

例如:

**输入：**

```text
5↵
```

**输出：**

```text
     1
     1     1
     1     2     1
     1     3     3     1
     1     4     6     4     1
```

### 题目与实现说明

- 原题n≤100，原参考答案int在较大行数会溢出；这里增加逐位大整数相加，以覆盖完整输入范围。

## 解答

```c
#include <stdio.h>

/* digits[j][k]保存当前行第j项的第k个十进制数字，低位在前。 */
int main(void)
{
    int n, digits[100][31] = {{0}};
    scanf("%d", &n);
    digits[0][0] = 1;
    for (int row = 0; row < n; ++row) {
        if (row > 0) {
            for (int col = row; col >= 1; --col) {
                int carry = 0;
                for (int k = 0; k < 31; ++k) {
                    int sum = digits[col][k] + digits[col - 1][k] + carry;
                    digits[col][k] = sum % 10;
                    carry = sum / 10;
                }
            }
        }
        for (int col = 0; col <= row; ++col) {
            int top = 30;
            while (top > 0 && digits[col][top] == 0) --top;
            for (int space = top + 1; space < 6; ++space) putchar(' ');
            for (int k = top; k >= 0; --k) putchar('0' + digits[col][k]);
        }
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 每行首尾为1，中间每项等于上一行对应位置与左邻位置之和。
2. 题目允许100行，靠近中间的系数超过long long，所以用数组逐位保存十进制数字，低位放在前面。
3. 从右往左更新各项，保证相加用到的左边项仍是上一行的数据。
4. 逐位相加时sum%10保存个位，sum/10进位；例如第5行中间的6来自上一行3+3。
5. 输出每项先补足最小6列宽度，再从最高位打印到最低位；大于6位时完整输出。

## 知识点总结

- **二维数组的两个下标**：int digits[100][31]可看作100行、每行31格的表；digits[col][k]先定位第col个数，再定位该数第k个十进制位。两个下标各有自己的范围，不能把行数与列数混用。
- **数组的整体零初始化**：声明数组时写={0}，或二维数组写={{0}}，会把第一个元素设为0，并将未列出的其余元素也补为0。它不是“只给第一格赋值、其他格不管”；计数表、标记表和这里的大整数空位都需要这种确定初值。
- **用数位数组表示大整数并进位**：普通整数装不下时，可用一格保存一个十进制数字，个位放在下标0。相加时从低位开始，把两个数位与carry相加，结果%10写回本位，结果/10留作下一位进位；输出则从最高非零位向低位扫描。
- **原地递推的更新方向**：若新数据依赖旧的左邻值，却要继续写回同一个数组，就从右往左更新。这样处理当前项时，左边还是上一行的数据；若从左往右更新，就会误用刚算出的本行值，改变原来的递推关系。

## 易错点

- 不能用int或long long保存题目全部范围的系数。
- 从左向右更新会读到本行刚改过的数据，算出的三角形会错误。
