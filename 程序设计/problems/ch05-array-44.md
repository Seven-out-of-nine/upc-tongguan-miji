## 题目

【题目描述】

程序定义了 4×4 的二维数组，请编写程序，给二维数组赋值，并使数组下三角元素（左上到右下的对角线及其左下角的元素）中的值乘以n 。

【输入】

有5行。前4行，每行4个整数，表示4×4 的二维数组，第5行输入一个整数n，表示数组下半三角元素要乘的数值。

【输出】

处理后的二维数组。每行4个数据，共4行。输出的数按照4位宽度来输出。

例如:

**输入：**

```text
1 2 3 4
2 2 3 4
3 2 3 4
4 2 3 4
0
```

**输出：**

```text
   0   2   3   4
   0   0   3   4
   0   0   0   4
   0   0   0   0
```

### 题目与实现说明

- 题干未给整数范围，本解使用long long扩大乘积范围；输入及乘积须在该类型范围内。

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long matrix[4][4], multiplier;
    for (int i = 0; i < 4; ++i)
        for (int j = 0; j < 4; ++j) scanf("%lld", &matrix[i][j]);
    scanf("%lld", &multiplier);
    for (int i = 0; i < 4; ++i) {
        for (int j = 0; j < 4; ++j) {
            if (j <= i) matrix[i][j] *= multiplier;
            printf("%4lld", matrix[i][j]);
        }
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 下三角包括主对角线和它左下方的元素，位置条件是列号j不大于行号i。
2. 读完4×4个元素后再读倍数n，逐个位置检查j<=i，满足条件才乘n。
3. 例如第0行只改第0列，第1行改第0、1列，最后一行四个元素全部修改。
4. 样例倍数为0，所以下三角全部变0，右上三角仍保留原值。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 主对角线也要乘，条件是j<=i，不是j<i。
- 题目要下三角，不能误改成i<=j的上三角。
