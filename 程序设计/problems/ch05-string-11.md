## 题目

10.11 字符出现的频率【★】

【题目描述】

从键盘输入一行文本，统计其中数字字符‘0’~‘9’出现的频率并输出。没出现的不需要输出。

【输入】

一行文本，长度不超过1000。

【输出】

按照从0到9顺序输出统计结果。每个数字的信息占一行，如“0:2”表示数字字符0出现了2次。

提示：利用统计的思想，会大大降低难度。

例如:

**输入：**

```text
Hello No 007.
```

**输出：**

```text
0:2
7:1
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int main(void) {
    char s[1003]; int count[10] = {0}; read_line(s, sizeof s);
    for (int i = 0; s[i]; ++i)
        if (s[i] >= '0' && s[i] <= '9') ++count[s[i] - '0'];
    for (int d = 0; d < 10; ++d) if (count[d]) printf("%d:%d\n", d, count[d]);
    return 0;
}
```

## 讲解

1. 建立10个计数格，依次对应数字字符0到9。
2. 读到数字就用字符减0得到格子编号，并累加。
3. 例如909中count[9]=2、count[0]=1，按编号顺序输出0:1和9:2。

## 易错点

- 先判断是数字再计算下标，避免把其他字符用作数组下标。
