## 题目

3.01 定义一个Dog类，实现并测试该类【★】

定义一个Dog类，包含age, weight等数据成员，以及对这些数据成员操作的方法。实现并测试这个类。

例如:

**输出：**

```text
Jack is a Dog who is 2 years old and 10 pounds weight
Now Jack is 7 years old and 20 pounds weight.
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Dog {
private:
    int age, weight;
public:
    Dog(int a, int w) : age(a), weight(w) {}
    int getAge() const { return age; }
    int getWeight() const { return weight; }
    void setAge(int a) { age = a; }
    void setWeight(int w) { weight = w; }
};
int main() {
    Dog Jack(2, 10);
    cout << "Jack is a Dog who is " << Jack.getAge() << " years old and "
         << Jack.getWeight() << " pounds weight\n";
    Jack.setAge(7);
    Jack.setWeight(20);
    cout << "Now Jack is " << Jack.getAge() << " years old and "
         << Jack.getWeight() << " pounds weight.\n";
    return 0;
}
```

[下载完整源码](../solutions/ch07-07.cpp)

## 讲解

1. 定义Dog，把年龄和体重设为私有数据。
2. 用构造函数Dog(2,10)创建Jack，初始年龄2、体重10。
3. 第一次通过get方法读取属性；再用set方法改为7和20，第二次输出反映修改后的状态。

## 知识点总结

- 构造函数与类同名，没有返回类型，在对象创建时自动执行。
- 冒号后的age(a),weight(w)是成员初始化列表，用输入参数初始化成员。
- get方法读取属性，set方法修改属性，这是常见的封装接口。

## 易错点

- 第一行weight后没有句点，第二行有句点，输出格式要按样例。
