## 题目

**描述**

完成第一个C语言程序，输出Hello world。

**输入**

没有输入

**输出**

Hello world

例如:

**输出：**

```text
Hello world
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    printf("Hello world\n");
    return 0;
}
```

[下载完整源码](../solutions/ch02-01.c)

## 讲解

1. 这道题没有输入，程序直接输出固定文字。
2. 把 Hello world 放在英文双引号内，交给 printf 输出。
3. 例如运行一次就得到 Hello world；末尾的 \n 让光标移动到下一行。

## 知识点总结

- #include <stdio.h>：引入标准输入输出头文件，本题才能使用 printf。
- int main(void)：程序从 main 开始执行，void 表示不接收参数。
- 字符串：双引号包围一串字符；\n 是一个换行转义字符。

## 易错点

- 大小写和空格必须与样例一致：Hello 的 H 大写，world 的 w 小写。
