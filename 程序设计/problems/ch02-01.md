## 题目

**描述**

完成第一个C语言程序，输出Hello world。

**输入**

没有输入

**输出**

Hello world

例如:

**输出：**

```text
Hello world
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    printf("Hello world\n");
    return 0;
}
```

[下载完整源码](../solutions/ch02-01.c)

## 讲解

1. 这道题没有输入，程序直接输出固定文字。
2. 把 Hello world 放在英文双引号内，交给 printf 输出。
3. 例如运行一次就得到 Hello world；末尾的 \n 让光标移动到下一行。

## 知识点总结

- **C程序入口与正常结束**：int main(void)是C程序的入口，花括号里的语句按顺序执行，void表示不接收参数。末尾return 0;表示正常结束。普通语句通常以英文分号结尾。
- **标准头文件与include**：#include <stdio.h>引入标准输入输出函数的声明，使编译器知道printf等函数怎样使用。include行末尾不写分号；使用其他标准库时再包含对应头文件。
- **printf输出**：printf(...)把指定内容写到标准输出，通常就是屏幕。它不会自动换行，要换行需在输出内容中明确写换行字符。
- **字符串字面量**：英文双引号包围的文字是字符串字面量，例如"Hello world"。引号界定文本，不会被输出；引号里的大小写、标点与空格都属于文本内容。
- **换行等转义字符**：反斜杠引入转义序列：\n表示一个换行字符，不是要输出的反斜杠与字母n。把它放在字符串末尾，就能让后续输出从新的一行开始。

## 易错点

- 大小写和空格必须与样例一致：Hello 的 H 大写，world 的 w 小写。
