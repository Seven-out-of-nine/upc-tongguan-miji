## 题目

**描述**

一个喷气式战斗机从航空母舰上的弹射器出发后的加速度a(单位：m/s<sup>2</sup>)，其中已知飞机的起飞速度v(km/h)和 弹射器对飞机从停止到起飞的加速的距离s(单位：m)。这里假定飞机做匀加速运动.还需要考虑的是战斗机加速到起飞速度的时间t(单位：s)。相关公式如 下：v=at；s=1/2\*a\*t<sup>2</sup>；其中v是速度，a是加速度，t是时间，s是距离。编写程序计算该飞机的加速度。

**输入**

仅一行。两个整数，分别表示飞机的起飞速度v(km/h)和弹射器对飞机从停止到起飞的加速的距离s(m)。

**输出**

仅一行。加速度a，保留2位小数。

## 解答

```c
#include <stdio.h>

int main(void)
{
    double speed_kmh, distance;
    scanf("%lf %lf", &speed_kmh, &distance);
    double speed = speed_kmh / 3.6;
    double acceleration = speed * speed / (2 * distance);
    printf("%.2f\n", acceleration);
    return 0;
}
```

[下载完整源码](../solutions/ch02-22.c)

## 讲解

1. 题目给速度的单位是km/h，先除以3.6换成m/s，与距离的米统一。
2. 由v=at和s=at²/2消去t，得到a=v²/(2s)。
3. 例如36km/h就是10m/s，若弹射距离为5m，加速度就是10*10/(2*5)=10，输出10.00。

## 知识点总结

- 单位换算：1km/h=1000/3600m/s，所以用输入速度除以3.6。
- double：保存换算后可能不是整数的速度与加速度。
- 表达式括号：2*distance作为完整分母，不能写成speed*speed/2*distance。

## 易错点

- 不换算km/h就直接平方，会使答案放大3.6²倍。
- 距离s必须为正，公式才有意义。
