## 题目

【函数+字符数组】F10.2 删除字符【★】

【题目描述】

编写函数Fun，其功能是：将字符串s中除了下标为奇数，同时 ASCII 值也为奇数的字符之外，其余的所有字符都删除，将剩余字符所形成的一个新串存放在数组t中。

【输入】

仅一行。字符串s（长度不超过1000）。

【输出】

仅一行。处理完后的字符串。

预设代码

前置代码

```text
#include <stdio.h>
#include <string.h>
#define N 1000
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    char s[N + 5], t[N + 5];
    scanf("%s", s);
    Fun(s, t);
    printf("%s\n", t);
    return 0;
}
```

例如:

**输入：**

```text
ABCDEFG12345
```

**输出：**

```text
135
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char s[], char t[]) {
    int j = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (i % 2 == 1 && (unsigned char)s[i] % 2 == 1) {
            t[j++] = s[i];
        }
    }
    t[j] = '\0';
}
```

## 讲解

1. 用 i 从左向右检查原字符串，用 j 记录新字符串已经保存了几个字符。
2. 只有“下标为奇数”和“字符的 ASCII 值为奇数”同时成立，才把 s[i] 放入 t[j]。
3. 例如 ABCDEFG12345 中，数字 1、3、5 位于奇数下标，且 ASCII 值也是奇数，所以结果为 135。
4. 扫描完成后写 t[j] = '\0'，告诉输出函数新字符串在这里结束。

## 知识点总结

- 数组下标从 0 开始，第二个字符的下标才是 1。
- % 是求余运算，i % 2 == 1 用来判断非负下标为奇数。
- && 表示两个条件都必须成立。
- t[j++] 先使用当前 j 存字符，再让 j 加 1。
- 字符串末尾的 '\0' 是结束标记，必须给它留一个位置。

## 易错点

- 原保存答案未补字符串结束符，可能输出垃圾字符；这里明确补上。
