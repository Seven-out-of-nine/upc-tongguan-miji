## 题目

**描述**

小明买了一箱n个苹果，很不幸箱子里有一条虫子，虫子每x小时可以吃掉一个苹果，假设虫子在吃完一个苹果之前不会吃另一个，那么经过y小时还有多少个完整的苹果？

输入

三个整数分别是：苹果总数n,吃一个苹果的时间x小时，经过的时间y小时，用空格隔开三个数据。

输出

输出一个整数

例如:

**输入：**

```text
10 40 7
```

**输出：**

```text
9
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long n, x, y;
    scanf("%lld %lld %lld", &n, &x, &y);
    long long damaged = y / x;
    if (y % x != 0) damaged++;
    long long whole = n - damaged;
    if (whole < 0) whole = 0;
    printf("%lld\n", whole);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-06.c)

## 讲解

1. 只要虫子开始咬一个苹果，这个苹果就不再完整，因此受损苹果数需要向上取整。
2. 先求y/x个已经吃完的苹果；如果y%x不为0，说明还在吃下一个，受损数再加1。
3. 例如10个苹果、每个40小时、经过7小时，虽然还没吃完一个，但已有1个受损，所以剩9个完整苹果。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 求的是完整苹果，不能只减掉已经全部吃完的数量。
- 吃苹果所需时间x必须大于0。
