## 题目

2.02 C++程序实现函数重载【★】

编写一个C++风格的程序，建立一个被称为sroot()的函数，返回其参数的二次方根。重载sroot()3次，让它返回整数、长整数与双精度数的二次方根（计算二次方根时，可以使用标准库函数sqrt()）。

例如:

**样例 1**

**输入：**

```text
2 3 4
```

**输出：**

```text
1,1,2
```

**样例 2**

**输入：**

```text
1 2 3
```

**输出：**

```text
1,1,1.73205
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

int sroot(int x) { return static_cast<int>(sqrt(x)); }
long sroot(long x) { return static_cast<long>(sqrt(x)); }
double sroot(double x) { return sqrt(x); }
int main() {
    int i;
    long l;
    double d;
    cin >> i >> l >> d;
    cout << sroot(i) << ',' << sroot(l) << ',' << sroot(d) << '\n';
    return 0;
}
```

[下载完整源码](../solutions/ch07-04.cpp)

## 讲解

1. 给sroot定义三个版本，参数分别是int、long和double。
2. 调用时编译器按实参类型选择版本，三个函数都用sqrt计算平方根。
3. int和long版本再把结果转回整数，double版本保留小数。
4. 例如2、3、2.25分别得到1、1、1.5。

## 知识点总结

- **函数重载与参数匹配**：C++允许同一作用域内函数同名，但参数类型或个数必须不同；仅返回类型不同不构成重载。调用sroot(i)、sroot(l)、sroot(d)时，编译器根据实参的int、long、double类型选择匹配版本，这种选择在编译期完成。

## 易错点

- 三个输入都应非负；long的位数与平台有关，不要把long固定理解为64位。
