## 题目

【题目描述】

周末商场促销呢，某品牌服装既可以买套装，也可以买单件。若买的不少于50套，每套80元；不足50套的每套90元，只买上衣每件60元，只买裤子每条45元。

【输入】

计划购买的上衣数量 a 和裤子的数量 b。

【输出】

应该付的款 m 。

例如:

**输入：**

```text
30 30
```

**输出：**

```text
2700
```

### 题目与实现说明

- 按恰好购买计划数量解释，不额外购买多余衣物以凑50套；保存页参考行为也采用这一解释。

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long shirts, trousers;
    scanf("%lld %lld", &shirts, &trousers);
    long long suits = shirts;
    if (trousers < suits) suits = trousers;
    long long suit_price = 90;
    if (suits >= 50) suit_price = 80;
    long long cost = suits * suit_price + (shirts - suits) * 60
                   + (trousers - suits) * 45;
    printf("%lld\n", cost);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-26.c)

## 讲解

1. 一套由一件上衣和一条裤子组成，所以能凑的套数是两者数量的较小值。
2. 一套的价格始终比单买一对的60+45=105元便宜，因此先尽量按套买，再处理剩余单件。
3. 例如60件上衣、30条裤子组成30套，共2700元；剩下30件上衣1800元，总额4500元。

## 知识点总结

- 求较小值：suits不能超过shirts，也不能超过trousers。
- 条件单价：套数至少50用80元，否则用90元。
- 算式拆项：套装费用、剩余上衣费用、剩余裤子费用分别计算后相加，便于核对。

## 易错点

- 50套的阈值看的是套数，不是衣服总件数。
- 不要把裤子单价45和上衣单价60写反。
