## 题目

F11.08 删除指定字符【★★】【函数+字符数组】

【题目描述】

编写函数Fun，其功能是：从字符串中删除指定的字符，区分大小写（即：同一字母的大、小写视为不同字符）。

【输入】

有两行。第1行是一个字符串（长度不超过1000）。第2行是需要删除的字符。

【输出】

仅一行。删除指定字符后的字符串。

预设代码

前置代码

```text
#include <stdio.h>
#include <string.h>
#define N 1000
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    char str[N + 5], ch;
    fgets(str,N,stdin); 
    str[strlen(str)-1]=0; //覆盖掉\n
    scanf("%c", &ch);
    Fun(str, ch);
    printf("%s\n", str);
    return 0;
}
```

例如:

**输入：**

```text
turbo c and borland c++
n
```

**输出：**

```text
turbo c ad borlad c++
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char s[], char ch) {
    int k = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] != ch) s[k++] = s[i];
    }
    s[k] = '\0';
}
```

```c
#include <stdio.h>
#include <string.h>

void Fun(char s[], char ch) {
    int k = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] != ch) s[k++] = s[i];
    }
    s[k] = '\0';
}

int main(void) {
    char s[1002], ch;
    fgets(s, sizeof s, stdin);
    s[strcspn(s, "\r\n")] = '\0';
    scanf("%c", &ch);
    Fun(s, ch);
    puts(s);
    return 0;
}
```

## 讲解

1. 用 i 检查原字符串的每一位，用 k 指向结果下一次写入的位置。
2. 遇到不等于 ch 的字符就保留；遇到 ch 就跳过，不增加 k。
3. 例如 AaA 删除 A，两个大写 A 被跳过，小写 a 保留，结果为 a。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 不能用无条件 strlen(s)-1 删除行尾，末行没有换行时会误删真实字符。
