## 题目

10.12 单词统计【★】

【题目描述】

对于英文写作者来说，尤其是写短文、小说之类的内容，都需要有一个固定的统计字数的要求，知道自己但文章中写了多少单词。假设用空格或换行分开的字符串称为单词。现在请编写一个程序，输入多行字符串，直到遇到了单词 “stop” 时才停止。最后输出单词的数量。用于分割单词的空格或换行可能多于1个。

【输入】

多行字符串，字符总数不超过1000。

【输出】

单词的数量。

例如:

**输入：**

```text
china abc
sum bstop stop
```

**输出：**

```text
4
```

## 解答

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char word[1001]; int count = 0;
    while (scanf("%1000s", word) == 1) {
        if (strcmp(word, "stop") == 0) break;
        ++count;
    }
    printf("%d\n", count); return 0;
}
```

[下载完整源码](../solutions/ch05-string-12.c)

## 讲解

1. 用%s逐个读单词，空格和换行自然被跳过。
2. 读到完整单词stop就停止，其他单词将count加1。
3. 例如bstop不是停止标志，所以bstop stop的统计结果为1。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 不要把含有stop的词当作停止词。
