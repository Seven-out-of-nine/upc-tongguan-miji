## 题目

**描述**

小明的朋友贝贝约他下周一起去看展览，但小明每周的1，3，5必须上课，请帮小明判断他能否接受贝贝的邀请，如果能输出“YES”；如果不能则输出”NO“

**输入**

用数字1到7表示从星期一到星期日。

**输出**

能输出YES，不能输出NO

例如:

**输入：**

```text
1
```

**输出：**

```text
NO
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int day;
    scanf("%d", &day);
    if (day == 1 || day == 3 || day == 5) puts("NO");
    else puts("YES");
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-23.c)

## 讲解

1. 找出不能赴约的三个日期：星期一、三、五。
2. 输入day只要等于1、3、5中的一个，就输出NO；其余合法星期可以赴约。
3. 例如输入3，要上课所以输出NO；输入7不在三个上课日中，输出YES。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 不能只判断奇偶，星期日7也是奇数，但小明可以赴约。
