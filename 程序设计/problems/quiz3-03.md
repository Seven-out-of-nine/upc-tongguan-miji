## 题目

3030 66666

题目描述

66666是2015年的流行词，起源无从考究，但总体意思就是“玩的很溜”，夸奖的意思。同学们的宿舍文化中66666表现在以下几个方面:

1.在同学们的语气中,我觉得应该是"赞赞赞赞赞"的意思。

2.有时候表示对某些人干一件事非常熟练的一种开着玩笑的“赞美”。

3.有时候，还表示对于一些“空想”、“不切实际”的想法的带着玩笑的“嘲讽”。

当然，大神们在做出了别的同学完成不了的题目的时候，大家都衷心的说：66666

输入

输入有多组数据。

每组数据包含一个整数，位数为N(0 &lt; N &lt; 30)，表示一条评论，占一行。

输出

对应输出多组结果，每位数据上包含一个6，就输出一个“zan!”，如果该行数据没有6就输出一个空行

例如:

**输入：**

```text
66786
12345789
162636666
```

**输出：**

```text
zan!zan!zan!

zan!zan!zan!zan!zan!zan!
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char s[31];
    while (scanf("%30s", s) == 1) {
        for (int i = 0; s[i]; ++i) if (s[i] == '6') printf("zan!");
        putchar('\n');
    }
    return 0;
}
```

[下载完整源码](../solutions/quiz3-03.c)

## 讲解

1. 把每条评论作为数字字符串读取，避免近30位整数超出整型范围。
2. 逐个检查字符，遇到6就输出一次zan!，不添加分隔符。
3. 例如66786含3个6，输出zan!zan!zan!；没有6仍需换行。

## 知识点总结

- char数组：只需判断每位字符，无须计算整数值。
- s[i]=='6'：比较的是数字字符6。
- 循环后统一换行：确保每组评论恰好对应一行输出。

## 易错点

- 不能用int读入，题目允许的位数远超int。
- 没有6时也必须输出空行。
