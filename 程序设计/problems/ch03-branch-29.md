## 题目

【题目描述】

输入一个整数，判断其奇偶性。

【输入】

整数n。

【输出】

n是奇数或n是偶数。注意输出格式。

例如:

**输入：**

```text
3
```

**输出：**

```text
3是奇数
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long n;
    scanf("%lld", &n);
    if (n % 2 == 0) printf("%lld是偶数\n", n);
    else printf("%lld是奇数\n", n);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-29.c)

## 讲解

1. 能被2整除的整数是偶数，其余整数是奇数。
2. 计算n%2，余数为0就输出偶数，否则输出奇数。
3. 例如3%2不为0，输出3是奇数；0%2等于0，所以0是偶数。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 判断奇数应使用n%2!=0，不能只检查==1，因为负奇数的余数可能是-1。
