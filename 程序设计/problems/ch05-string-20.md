## 题目

【题目描述】

索马里海盗是一群专门在海上抢劫其他国船只的犯罪者。联合国安理会决定在索马里境内和境外对海盗进行打击。现在安插在索马里海盗内部的内线已经获得了海盗的QQ加密之后的密码。

传言索马里海盗痛恨数字，所以他们的QQ密码从来都不包含任何数字。给定几行加密了的海盗QQ密码，你被要求对获得的加密密码进行破译。破译规则是删除这些密码中的数字并将其余字符按照原来的顺序打印出来。这样联合国安理会就可根据索马里海盗QQ的密码截取海盗之间的通信。

【输入】

有多行。第一行一个整数T（0&lt;T&lt;50），表示有T组加密了的海盗QQ密码。接下来有T行，每行表示一个加密了的海盗QQ密码。密码的长度最小为1，最长为100。密码只由数字、英文字母和空格组成。

【输出】

对于每个候选的密码，删除所有的数字并在一行上输出余下的字符。

提示：处理回车符。

例如:

**输入：**

```text
2
BeatLA123
U12P34C 56A7C8M 9CLUB
```

**输出：**

```text
BeatLA
UPC ACM CLUB
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int main(void) {
    int t, ch; scanf("%d", &t);
    while ((ch = getchar()) != '\n' && ch != EOF) {}
    while (t--) {
        char s[103]; read_line(s, sizeof s);
        for (int i = 0; s[i]; ++i) if (s[i] < '0' || s[i] > '9') putchar(s[i]);
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 先读组数并处理这一行剩余换行。
2. 每个密码整行读入，扫描时跳过0到9的数字，其余字符立即输出。
3. 例如U12P34C 56会保留UPC和一个空格。

## 知识点总结

- s[i]<'0'
- s[i]>'9'：不在数字范围内才保留。
- while(t--)：每个测试密码单独处理。
- putchar('
')：即使整串都是数字也输出一个空行。

## 易错点

- 输入中的空格必须保留，不能使用按单词读取的%s。
