## 题目

【题目描述】

已知有两个整数方阵a和b，方阵阶数为n(n&lt;100)，求方阵a和b的加法矩阵c。例如当n=3时，矩阵int a\[3\]\[3\]，矩阵int b\[3\]\[3\]。 矩阵的数据由用户输入。输出新的矩阵c=a+b。 输出格式： c00 c01 c02 c10 c11 c12 c20 c21 c22 每两个数字之间有1个空格。

【输入】

有多行。第一行是一个整数n，表示方阵a和b的阶数，接下来前n行n列数据表示方阵a的数据，最后n行n列表示方阵b的数据。

【输出】

有n行n列，表示方阵a和b的加法矩阵c。

【提示】

**输出时每行最后不能有空格**

例如:

**输入：**

```text
3
1 2 3
4 5 6
7 8 9
7 8 9
4 5 6
1 2 3
```

**输出：**

```text
8 10 12
8 10 12
8 10 12
```

### 题目与实现说明

- 采用long long容纳常见int输入相加后的结果；题干未明确整数上界。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n;
    long long matrix[100][100], value;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) scanf("%lld", &matrix[i][j]);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j) { scanf("%lld", &value); matrix[i][j] += value; }
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            if (j) putchar(' ');
            printf("%lld", matrix[i][j]);
        }
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 矩阵加法是同一行、同一列的两个元素相加，结果矩阵大小不变。
2. 先读入第一个矩阵，读第二个矩阵时就把当前值加到第一个矩阵对应位置，无需再存完整第二个矩阵。
3. 例如2×2矩阵首行1 2与3 4相加，结果首行是4 6，第二行也按对应位置处理。
4. 输出每行时只在第2个及后续元素前打印空格，严格保证行末没有空格。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 不能把整行总和当成矩阵加法结果，每个坐标独立相加。
- n行读取完第一个矩阵后再读取第二个，不能交替按行读两个矩阵。
