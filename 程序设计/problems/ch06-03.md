## 题目

【函数+字符数组】F10.4 组新串【★★】

【题目描述】

编写函数Fun，其功能是：逐个比较两个字符串a和b对应位置中的字符，把ASCII值大或相等的字符依次存放到数组c中，形成一个新的字符串。

【输入】

有两行。每行是一个字符串（长度都不超过1000）。

【输出】

仅一行。合并后的新串。

预设代码

前置代码

```text
#include <stdio.h>
#include <string.h>
#define N 1000
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    char a[N + 5], b[N + 5], c[N + 5];
    fgets(a,N,stdin);
    fgets(b,N,stdin);
    Fun(a, b, c);
    puts(c);
    return 0;
}
```

例如:

**输入：**

```text
aBCDeFgH
ABcd
```

**输出：**

```text
aBcdeFgH
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char a[], char b[], char c[]) {
    a[strcspn(a, "\r\n")] = '\0';
    b[strcspn(b, "\r\n")] = '\0';
    int na = (int)strlen(a), nb = (int)strlen(b);
    int n = na > nb ? na : nb;
    for (int i = 0; i < n; i++) {
        if (i >= na) c[i] = b[i];
        else if (i >= nb) c[i] = a[i];
        else c[i] = a[i] >= b[i] ? a[i] : b[i];
    }
    c[n] = '\0';
}
```

## 讲解

1. 先去掉 fgets 可能读入的行末换行，避免把它当成要比较的字符。
2. 在两个串都还有字符的位置，比较 ASCII 值，把较大的放入 c。
3. 一个串用完后，较长串剩余的字符直接保留。
4. 例如 aBCDeFgH 与 ABcd 比较，前四位得到 aBcd，后面保留 eFgH，结果是 aBcdeFgH。

## 知识点总结

- **strcspn定位分隔字符**：strcspn(a,"\r\n")给出从a开头到第一个回车或换行之前的长度；若没有这些字符，则返回整串长度。在该下标写'\0'可截去行尾；这会截断第一个匹配处分隔后的所有内容，只适用于相应输入约定。

## 易错点

- 样例表明长度可以不同，不能只处理两个串共有的部分。
