## 题目

【函数】F7.06 浮点数四舍五入【★】

【题目描述】

请编一个将浮点数四舍五入的函数fun，其功能是使浮点数保留2位小数，并对第3位进行四舍五入（规定实型数为正数）。

例如：实型数为1234.567，则函数返回1234.570000；实型数为1234.564，则函数返回1234.560000。

【输入】

一个浮点数。

【输出】

精确到小数点后面2位的浮点数。

前置代码：

```text
#include <stdio.h>
#include <math.h>
#include <bits/stdc++.h>
using namespace std;
```

后置代码：

```text
int main( )
{   double  a;
    scanf ( "%lf", &a );
    printf ( "%lf\n", fun ( a ) );
    return 0;
}
```

例如:

**输入：**

```text
1234.567
```

**输出：**

```text
1234.570000
```

### 题目与实现说明

- 为修正常见十进制边界如1.005被二进制浮点表示略低的问题，中间值仅向上移动一个double可表示步长，不使用固定epsilon；原main的double接口仍无法区分读入后变成同一double值的两个十进制输入。

    double shifted = a * 100.0 + 0.5;

## 讲解

1. 题目规定输入为正数，先将a乘100，把保留两位小数变成取整问题。
2. 给放大后的数加0.5，理论上再向下取整即可；但1.005的double表示稍小，计算可能得到略低于101的数。
3. nextafter把这个中间值向更大方向移动一个可表示的最小步长，补偿常见的舍入边界误差；随后floor取整，除以100.0恢复小数点。
4. 例如1234.567返回1234.57；1.005经过边界补偿返回1.01，main仍按默认6位小数显示。

## 知识点总结

- **用缩放与取整保留小数位**：对正数保留两位小数，可先乘100、加0.5，再用floor向下取整，最后除以100.0。例如12.344理论上变为1234.4，加0.5后取整1234，恢复为12.34；这一步改变的是数值，而不只是输出格式。
- **nextafter与相邻浮点值**：nextafter(x,HUGE_VAL)取得比x稍大的下一个double可表示值。本题把加0.5后的中间值只向上移动这样一个步长，修正常见边界如1.005的表示偏差；这不是任意加入固定epsilon，也不能恢复读入double时已经丢失的十进制信息。

## 易错点

- 题目要求函数先完成舍入，不能只把main改成%.2f。
- 原题规定正数，此规则不应直接套用于负数的四舍五入。
- double接口不能恢复已经丢失的十进制信息，极近边界且读入后无法区分的输入仍受表示精度限制。
