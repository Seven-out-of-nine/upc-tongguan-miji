## 题目

**描述**

超市前放置了一个硬币处理机，可以帮你把零钱转换为存款单。在实际应用中，机器中将有相应装置自动识别并计算你的零钱的数目，但是我们现在只能先进行一个手工的小实验，由你自己输入每种硬币的数目。依次输入1元、5角、1角的零钱的个数，然后编写程序将其转换成存款单。例如输入三个整数3 10 25，则表示有3个1元硬币、10个5角硬币和25个1角的硬币，则输出存单金额，如对上例的输入，输出为Dollars=10 Change=50表示存单上的整数金额为10元，零钱金额为50分。

**输入**

仅一行。三个整数，依次表示1元、5角、1角的零钱的个数。

**输出**

有两行。分别表示存单金额的整数金额（单位：元）和零钱金额（单位：分）。

例如:

**输入：**

```text
3 10 25
```

**输出：**

```text
Dollars=10
Change=50
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long one_yuan, five_jiao, one_jiao;
    scanf("%lld %lld %lld", &one_yuan, &five_jiao, &one_jiao);
    long long cents = one_yuan * 100 + five_jiao * 50 + one_jiao * 10;
    printf("Dollars=%lld\nChange=%lld\n", cents / 100, cents % 100);
    return 0;
}
```

[下载完整源码](../solutions/ch02-25.c)

## 讲解

1. 先统一换算成“分”：1元=100分，5角=50分，1角=10分。
2. 把三种硬币对应的分数相加得到总金额cents。
3. 例如3、10、25对应300+500+250=1050分，除以100得10元，余50分。

## 知识点总结

- 整数表示金额：以分为单位就不需要用浮点数，避免小数表示带来的误差。
- 取整与取余：cents/100得到整元，cents%100得到不足1元的分数。
- 多行输出：用\n让Dollars和Change各占一行。

## 易错点

- 输入是各种硬币的“个数”，不是已经换算后的元、角、分金额。
