# \[5.03\]寻找不一样的信号★★

来源：【测验】第3章 part1分支.html，第3题。

## 题目

**描述**

三个无线信号：A，B，C。这三个信号中，有一个信号与其他两个信号的强度是不一样，要求找出这个不一样的信号，输出他的代号。

**输入**

1 1 2

**输出**

C

例如:

**输入：**

```text
1 1 2
```

**输出：**

```text
C
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);
    if (a == b) {
        puts("C");
    } else if (a == c) {
        puts("B");
    } else {
        puts("A");
    }
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-03.c)

## 讲解

1. 题目保证三个信号中恰有两个强度相同，因此只需找出相同的那一对。
2. a==b时不同的是C；否则若a==c，不同的是B；剩下的情况不同的是A。
3. 例如1、1、2中a==b成立，所以输出信号代号C，而不是强度2。

## 知识点总结

- ==：判断是否相等，和给变量赋值的单个=不同。
- 互斥分支：else if只在前一个条件不成立时再检查。
- puts：输出一个字符串并自动换行，本题用来输出单个代号。

## 易错点

- 输出大写A/B/C，不要输出数值。
- 判断方法依赖“恰好两个相同”的题目保证，不能直接用于三个都不同的输入。
