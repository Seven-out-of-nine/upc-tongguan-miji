## 题目

【题目描述】

输入一个实数，不使用绝对值函数计算并输出该实数的绝对值。

【输入】

一个实数。

【输出】

该实数的绝对值。

例如:

**输入：**

```text
-3.5
```

**输出：**

```text
3.500000
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double value;
    scanf("%lf", &value);
    if (value < 0) value = -value;
    if (value == 0) value = 0.0;
    printf("%.6f\n", value);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-28.c)

## 讲解

1. 绝对值表示数到0的距离：负数取相反数，非负数保持原样。
2. 因此只需要在value<0时执行value=-value。
3. 例如-3.5变成3.5，按样例保留6位小数，显示3.500000。

## 知识点总结

- 单目负号-：-value表示value的相反数，而不是减去另一个变量。
- if：只对负数修改；正数不进入分支，值不变。
- %.6f：固定输出小数点后6位，以匹配样例。

## 易错点

- 题目限制不能调用绝对值函数，本解没有使用fabs或abs。
- 额外把浮点负零规范为0，避免显示-0.000000。
