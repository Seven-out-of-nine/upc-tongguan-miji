## 题目

10.03 字符变换【★】

【题目描述】

小明在录入一篇英文文献时由于键盘误操作，事先按下了CapsLock（大写锁定）键，然后又按照平时的录入习惯进行操作。结果录入的内容里面，原本应该是英文大写的地方都变成了小写，而原来应该是英文小写的地方都变成了大写。如果重新录入的话实在太可怕了！

请你帮小明设计一个程序，可以将字符串中的大写英文字母转换成对应的小写英文字母，而将小写英文字母转换成对应的大写英文字母，其余字符保持不变。

【输入】

任意一个字符串（长度小于等于80），以换行结束。

【输出】

转换后的字符串。

例如:

**输入：**

```text
i AM A STUDENT.i AM 19.
```

**输出：**

```text
I am a student.I am 19.
```

## 解答

```c
#include <stdio.h>

void read_line(char s[], int size) {
    if (!fgets(s, size, stdin)) { s[0] = '\0'; return; }
    int i = 0;
    while (s[i] && s[i] != '\n') ++i;
    int end = i;
    if (s[i] == '\n' && i > 0 && s[i - 1] == '\r') --end;
    s[end] = '\0';
}
int main(void) {
    char s[83]; read_line(s, sizeof s);
    for (int i = 0; s[i]; ++i) {
        if (s[i] >= 'a' && s[i] <= 'z') s[i] = s[i] - 'a' + 'A';
        else if (s[i] >= 'A' && s[i] <= 'Z') s[i] = s[i] - 'A' + 'a';
    }
    puts(s); return 0;
}
```

## 讲解

1. 逐个检查行中的字符。
2. 小写字母减去a得到0到25的序号，再加A变成对应大写；大写则反过来。
3. 例如aB!变为Ab!，感叹号不属于两种字母范围，因此保持原样。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 两次转换须用else if连接，否则刚变成大写又会被改回去。
