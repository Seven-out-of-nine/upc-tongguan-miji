## 题目

**描述**

某日，国家安全局获得一份珍贵的材料，上面记载了一个即将进行的恐怖活动的信息。不过，国家安全局没法获知具体的时间，因为材料上的时间使用的是LINUX的时间戳，即是从2011年1月1日0时0分0秒开始到该时刻总共过了多少秒。此等重大的责任现在落到了小通的肩上，给出小通该时间戳，小通能计算出恐怖活动在哪一天实施吗？（为了简单起见，规定一年12个月，每个月固定都是30天）。

**输入**

仅一行。一个整数n，表示从2011年1月1日0时0分0秒开始到该时刻过了n秒。

**输出**

仅一行。三个整数y、m、d，分别表示恐怖活动在y年m月d日实施。

例如:

**输入：**

```text
123456789
```

**输出：**

```text
2014 12 19
```

### 题目与实现说明

- 题中把它称作LINUX时间戳，但其起点和固定每月30天的规则是本题自定义的；本解严格遵守题目规则。

## 解答

```c
#include <stdio.h>

int main(void)
{
    long long seconds;
    scanf("%lld", &seconds);
    long long days = seconds / 86400;
    long long year = 2011 + days / 360;
    long long month = days % 360 / 30 + 1;
    long long day = days % 30 + 1;
    printf("%lld %lld %lld\n", year, month, day);
    return 0;
}
```

[下载完整源码](../solutions/ch02-24.c)

## 讲解

1. 一天有24*60*60=86400秒，先把秒数除以86400，得到已过的完整天数。
2. 题目规定每年360天、每月30天：完整年数用days/360，年内月份用days%360/30。
3. 例如days=30时，已经过去一个整月，所以日期是2011年2月1日；月份和日期都要从1开始。

## 知识点总结

- long long：秒数可能较大，使用较宽的整数类型保存和计算。
- 商和余数：/求完整单位数，%保留不足一个单位的剩余部分。
- 从0到1的换算：已经过0天对应1日，所以求完余数后加1。

## 易错点

- 这里一年固定360天，不要按真实公历或Unix时间库计算。
- 这是以2011年为起点的题目自定义时间戳，与常见1970年起点不同。
