# 8.32 出现最多的数字【★★】

[学习首页](../README.md) · [本章目录](../chapters/ch05-array/README.md) · [知识点索引](../知识点索引.md)

来源：【测验】第5章 part1数组.html，第32题。

## 题目

【题目描述】

给定一系列整数，对所有整数的每一位数字统计0~9各个数字的出现次数，求出现次数最多的数字。

【输入】

有两行，第1行是整数n（1≤n≤100)，表示有n个整数；第2行是n个整数。

【输出】

有两行。第1行输出出现最多的次数。第2行输出出现最多的数字d（如果d不唯一，要由小到大列出全部，每个数据以2列的域宽显示）。

例如:

**输入：**

```text
3
1234 2345 3456
```

**输出：**

```text
3
 3 4
```

### 题目与实现说明

- 题目只说“整数”未写位数上界，程序按普通整数的十进制输入处理；字符缓冲区可容纳127位。

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, count[10] = {0};
    char number[128];
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        scanf("%127s", number);
        for (int j = 0; number[j] != '\0'; ++j)
            if (number[j] >= '0' && number[j] <= '9') ++count[number[j] - '0'];
    }
    int maximum = 0;
    for (int digit = 0; digit < 10; ++digit)
        if (count[digit] > maximum) maximum = count[digit];
    printf("%d\n", maximum);
    for (int digit = 0; digit < 10; ++digit)
        if (count[digit] == maximum) printf("%2d", digit);
    putchar('\n');
    return 0;
}
```

## 讲解

1. 把每个输入整数读成字符序列，逐字符统计其中0到9各数字的出现次数；负号不计为数字。
2. 统计完后扫描count找出最高次数maximum。
3. 再从0到9扫描，输出所有次数等于maximum的数字，天然得到由小到大的顺序。
4. 例如1234、2345、3456中，3和4各出现3次，先输出次数3，再输出数字3和4。

## 知识点总结

- **有界%s与字符串输入容量**：scanf("%127s",number)最多读取127个非空白字符，并自动再写一个'\0'，因此number至少要有128格。%s会跳过开头空白，并在下一处空白停止；宽度用于限制写入范围，不会把过长输入的剩余部分自动丢弃。

## 易错点

- 输入0本身包含一个数字0，不能用只在n>0时执行的拆位循环把它忽略。
- 最大次数必须初始化，不能使用没有赋值的变量比较。
