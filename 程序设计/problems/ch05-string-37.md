## 题目

【题目描述】

我叫郭大锤，昨天还是一名C语言老师。万万没想到，我又失业了。昨天上课前我写的程序让整个学校的电脑中了病毒。为了生计，无可奈何，在学校旁边的唐师傅理发店找了一份兼职。

唐师傅理发店已经开张十年有余，生意红火。唐币是一种专门用来唐师傅营业额的，用int以至于long long int已经无法表示唐师傅的总营业额了。而唐师傅又想要计算自开业以来的总营业额。他给了我两个账本和我的第一个任务，能不能获得这份工作，在此一举！

每个账本都已经在最后一页写上了这一时期的总营业额，设计一个程序，计算出它们的和。

【输入】

有两行，每行1个正整数(不超过100位)，分别表示每个账本上写着的总营业额。

【输出】

一个整数，表示总的营业额。

例如:

**输入：**

```text
18446744073709551616
4294967296
```

**输出：**

```text
18446744078004518912
```

## 解答

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char a[101], b[101]; int digits[102], n = 0;
    scanf("%100s%100s", a, b);
    int i = (int)strlen(a) - 1, j = (int)strlen(b) - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        digits[n++] = sum % 10; carry = sum / 10;
    }
    while (n > 1 && digits[n - 1] == 0) --n;
    for (int k = n - 1; k >= 0; --k) printf("%d", digits[k]);
    putchar('\n'); return 0;
}
```

[下载完整源码](../solutions/ch05-string-37.c)

## 讲解

1. 从两个数的最右边开始相加，并加上上一列进位carry。
2. 每列的个位sum%10存入结果，十位sum/10留给下一列。
3. 例如99+1：先算9+1=10写0进1，再算9+1=10，最终结果为100。
4. 结果按低位到高位保存，输出时反向读取。

## 知识点总结

- strlen：得到数字串的位数，再减1就是个位下标。
- sum%10和sum/10：分别取本位数字与进位。
- i>=0判断：两数位数不同，较短数用完后不再读取。

## 易错点

- 最高位可能产生新进位，结果最多101位。
- 不能转换为long long，100位远超其容量。
