## 题目

1.02 用面向对象程序设计实现简单计算器功能【★】

用C++语言编写简单计算器，实现加、减、乘、除等操作。

例如:

**样例 1**

**输入：**

```text
5*8
```

**输出：**

```text
5*8=40
```

**样例 2**

**输入：**

```text
20/5
```

**输出：**

```text
20/5=4
```

**样例 3**

**输入：**

```text
3+7
```

**输出：**

```text
3+7=10
```

**样例 4**

**输入：**

```text
10-3
```

**输出：**

```text
10-3=7
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Calculator {
public:
    int add(int a, int b) const { return a + b; }
    int sub(int a, int b) const { return a - b; }
    int mul(int a, int b) const { return a * b; }
    int div(int a, int b) const { return a / b; }
};
int main() {
    Calculator calc;
    int a, b, answer;
    char op;
    while (cin >> a >> op >> b) {
        if (op == '+') answer = calc.add(a, b);
        else if (op == '-') answer = calc.sub(a, b);
        else if (op == '*') answer = calc.mul(a, b);
        else if (op == '/' && b != 0) answer = calc.div(a, b);
        else continue;
        cout << a << op << b << '=' << answer << '\n';
    }
    return 0;
}
```

## 讲解

1. 定义计算器类，每种运算对应一个成员函数。
2. 每次读取一个整数、运算符和另一个整数，按运算符调用对应方法。
3. 例如7/2使用整数除法，得到3；程序输出7/2=3。
4. 把读取操作放在while条件中，只有完整读入一组数据后才执行，输入结束就停止。
