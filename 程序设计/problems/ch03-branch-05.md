## 题目

**描述**

邮局对邮寄包裹的费用是这样规定的，如果包裹的长宽高任意一个尺寸超过一米，或者重量超过30千克，不予邮寄，对可以邮寄的包裹每件收的手续费0.2，不同重量的邮资按下表计算：

小于10千克的包裹 ， 0.8元/千克；大于等于10小于20千克的包裹， 0.75元/千克；大于等于20小于等于30千克的包裹 ， 0.7元/千克。

不予邮寄显示：error。尺寸不可以是零或者负数的哦，程序要实现辨别，如果尺寸为负数，要输出error

**输入**

四个double类型的数字，分别代表包裹长，宽，高（单位米，精度不超过0.01）；以及重量（单位千克，精度不超过0.01）。

0.2 0.3 0.8 25

**输出**

17.70

例如:

**输入：**

```text
0.2 0.3 0.8 25
```

**输出：**

```text
17.70
```

### 题目与实现说明

- 题面明确尺寸必须为正，没有单独规定非正重量；本解同样把重量<=0视作无效包裹。

## 解答

```c
#include <stdio.h>

int main(void)
{
    double length, width, height, weight;
    scanf("%lf %lf %lf %lf", &length, &width, &height, &weight);
    if (length <= 0 || length > 1 || width <= 0 || width > 1 ||
        height <= 0 || height > 1 || weight <= 0 || weight > 30) {
        puts("error");
    } else {
        double rate;
        if (weight < 10) rate = 0.8;
        else if (weight < 20) rate = 0.75;
        else rate = 0.7;
        printf("%.2f\n", weight * rate + 0.2);
    }
    return 0;
}
```

## 讲解

1. 先检查长宽高和重量是否在允许范围，任何一项不合法就输出error。
2. 能寄的包裹再按重量选择每千克单价：不足10用0.8，不足20用0.75，剩余用0.7。
3. 例如25千克采用0.7元/千克，邮费25*0.7+0.2=17.70元；这里0.2是每件只收一次的手续费。

## 知识点总结

- 逻辑或||：把多个“不予邮寄”的条件连接起来，只要一个成立就拒收。
- 分段判断：10千克进入0.75档，20千克进入0.7档，30千克仍可寄。
- double与%.2f：尺寸、重量、邮资带小数，最后按两位小数显示金额。

## 易错点

- 每个重量区间的单价作用于整个包裹，不是累进分段收费。
- 一米和30千克都允许，超过才拒收；尺寸为0也拒收。
