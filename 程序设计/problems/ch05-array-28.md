## 题目

【题目描述】

你知道第二价格竞拍吗？这是非常简单但很有名的一种竞拍方式。在第二价格竞拍中，每个潜在的买家私下的提交，可能是装在密封的信封里或者通过一个安全的联系途径，他（她）把投标价给物品的拍卖商。收到所有的投标价之后，拍卖商将物品判决给投标价最大的投标人，并向他（她）收取第二大投标价的费用。

假设你是拍卖商，并且你已经收到所有的投标价，你需要决定谁是赢家，并且决定他（她）支付的费用。

【输入】

有多行。第1行是一个整数T（0&lt;T&lt;50），表示有T组竞拍。接下来有T组数据，每组数据包括2行：第1行仅包括一个整数N（2≤N≤100)，表示投标人的数量。第2行包括N个整数，用一个空格隔开。第i个整数P<sub>i</sub>表示第i个投标人的投标价（0&lt;P<sub>i</sub>≤60000），你可以假定最大的投标价是唯一的。

【输出】

有多行。对于每组数据输出一行，两个整数index和cost，表示第index个投标人是赢家，他（她）需要支付的费用是cost，用一个空格分开。

例如:

**输入：**

```text
2
3
3 2 1
2
4 9
```

**输出：**

```text
1 2
2 4
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int tests;
    scanf("%d", &tests);
    while (tests--) {
        int n, bid, highest = 0, second = 0, winner = 0;
        scanf("%d", &n);
        for (int i = 1; i <= n; ++i) {
            scanf("%d", &bid);
            if (bid > highest) { second = highest; highest = bid; winner = i; }
            else if (bid > second) second = bid;
        }
        printf("%d %d\n", winner, second);
    }
    return 0;
}
```

## 讲解

1. 每组维护最大报价highest、次大报价second和最大报价者编号winner。
2. 新报价比最大值高时，旧最大值退到次大，再更新最大值与编号。
3. 否则只要新报价超过次大值，就更新次大值；最终赢家支付的费用是second。
4. 例如报价3、2、1，赢家1号、费用2；报价4、9，赢家2号、费用4。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- 发现新最大报价时必须把旧最大值保存到second，不能直接丢掉。
- 投标人编号从1开始，输出的是编号和次高报价，不是最高报价。
