## 题目

4003 算法普及课程

题目描述

在将来的某一天，ACM-ICPC在我们学校越来越受到重视了，大家对算法的学习热情非常高，学校决定每天都开设很多算法普及课，由于课程太多，学校没有太多的老师，于是学校派我们ACM集训队的队员去当小讲师。

每个课程都有固定的开始时间和结束时间，我们集训队的小讲师精力非常充沛，只要课程不冲突，讲师们都乐意去上，上课时间冲突的话视为两个课程冲突，比如(1～3和2～4)就冲突，(1～5和5～10)这样就不冲突。

现在安排课程讲师的lynncui非常头疼，因为课程成百上千，需要的讲师也很多很多，为了安排这些讲师，lynncui首先要知道每天最少需要多少讲师，你能告诉他吗？

输入

第一行有一个整数N(0 &lt; N &lt; 1000)，表示课程的数目。

接下来N行，每行有两个整数S和T, (0 &lt;= S &lt; T &lt;= 24), 表示该课程的开始时间和结束时间。

输出

输出一个整数代表最少需要多少讲师。

提示

Sample里面只需要两个讲师，一个上第1门课（1-5），另外一个上剩下5门课(2-3，3-4，6-7，8-9，10-12)。

例如:

**输入：**

```text
6
1 5
2 3
3 4
6 7
8 9
10 12
```

**输出：**

```text
2
```

### 题目与实现说明

- 原保存答案标记为错误，已重新采用最大同时课程数算法。时间均为0到24的整数，适合用25格差分数组。

## 解答

```c
#include <stdio.h>

int main(void) {
    int n, change[25] = {0}; scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        int start, end; scanf("%d%d", &start, &end);
        ++change[start]; --change[end];
    }
    int active = 0, answer = 0;
    for (int hour = 0; hour < 24; ++hour) {
        active += change[hour];
        if (active > answer) answer = active;
    }
    printf("%d\n", answer); return 0;
}
```

## 讲解

1. 一个时刻有多少门课同时进行，就至少需要多少位讲师。
2. 用change记录课程开始时人数需求加1、结束时减1，再按小时累加得到同时进行数。
3. 例如1到5与2到3两课，在2到3间同时进行2门，需要2人。
4. 相同端点的增减在一起计算，所以1到5与5到10不会重叠；最大同时数也能通过课程结束后复用讲师来达到。

## 知识点总结

- change[25]：包含0到24两个端点，24可作为结束时刻。
- ++change[start]和--change[end]：表示区间[start,end)内课程有效。
- active+=change[hour]：前缀累加恢复该小时的课程数量。
- answer：扫描中保留出现过的最大同时课程数。

## 易错点

- 统计互相冲突的课程对数不能得到最少讲师数。
- 结束时间等于下一课开始时间时允许复用讲师。
