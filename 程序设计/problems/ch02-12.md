## 题目

**描述**

从键盘上键入一个实数作为半径，计算并输出圆的周长、面积。（圆周率取3.14）

**输入**

一行，输入一个实数作为圆的半径。

**输出**

两行，分别计算圆的周长，面积。

例如:

**输入：**

```text
3
```

**输出：**

```text
l=18.84
s=28.26
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    double r;
    const double pi = 3.14;
    scanf("%lf", &r);
    double length = 2 * pi * r;
    double area = pi * r * r;
    printf("l=%.2f\ns=%.2f\n", length, area);
    return 0;
}
```

[下载完整源码](../solutions/ch02-12.c)

## 讲解

1. 读入半径 r，并按题目把圆周率固定为3.14。
2. 先计算周长2πr，再计算面积πr²。
3. 例如 r=3 时，周长为18.84、面积为28.26，分别带 l= 和 s= 输出。

## 知识点总结

- **const常量**：const double pi=3.14;定义一个有名字、之后不允许重新赋值的常量。用pi代替多次手写3.14可保持参数一致；常量仍有类型，这里是double。
- **整数与浮点数的混合运算**：一次运算中有double操作数时，整数会先转为浮点数，如2*pi。若两边都是整数仍作整数运算：5/9先得到0，再赋给double也不能恢复小数，需写5.0/9.0或先转换一个操作数。

## 易错点

- 不要用更精确的π代替3.14，本题明确规定圆周率取值。
