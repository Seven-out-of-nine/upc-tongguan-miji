## 题目

【函数+指针】F9.2 房价打折【★】

【题目描述】

我叫郭大锤，我是一名C++教师（昨天之前），万万没想到，我叕失业了。我辅导班长于淼半个学期，他还是一行代码不会写。也不能这么说，他会写int main()；绝望之下我给他展示了三行代码摧毁学校网络的本事。万万没想到，这个他学会了。带着歉意的班长跟我说，他家在本地开的楼盘可以给我打折，骨折都可以。于是我去了售楼处，经理很热情的招待了我，万万没想到，他最后告诉我只可以抹掉百元以下的零头。

例如房价是8999999.99，他可以给我优惠价8999900。

【输入】

一个浮点数。

【输出】

一个整数，优惠后的房价。

预设代码

前置代码

```text
#include <stdio.h>
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    double d;
    scanf("%lf", &d);
    Fun(&d);
    printf("%d\n", (int)d);
    return 0;
}
```

例如:

**输入：**

```text
8999999.99
```

**输出：**

```text
8999900
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(double *price) {
    *price = (int)(*price / 100) * 100;
}
```

<details>
<summary>展开完整本地运行程序</summary>

```c
#include <stdio.h>
#include <string.h>

void Fun(double *price) {
    *price = (int)(*price / 100) * 100;
}

int main(void) {
    double price;
    scanf("%lf", &price);
    Fun(&price);
    printf("%d\n", (int)price);
    return 0;
}
```

</details>

## 讲解

1. 把非负房价先除以 100，变成“有多少个百元”。
2. 转为 int 去掉不足一百元的小数，再乘 100 还原为价格。
3. 例如 123456.78/100=1234.5678，取整数1234，再乘100得到123400。

## 知识点总结

- double 保存含小数的房价，scanf 读 double 使用 %lf。
- (int) 是显式类型转换，对非负数会直接去掉小数部分。
- double *price 允许函数直接修改调用处的浮点变量。

## 易错点

- 这不是四舍五入，而是抹去百元以下的零头；按原main，结果须能由 int 表示。
