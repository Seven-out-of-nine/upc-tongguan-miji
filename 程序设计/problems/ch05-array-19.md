## 题目

**【题目描述】**

在数学上，矩阵是指纵横排列的二维数据表格，最早来自于方程组的系数及常数所构成的方阵。这一概念由19世纪英国数学家凯利首先提出。矩阵概念在生产实践中也有许多应用，比如矩阵图法以及保护个人帐号的矩阵卡系统等等。“矩阵”的本意也常被应用，比如监控系统中负责对前端视频源与控制线切换控制的模拟设备也叫矩阵。

现有a为n×m阶矩阵（即n行m列），将a的所有元素绕着一条从第1行第1列元素出发的右下方45度的射线作镜面反转，即得到a的转置。

**【输入】**

有多行。第1行是两个整数n和m（1≤n,m≤1000），表示矩阵a的n行m列。接下来是n行整数，每行m个数，表示矩阵值。

**【输出】**

m行n列数据，表示矩阵a的转置矩阵m×n，每行数据间以空格分隔。

例如:

**输入：**

```text
3 5
1 3 5 7 9
2 4 6 8 10
0 5 3 6 8
```

**输出：**

```text
1 2 0
3 4 5
5 6 3
7 8 6
9 10 8
```

## 解答

```c
#include <stdio.h>

static int matrix[1000][1000];

int main(void)
{
    int n, m;
    scanf("%d%d", &n, &m);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j) scanf("%d", &matrix[i][j]);
    for (int j = 0; j < m; ++j) {
        for (int i = 0; i < n; ++i) {
            if (i > 0) putchar(' ');
            printf("%d", matrix[i][j]);
        }
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 转置把原矩阵第i行第j列元素放到新矩阵第j行第i列，行数和列数交换。
2. 可以不用真的建立第二个矩阵，只要把原矩阵的一列按从上往下的顺序输出为新的一行。
3. 因此输出时列号j放在外层循环，行号i放在内层循环。
4. 例如原矩阵两行为1 2 3和4 5 6，转置后为1 4、2 5、3 6三行。

## 知识点总结

- **大数组的静态存储**：把static int matrix[1000][1000]写在函数外，使它在程序运行期间持续存在并位于静态存储区，避免把约4MB的大矩阵放进函数调用栈。static还把该名字的可见范围限制在当前源文件。
- **转置时交换行列角色**：转置将原matrix[i][j]放到新矩阵的第j行第i列。无需建立新矩阵时，可让原列号j在外层循环、原行号i在内层循环，依次将原来的每一列输出为新的一行，结果尺寸由n*m变为m*n。

## 易错点

- 转置不是逆时针旋转；原第一列应成为新第一行。
- 非方阵也必须正确处理，不能假设n等于m。
