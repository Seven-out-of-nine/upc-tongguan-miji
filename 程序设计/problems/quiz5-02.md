## 题目

20105 胡恼分苹果

胡恼今年8岁了，他有个5岁的弟弟叫胡边。胡恼非常照顾弟弟，什么事都向着弟弟，比方说，别人送了两个玩具，新的给自己旧的给弟弟，因为新的有甲醛；别人送了两块巧克力，大的给自己小的给弟弟，因为吃多了牙疼……今天，邻居给了他们哥俩两苹果，胡恼又要向着弟弟了！如果给弟弟的苹果重，那就交换过来！

胡恼虽小但喜欢编程，胡编；还喜欢算数，瞎算，现在他要编个函数计算一下。给定两个整数a,b，代表给胡恼和胡边的苹果重量（克，不大于500），如果a&lt;b，则交换。最后输出a,b,及a占两苹果总重量的百分比（小数点后保留2位）。

【输入】

两个整数a,b。

【输出】

处理后的a,b,及a占两苹果总重量的百分比（小数点后保留2位）。

前置后置代码已给出，要求编写函数Fun。注意提交代码时只提交该函数！

【前置代码】

#include &lt;cstdio&gt;

#include &lt;iostream&gt;

【后置代码】

int main()

{

int a,b;

double res=0;

scanf("%d%d",&a,&b);

res = Fun(&a,&b);

printf("%d %d %.2f",a,b,res);

return 0;

}

例如:

**输入：**

```text
3 1
```

**输出：**

```text
3 1 75.00
```

### 题目与实现说明

- 题意中的苹果重量应为正数；总重量为0时百分比没有定义，不属于有效数据。

## 解答

平台已给main，只提交下面函数，勿再提交main。

### 平台提交版

```c
double Fun(int *a, int *b) {
    if (*a < *b) {
        int temp = *a; *a = *b; *b = temp;
    }
    return 100.0 * (*a) / (*a + *b);
}
```

double Fun(int *a, int *b) {
    if (*a < *b) {
        int temp = *a; *a = *b; *b = temp;
    }
    return 100.0 * (*a) / (*a + *b);
}
int main(void) {
    int a, b;
    double res = 0;
    scanf("%d%d", &a, &b);
    res = Fun(&a, &b);
    printf("%d %d %.2f", a, b, res);

## 讲解

1. 函数收到两个重量变量的地址，通过解引用访问并修改原重量。
2. 若第一个小于第二个，用临时变量交换，让a总是较重的苹果。
3. 例如1和3先交换为3和1，再算3÷4×100=75.00。
4. 返回百分比供给定main输出，函数本身不打印。

## 知识点总结

- int *a：a保存外部整数的地址，*a访问其实际数值。
- &a：在main中取变量地址，使函数能够交换外部变量。
- 100.0：先引入浮点运算，避免整数相除变成0。
- double返回值：返回带小数的百分比。

## 易错点

- 交换的是*a和*b指向的重量，不能只交换两个指针变量。
- 分母应为两苹果总重量。
