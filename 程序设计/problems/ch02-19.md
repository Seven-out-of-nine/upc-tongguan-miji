# \[4.06\]冰箱的温度★

## 题目

**描述**

夏天用电高峰时容易断电，请编写程序预测断电一段时间以后冰箱内的温度T（°C），假设该温度T可由以下公式计算得到结果：T=4t<sup>2</sup>/(t+2)-20 。其中断电后所经过的时间t是给定的，求断电t小时后冰箱内的温度。

**输入**

断电后经过的时间t

**输出**

断电t小时后冰箱内的温度，保留2位小数。

## 解答

```c
#include <stdio.h>

int main(void)
{
    double t;
    scanf("%lf", &t);
    double temperature = 4 * t * t / (t + 2) - 20;
    printf("%.2f\n", temperature);
    return 0;
}
```

[下载完整源码](../solutions/ch02-19.c)

## 讲解

1. 把断电后的小时数 t 读成double，以便接受2.5这样的时间。
2. 按照题给公式先算4*t*t，再除以(t+2)，最后减20。
3. 例如t=2时，4*2*2/4-20=-16，按两位小数显示为-16.00。

## 知识点总结

- double：保存时间和温度，允许出现小数和负温度。
- 括号优先：必须写/(t+2)，表示分母整体是t+2。
- 平方写法：t*t表示t²，^在C中不是乘方运算。

## 易错点

- 不要写4*t*t/t+2-20，它改变了分母，计算的是另一个公式。
