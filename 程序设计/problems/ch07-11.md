## 题目

3.05 定义一个树（Tree）类，计算并显示树龄【★】

定义一个Tree（树）类，有成员ages（树龄），成员函数grow(int years)表示树的生长，对ages加上生长的年数。成员函数age()显示树对象的ages值。

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Tree {
private:
    int ages;
public:
    Tree(int a) : ages(a) {}
    void grow(int years) { ages += years; }
    void age() const { cout << "this tree's age is " << ages << '\n'; }
};
int main() {
    Tree t(12);
    t.age();
    t.grow(4);
    t.age();
    return 0;
}
```

[下载完整源码](../solutions/ch07-11.cpp)

## 讲解

1. 先建立12岁的树对象，第一次age输出12。
2. 调用grow(4)把成员ages增加4，树对象本身的状态变成16。
3. 再次调用age输出16，体现“同一对象在方法调用后发生状态变化”。

## 知识点总结

本题没有新增知识点，沿用前文写法，重点见上面的解题讲解。

## 易错点

- grow必须修改成员ages，不能只修改参数years或一个局部副本。
