# \[5.17\]比较两个数大小★

[学习首页](../README.md) · [本章目录](../chapters/ch03-branch/README.md) · [知识点索引](../知识点索引.md)

来源：【测验】第3章 part1分支.html，第17题。

## 题目

**描述**

从键盘上输入两个整数，按照从小到大的顺序排序，然后输出。

**输入**

a,b

**输出**

按照大小排序，以','分隔。

例如:

**输入：**

```text
1,2
```

**输出：**

```text
1,2
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    scanf("%d,%d", &a, &b);
    if (a > b) {
        int temp = a;
        a = b;
        b = temp;
    }
    printf("%d,%d\n", a, b);
    return 0;
}
```

[下载完整源码](../solutions/ch03-branch-17.c)

## 讲解

1. 先读入逗号分隔的两个整数。
2. 如果a已经不大于b，直接输出；否则交换它们。
3. 例如输入9,2，先把9临时存起来，再令a=2、b=9，输出2,9。

## 知识点总结

- 临时变量：temp保存交换前的a，避免赋值后丢失原数。
- if(a>b)：只在顺序错误时交换，相等时不必处理。
- 格式字符串的逗号：scanf、printf里都明确写英文逗号，以符合题目输入输出。

## 易错点

- 不能写a=b;b=a，这样两个变量都会变成原来的b。
