来源：【测验】第5章 part1数组.html，第20题。

## 题目

**【题目描述】**

旋转是图像处理的基本操作，是指图像以某一点为中心旋转一定的角度，形成一幅新的图像的过程。当然这个点通常就是图像的中心。既然是按照中心旋转，自然会有这样一个属性：旋转前和旋转后的点离中心的位置不变。

在这个问题中，你需要将一个图像逆时针旋转90度。计算机中的图像表示可以用一个矩阵来表示，为了旋转一个图像，只需要将对应的矩阵旋转即可。

**【输入】**

有多行。第1行是两个整数n和m（1≤n,m≤1000），分别表示图像矩阵的行数和列数。接下来的n行，每行是m个整数，表示输入图像。

**【输出】**

有m行，每行是n个整数，表示原始矩阵逆时针旋转90度后的矩阵。

例如:

**输入：**

```text
2 3
1 5 3
3 2 4
```

**输出：**

```text
3 4
5 2
1 3
```

## 解答

```c
#include <stdio.h>

static int matrix[1000][1000];

int main(void)
{
    int n, m;
    scanf("%d%d", &n, &m);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j) scanf("%d", &matrix[i][j]);
    for (int j = m - 1; j >= 0; --j) {
        for (int i = 0; i < n; ++i) {
            if (i > 0) putchar(' ');
            printf("%d", matrix[i][j]);
        }
        putchar('\n');
    }
    return 0;
}
```

## 讲解

1. 逆时针旋转90度后，原最后一列从上到下的元素构成新第一行。
2. 所以按原列号从m-1到0的顺序访问，每一列内部仍按行号0到n-1输出。
3. 例如1 5 3与3 2 4两行，最后一列3 4先输出，然后5 2，最后1 3。

## 知识点总结

- 外层j递减：控制列的逆序，使转置结果再上下翻转。
- 内层i递增：保持每个原列从上往下的顺序。
- static矩阵：1000×1000的int数组约4MB，静态存储比局部栈数组稳妥。

## 易错点

- 若外层列号递增，只得到转置矩阵，没有完成旋转。
- 旋转后的尺寸是m行n列，不能仍输出n行m列。
