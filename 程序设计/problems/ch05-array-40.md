[学习首页](../README.md) · [本章目录](../chapters/ch05-array/README.md) · [知识点索引](../知识点索引.md)

来源：【测验】第5章 part1数组.html，第40题。

## 题目

【题目描述】

假设有n项物品，大小分别为s1，s2，...，sn，其中si是整数且满足：1≤si≤100。要把这些物品装入到容量为100的一批箱子（序号1~n）中。装箱方法是：对每项物品si，依次扫描所有这些箱子，把si放入足以能够容下它的第一个箱子中（first-fit策略）。写一个程序来模拟这个装箱的过程。

【输入】

有两行。第1行是整数n（n≤1000），表示物品的个数。第2行是n个整数si（si≤100），分别表示n个物品的大小。

【输出】

有多行。每行是一个物品和其所在的箱子序号，最后一行是所需的箱子数目。

例如:

**输入：**

```text
8
60 70 80 90 30 40 10 20
```

**输出：**

```text
60 1
70 2
80 3
90 4
30 1
40 5
10 1
20 2
5
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, used[1000] = {0}, boxes = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i) {
        int size, box = 0;
        scanf("%d", &size);
        while (box < boxes && used[box] + size > 100) ++box;
        if (box == boxes) ++boxes;
        used[box] += size;
        printf("%d %d\n", size, box + 1);
    }
    printf("%d\n", boxes);
    return 0;
}
```

## 讲解

1. used[box]保存已用箱子的当前容量，每个物品必须按原输入顺序处理。
2. 从第一个箱子开始找，容量加上物品大小不超过100的第一个箱子，就是题目first-fit要求的位置。
3. 若全部已有箱子都装不下，启用一个新的空箱子，再放入物品。
4. 例如60、70、30，前两个分别用1、2号箱，30能放进1号箱，因此输出30 1，最终只需2箱。

## 知识点总结

- while条件包含box<boxes：先确认箱子已经启用，再检查是否装得下。
- used[box]+=size：在放入后立即更新容量，后续物品会看到新容量。
- box+1：数组下标从0开始，题目箱子编号从1开始。

## 易错点

- 每个物品都必须从第1个箱子重新找，不能接着上次箱号往后找。
- first-fit是指定模拟策略，不能把物品排序后重新装箱。
