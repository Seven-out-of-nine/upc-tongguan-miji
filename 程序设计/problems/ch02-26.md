## 题目

**描述**

根据火车的出发时间和到达时间（不跨天，24小时制），编写程序计算整个旅途所用的时间。比如G198次列车从青岛站出发时间为16:00，到达北京南站的时间为20:40，则整个旅途所用时间为04:40。输入格式仅一行，包含两个4位的正整数start和end，中间以空格分隔，分别表示火车的出发时间和达到时间。在一行中输出整个旅途所用的时间，格式为“hh:mm”，其中hh表示2位小时数，mm表示2位分钟数。

**输入**

两个4位的正整数start和end，格式为"hhmm"。

**输出**

旅途所用的时间，格式为"hh:mm"。

例如:

**输入：**

```text
1600 2040
```

**输出：**

```text
04:40
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int start, end;
    scanf("%d %d", &start, &end);
    int start_minutes = start / 100 * 60 + start % 100;
    int end_minutes = end / 100 * 60 + end % 100;
    int duration = end_minutes - start_minutes;
    printf("%02d:%02d\n", duration / 60, duration % 60);
    return 0;
}
```

[下载完整源码](../solutions/ch02-26.c)

## 讲解

1. hhmm形式中，除以100取小时，%100取分钟。
2. 把出发和到达时间都换成总分钟，再相减得到旅途分钟数。
3. 例如1600为960分钟，2040为1240分钟，差280分钟，也就是4小时40分，输出04:40。

## 知识点总结

- **输出域宽与补零**：%02d规定最小2列，位数不足时左补0，4显示04；%3d未带0则默认左补空格。超宽数字仍完整输出，不会截断；这与%.2f控制小数位不同。

## 易错点

- 不能直接拿2040-1600得到440，再把440当成440分钟。
- 原题保证不跨天，到达时间不早于出发时间。
