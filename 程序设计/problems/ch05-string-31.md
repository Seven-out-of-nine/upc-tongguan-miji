# 10.31 字符最后一次出现的位置【★】

## 题目

**【题目描述】**

从键盘输入一个不带空格的字符串str，再输入一个特定字符ch。编程输出ch在字符串str中最后一次出现的位置，如果不存在，则输出0。

**【输入】**

一个不带空格的字符串str（长度小于等于100）和要查找的特定字符ch，以空格分隔。

**【输出】**

h在字符串str中最后一次出现的位置（从1开始数，不是下标）。

例如:

**输入：**

```text
HelloWorld o
```

**输出：**

```text
7
```

## 解答

```c
#include <stdio.h>

int main(void) {
    char s[101], ch; scanf("%100s %c", s, &ch);
    int position = 0;
    for (int i = 0; s[i]; ++i) if (s[i] == ch) position = i + 1;
    printf("%d\n", position); return 0;
}
```

[下载完整源码](../solutions/ch05-string-31.c)

## 讲解

1. 初始答案为0，方便处理完全找不到的情况。
2. 逐个扫描字符，每次匹配都更新位置，后面的匹配会覆盖前面的。
3. 例如banana中a在2、4、6位置，最终保存6。

## 知识点总结

- position=i+1：记录题目使用的1起始位置。
- for循环：必须遍历完整串才能确定最后一次。
- if：只有字符匹配才更新答案。

## 易错点

- 不要在第一次匹配后break。
