## 题目

【函数+指针】F9.3 只保留整数中的奇数位【★】

【题目描述】

编写函数Fun，其功能是：将整数n各位上为偶数的数去除，剩余的数按原来的顺序组成一个新的数。

【输入】

仅一行。一个整数n（0&lt;n≤100000000）。

【输出】

仅一行。一个整数，表示组成的新数。

预设代码

前置代码

```text
#include <stdio.h>
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    int n;
    scanf("%d", &n);
    Fun(&n);
    printf("%d\n", n);
    return 0;
}
```

例如:

**输入：**

```text
27638496
```

**输出：**

```text
739
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(int *n) {
    int x = *n, result = 0, place = 1;
    while (x > 0) {
        int digit = x % 10;
        if (digit % 2 != 0) {
            result += digit * place;
            place *= 10;
        }
        x /= 10;
    }
    *n = result;
}
```

## 讲解

1. 从个位向左取数字，用 x%10 取得当前位，x/=10 去掉这一位。
2. 只有当前数字为奇数时才写入结果，place 表示下一个保留数字应放在个位、十位还是百位。
3. 例如 27638496 从右往左保留 9、3、7，分别放在个位、十位、百位，得到739。
4. 如果各位全为偶数，result 一直为0，输出0。

## 知识点总结

- !=0 判断非零余数；这里用于判断数字是奇数。
- place 从1开始，每保留一位乘10，使原先的数字顺序保持不变。
- 指针解引用 *n 用来把最终结果返回给 main。

## 易错点

- 题名“奇数位”指数字的值为奇数，不是指下标或数位的位置为奇数。
