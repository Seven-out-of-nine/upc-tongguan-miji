## 题目

4.05 运用C++的继承性求解问题【★★】

建立一个员工信息类的层次体系。其中，基类Employee包含保护的数据成员name和ID，代表雇员的姓名和职工号；由Employee类派生出经理类Manager包含私有的数据成员sal，代表经理的月工资；由Employee类派生出钟点工类HourlyWorker包含私有的数据成员wage和hours，代表钟点工每小时的工资数和月工作时数。所有类都通过构造函数对数据成员初始化，通过show()函数输出数据成员的值。在主函数中，实例化Manager类和HourlyWorker类的对象并且将其数据输出。

例如:

**输出：**

```text
Tom,100
6000
Mike,1001
20,8
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class Employee {
protected:
    string name;
    int ID;
public:
    Employee(string n,int id) : name(n),ID(id) {}
    void show() const { cout << name << ',' << ID << '\n'; }
};
class Manager : public Employee {
private:
    double sal;
public:
    Manager(string n,int id,double s) : Employee(n,id),sal(s) {}
    void show() const { Employee::show(); cout << sal << '\n'; }
};
class HourlyWorker : public Employee {
private:
    double wage;
    int hours;
public:
    HourlyWorker(string n,int id,double w,int h) : Employee(n,id),wage(w),hours(h) {}
    void show() const { Employee::show(); cout << wage << ',' << hours << '\n'; }
};
int main() {
    Manager mg("Tom",100,6000.0);
    HourlyWorker hw("Mike",1001,20.0,8);
    mg.show(); hw.show();
    return 0;
}
```

## 讲解

1. Employee保存两种员工共有的姓名和工号，并负责显示这一部分。
2. Manager新增月薪sal，HourlyWorker新增时薪wage和工时hours。
3. 各自show先调用Employee::show，再输出本类特有的数据。
4. 例如Tom显示Tom,100与6000；Mike显示Mike,1001与20,8。

## 知识点总结

- 继承复用共有的字段和显示方法，避免在两个类里各存一套姓名工号。
- 派生构造函数通过Employee(n,id)初始化基类。
- double默认输出时整数值可显示为6000，没必要先强转int而损失潜在的小数。

## 易错点

- 题目要求显示时薪和工时，不是只输出两者乘积；基类也应有show函数。
