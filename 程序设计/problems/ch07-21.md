## 题目

4.04 单继承的应用【★】

建立一个建筑物类的层次体系。其中，基类building包括保护数据成员name（建筑物名称）、floors（层数）和areas（总面积），由building类派生住宅类house和办公楼类office；住宅类house包括私有数据成员 bedrooms（卧室数）和 bathroom（浴室数）；办公楼类office包括私有数据成员offices（办公室数）和meetingrooms（会议室数）。基类building、住宅类house和办公楼类office都含有构造函数和print函数，以分别用于对数据成员的初始化和输出。在主函数中，实例化house类和office类对象并且将其数据输出。

例如:

**输出：**

```text
建筑物名称：江山瑞城, 层数：3, 总面积：200平方米, 卧室数：5, 浴室数：2.
建筑物名称：工科楼E, 层数：20, 总面积：10000平方米, 办公室数：2000, 会议室数：100.
```

## 解答

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
#include <string>
#include <cstring>
using namespace std;

class building {
protected:
    string name;
    int floors, areas;
public:
    building(string n, int f, int a) : name(n), floors(f), areas(a) {}
    void print() const {
        cout << "建筑物名称：" << name << ", 层数：" << floors << ", 总面积：" << areas << "平方米";
    }
};
class house : public building {
private:
    int bedrooms, bathroom;
public:
    house(string n,int f,int a,int b,int bath) : building(n,f,a),bedrooms(b),bathroom(bath) {}
    void print() const {
        building::print();
        cout << ", 卧室数：" << bedrooms << ", 浴室数：" << bathroom << ".\n";
    }
};
class office : public building {
private:
    int offices, meetingrooms;
public:
    office(string n,int f,int a,int o,int m) : building(n,f,a),offices(o),meetingrooms(m) {}
    void print() const {
        building::print();
        cout << ", 办公室数：" << offices << ", 会议室数：" << meetingrooms << ".\n";
    }
};
int main() {
    house myhouse("江山瑞城",3,200,5,2);
    office myoffice("工科楼E",20,10000,2000,100);
    myhouse.print(); myoffice.print();
    return 0;
}
```

## 讲解

1. 先把名称、层数、面积这些共同数据写进building。
2. house增加卧室浴室，office增加办公室会议室，二者分别继承building。
3. 派生类print先调用building::print输出共同部分，再输出各自专有部分。
4. 例如住宅先显示江山瑞城、3层、200平方米，再接5间卧室、2间浴室。

## 知识点总结

- 公有继承表达住宅或办公楼“是一种建筑物”。
- 作用域运算符building::指定调用基类版本，避免再次调用本类print造成递归。
- 初始化列表先构造基类，再初始化派生类自身的私有成员。

## 易错点

- 题目要求基类也有构造函数和print，不能只在两个派生类里复制输出逻辑。
