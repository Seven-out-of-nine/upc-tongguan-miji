## 题目

**【题目描述】**

我们知道，每位考入大学的孩子们，在上大学前都会经历许多次的考试、排名，这样老师才能及时地了解孩子们的学习和自己的教学状况，从而帮助并引导他们顺利考入自己梦想的大学。请编程计算出每位学生的总分和每门课程的平均分，以便帮助老师们快速统计出孩子们的课程学习效果吧！

**【输入】**

有多行。第1行是两个整数n（n≤30）和m（m≤10），表示需要统计n位学生的m门课程的学习成绩（均为整数）。接下来是n行数据，每行数据表示每位学生的m门课程的成绩。

**【输出】**

有多行。第1行是m门课程的平均分，结果保留两位小数，每个数据前有空格。接下来是n行整数，分别表示每位学生的总分。

例如:

**输入：**

```text
3 6
80 78 90 58 65 73
70 66 89 95 77 83
50 66 77 88 96 80
```

**输出：**

```text
 66.67 70.00 85.33 80.33 79.33 78.67
444
480
457
```

## 解答

```c
#include <stdio.h>

int main(void)
{
    int n, m, score;
    long long row_sum[30] = {0}, col_sum[10] = {0};
    scanf("%d%d", &n, &m);
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            scanf("%d", &score);
            row_sum[i] += score; col_sum[j] += score;
        }
    }
    for (int j = 0; j < m; ++j) printf(" %.2f", (double)col_sum[j] / n);
    putchar('\n');
    for (int i = 0; i < n; ++i) printf("%lld\n", row_sum[i]);
    return 0;
}
```

## 讲解

1. 把行看作学生，列看作课程；读到第i个学生第j门课的成绩，同时加进该学生总分和该课程总分。
2. 先按课程顺序输出col_sum[j]/n，每个平均分前必须有一个空格。
3. 再按学生顺序逐行输出row_sum[i]，不需要重新保存完整成绩矩阵。
4. 例如只有两名学生、两门课，成绩80 90与60 70，课程平均70.00、80.00，学生总分170、130。

## 知识点总结

- 数组初始化={0}：所有累计值从0开始，否则未初始化的数据会影响总分。
- (double)col_sum[j]/n：先转浮点数再除，避免整数除法丢失小数。
- row_sum[i]与col_sum[j]：同一个成绩在两个不同方向参与统计。

## 易错点

- 课程平均分的分母是学生数n，不是课程数m。
- 第一行每个数据前有空格，包括第一个数据。
