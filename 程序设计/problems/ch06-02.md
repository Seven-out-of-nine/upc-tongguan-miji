## 题目

【函数+字符数组】F10.3 字符移位【★★】

【题目描述】

编写函数Fun，其功能是：将数组s存放的字符串中的所有数字字符移到所有非数字字符之后，并保持数字字符串和非数字字符串原有的先后次序。

【输入】

仅一行。字符串s（长度不超过1000）。

【输出】

仅一行。处理完后的字符串。

预设代码

前置代码

```text
#include <stdio.h>
#include <string.h>
#define N 1000
#include <bits/stdc++.h>
using namespace std;
```

后置代码

```text
int main()
{
    char s[N + 5];
    scanf("%s",s);
    Fun(s);
    puts(s);
    return 0;
}
```

例如:

**输入：**

```text
def35adh3kjsdf7
```

**输出：**

```text
defadhkjsdf3537
```

## 解答

平台已经提供头文件和 main 函数，只提交下方函数；完整程序供本地练习。

### 平台提交版

```c
void Fun(char s[]) {
    char temp[1001];
    int j = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] < '0' || s[i] > '9') temp[j++] = s[i];
    }
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= '0' && s[i] <= '9') temp[j++] = s[i];
    }
    temp[j] = '\0';
    strcpy(s, temp);
}
```

## 讲解

1. 先扫描一遍，把所有非数字字符按出现顺序放入 temp。
2. 再扫描一遍，把所有数字字符接到 temp 后面；每次都从左到右，因此两组各自的相对顺序不变。
3. 例如 a2b1 先收集 ab，再接上 21，得到 ab21。
4. 给 temp 补结束符，再用 strcpy 把结果复制回 s。

## 知识点总结

- 字符 '0' 到 '9' 的编码连续，可以用大小比较判断数字字符。
- || 表示至少一个条件成立；小于 '0' 或大于 '9' 就不是数字。
- 临时数组用于保存重排结果，避免覆盖还没扫描的原字符。
- strcpy 在 string.h 中声明，复制时也会复制字符串结束符。

## 易错点

- 不能边扫描边随意交换数字与字母，否则可能破坏原来的先后次序。
