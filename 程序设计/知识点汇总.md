## 一、基础：变量保存什么，程序怎样输入和输出

### 1. 从程序入口到一次计算

```c
#include <stdio.h>

int main(void) {
    int a, b;
    scanf("%d%d", &a, &b);
    int sum = a + b;
    printf("%d\n", sum);
    return 0;
}
```

`#include`引入头文件中的声明；程序从main执行。大括号圈出函数体，语句通常以分号结束。`int a`声明整数变量，`a = 3`把3存进去，后续赋值可以改变它。变量名区分大小写，不能随意省略初始化：读取失败或还没有赋值的局部变量不能直接拿来计算。

`scanf`把输入写入变量，所以这里传`&a`、`&b`两个地址；`printf`只读取值，直接传a、b。格式中的第一个占位符对应第一个参数，后面的依次对应。输入3和4时，sum保存7，最后只输出7。字符串字面量写在双引号中；`\n`表示换行，空格和标点也都是实际输出的一部分。

例题：[Hello world](problems/ch02-01.md)、[整数输入与原样输出](problems/ch02-03.md)、[整数求和](problems/ch02-07.md)。

### 2. 类型与格式必须配套

| 保存的内容 | 常见类型 | scanf读取 | printf输出 |
|---|---|---|---|
| 整数 | `int` | `%d` | `%d` |
| 较大整数 | `long long` | `%lld` | `%lld` |
| 带小数的数 | `double` | `%lf` | `%f`，如`%.2f` |
| 一个字符 | `char` | `%c` | `%c` |

`%.2f`规定显示两位小数，`%02d`把整数补足两位、前面补0，`%3d`规定至少占三列、默认右对齐；域宽不会截断较长数。格式中要输出百分号本身，应写`%%`。`%o`、`%x`分别输出无符号数的八进制、十六进制形式；需要时先转为`unsigned int`，使参数类型相符。

类型决定可表示范围，输出格式不会扩大范围。两个int相乘时，不能等乘法完成后再指望一个long long变量救回已经溢出的结果；应让乘法本身使用较宽类型，如`1LL * a * b`。也要检查中间值，最后答案较小不代表中间累加一定安全。

例题：[实数输出](problems/ch02-06.md)、[进制显示](problems/ch02-14.md)、[时间补零](problems/ch02-26.md)、[超宽中间总和的分块累计](problems/ch05-array-43.md)。

### 3. 运算顺序与数值含义

`+ - * /`分别做加减乘除；整数除法向0截断，所以`7 / 2`是3，`7 / 2.0`才是3.5。`%`求整数余数，非负整数的`n % 10`取个位，`n / 10`去掉个位；多个位置按十进制位权乘10、100等再相加。C里的`^`不是乘方，平方写`x * x`。

括号写清整体含义：`4 * t * t / (t + 2)`的分母是t+2；`4*t*t/t+2`已经是另一条公式。除数不能为0。表达式有整数与实数时会发生类型转换，`(double)a / b`可以主动引入实数运算；`(int)x`对可表示范围内的实数向0截断，不等于四舍五入。

正整数向上取整除法可写`(n + a - 1) / a`，但须确保加法不溢出；另一个写法是`n / a + (n % a != 0)`。铺地砖要分别算两个方向需要几块，再相乘，不能只用总面积相除。

例题：[整数四则运算](problems/ch02-04.md)、[分离三位数](problems/ch02-11.md)、[冰箱温度公式](problems/ch02-19.md)、[铺广场](problems/ch02-27.md)。

### 4. 字符、空白与输入流

字符常量用单引号：`'3'`是数字字符，`3`是整数；在题目的ASCII环境中，`'3' - '0'`得到整数3，字母也可用相对`'A'`或`'a'`的位置转换。`getchar()`读取下一个字符并返回int，既能表示字符，也能表示输入结束的EOF；`putchar(c)`输出一个字符，`puts(s)`输出整串并另加换行。

scanf读取数值时通常跳过前导空白，`%c`本身不跳过。格式`" %c"`中的空格会先跳过所有空白，适合读取运算符；若目标字符可能就是空格，则不能这样写。格式里的逗号、冒号等固定字符要与输入对应，比如`"%d:%d"`读取时、分。

`scanf`返回成功写入的项目数。读取两个数时检查是否返回2，读一个数时检查是否返回1，才能在输入结束时停止，避免再次使用旧值。哨兵是题目约定的结束值，必须先判断再参与计算；它与EOF不是同一回事。

例题：[字符编码](problems/ch02-16.md)、[混合类型输入](problems/ch02-18.md)、[哨兵结束输入](problems/ch03-function-08.md)、[根据scanf返回值读取记录](problems/ch05-array-42.md)。

### 5. 小数输出、数值取整与浮点误差

`printf("%.2f", x)`只控制显示方式，通常不改变变量x。若算法确实需要把数值保留到某一位，才使用缩放、取整、缩回去的办法。`sqrt`、`fabs`、`floor`等数学函数由`<math.h>`提供，分别求平方根、绝对值和向下取整。

计算机中的浮点数只能表示有限个值，很多十进制小数只能近似保存。因此“理论上相等”的两次计算可能留下很小差值。容差必须有具体依据：方程题对a的零阈值按题干执行；判别式的舍入处理只用机器精度量级的误差界，不能把可区分的正、负判别式随意并成0。`long double`提高精度，`nextafter`能移到相邻可表示值，但都不能恢复读入时已丢失的任意精确信息。超长十进制数应采用字符串或数位数组。

例题：[海伦公式](problems/ch02-13.md)、[数值保留小数位](problems/ch03-function-06.md)、[一元二次方程](problems/ch03-branch-16.md)。

## 二、分支与循环：决定做哪一步、重复多少次

### 6. 条件先后决定边界归属

`==`判断相等，`=`负责赋值；`< <= > >= !=`作其他比较。

| 逻辑写法 | 条件含义 | 例子 |
|---|---|---|
| `a && b` | 两边都成立 | `x >= 0 && x <= 100` |
| `a \|\| b` | 至少一边成立 | `x < 0 \|\| x > 100` |
| `!a` | 真假取反 | `!seen[x]`表示尚未标记 |

`!a`只有一个操作数，`a != b`则比较两个值是否不相等，不能混为同一种写法。逻辑与、或会短路：`i >= 0 && a[i] == x`先确认下标合法，再访问数组，不能把两个条件随意调换。

```c
if (score < 0 || score > 100) puts("error");
else if (score < 60) puts("D");
else if (score < 80) puts("C");
else if (score < 90) puts("B");
else puts("A");
```

进入第二个合法区间时，前面的较小区间已经排除，所以不用重复写下界。先检查输入有效性，再分类；先检查等边，再检查等腰，否则等边会提前落入等腰。分段单价还要看清是整件选档还是累进收费：邮资按整件重量选单价，出租车超出部分则叠加到前段费用上。

固定离散值可用switch/case分派，用break结束当前case，default处理其他值。`条件 ? 值1 : 值2`产生一个值，适合简单二选一，不宜把复杂多步处理压成难读的一行。

例题：[成绩分段](problems/ch03-branch-20.md)、[邮资](problems/ch03-branch-05.md)、[出租车](problems/ch03-branch-31.md)、[星期翻译](problems/ch03-branch-14.md)。

### 7. 循环与状态更新

| 写法 | 执行次序 | 适用情况 |
|---|---|---|
| `for (初始化; 条件; 更新)` | 初始化一次，每轮先判条件，执行循环体后更新 | 已知下标范围、候选范围 |
| `while (条件)` | 每轮先判断，可能一次也不执行 | 读到结束、持续缩小问题 |
| `do { ... } while (条件);` | 先执行一次，再判断是否继续 | 数字0也要检查一位 |

`i++`、`i--`分别增减1；`sum += x`等于`sum = sum + x`。累计和从0起、累计积从1起，初始化放在循环外；每组数据独立时，又要在新一组开始时清零。需要同时更新几个状态，先用临时变量保留旧值，避免后一步误用已经改变的数据。

break退出所在的最内层循环或switch；continue只跳过当前轮余下代码，for随后仍执行更新部分。嵌套循环中，内层会对每一次外层迭代完整执行；换行应在一行的内层循环结束之后打印。

例题：[for与素数试除](problems/ch03-function-03.md)、[累计乘积](problems/ch03-function-04.md)、[嵌套循环画图](problems/ch05-array-03.md)、[do-while处理数位](problems/ch05-array-26.md)。

### 8. 周期、日期与递推

从1开始的“第n天”常先减1，再模周期长度，转换成0起始位置。时间先统一成分钟或秒，再做差；日期须按题目规则处理，真实闰年、固定30天月份是不同模型。普通闰年能被4整除，整百年份还必须能被400整除。

递推保存足以产生下一项的状态：斐波那契数只需相邻两项；幂与阶乘的比值可由上一项乘`x / i`得到，不必分别计算很大的幂、阶乘。需要旧状态的数组递推，应选正确更新方向，例如新项依赖旧左邻时从右向左写回。

例题：[五天周期](problems/ch03-branch-24.md)、[月历状态推进](problems/ch05-array-38.md)、[固定30天的时间戳](problems/ch02-24.md)、[相邻项递推](problems/ch03-function-05.md)。

## 三、函数、数组与字符串：组织数据和复用步骤

### 9. 函数把输入变成结果

```c
int GetMax(int a, int b) {
    if (a > b) return a;
    return b;
}
```

返回类型、函数名、形参列表共同说明接口；调用前必须已有定义或声明。`GetMax(x,y)`把x、y的当前值交给a、b，普通值形参是副本，修改a不会直接改变x。return交回结果并立即结束本次调用；调用者可以保存结果、继续计算，也可以统一负责打印。

void函数不返回数值，可用`return;`提前结束；它仍可打印结果，或通过调用者提供的数组、地址写出结果。数组形参不自动携带元素数量，应另传有效长度；const数组形参表达只读约定，不能通过它修改元素。

递归是函数调用自身。每次调用有独立参数，必须有终止条件且参数朝它推进。分治把区间拆成不重叠子区间，分别求解后合并；数列递归还可把相邻项作为参数传下去，避免重复展开同一结果。

例题：[函数接口与值参数](problems/ch03-function-01.md)、[递归与分治](problems/ch03-function-10.md)、[递归状态参数](problems/ch03-function-12.md)、[数组形参](problems/ch05-array-23.md)、[void与结果数组](problems/ch06-01.md)。

### 10. 数组容量、长度与位置

`int a[100]`预留100个同类型元素；若只读入n项，就只使用下标0到n-1，不能访问a[100]。`int a[100] = {0};`让未明确列出的元素也补0；这不同于未初始化的局部数组。`sizeof a`取得实际数组的总字节数，`sizeof a[0]`取得一项字节数；函数的数组形参已按指针处理，不能照搬这个办法求原数组长度。

二维数组`a[row][col]`是行与列两个下标；二维数组形参需要知道后一维大小，才能正确跨行定位。主对角线满足`row == col`，副对角线满足`row + col == n - 1`，边界满足首末行或首末列。用一个合并条件处理重合位置，避免重复算角点或中心。

转置交换行、列角色，尺寸从n×m变成m×n；旋转90度还要改变其中一个方向的遍历顺序。大矩阵放在静态存储区可减少函数调用栈压力，文件作用域static也限制名字只在当前源文件可见。学号与成绩等平行数组用同一下标表示同一记录；重排时必须保持对应关系。

例题：[数组有效范围](problems/ch05-array-01.md)、[二维数位数组](problems/ch05-array-04.md)、[边界与重合位置](problems/ch05-array-12.md)、[转置](problems/ch05-array-19.md)、[旋转](problems/ch05-array-20.md)、[平行记录](problems/ch05-array-42.md)。

### 11. 查找、排序与数据移动

### 12. 统计、模拟与贪心各在保存什么

频次数组count[x]保存出现次数，标记数组seen[x]只保存“有没有”；两者都以有限值域作下标。求平均要先累计总分，再用实数除法。只去掉一个最高分、一个最低分时，即使分数重复，也只减各一次。

模拟按题目指定顺序更新状态：区间标记重复写同一状态，可自然去重；开关可用`state = !state`反转；装箱的首次适应必须每次从第一个箱子查起，不能擅自换成排序后的策略。

贪心需要解释为什么当前选择安全。均分砖堆时总量不变，目标高度固定，所有高于目标的砖必须移走，直接移给不足者恰好达到这个下界。排序后的中位数能使绝对距离和最小；两端配对时先处理最贵者，再判断最便宜者能否同组，才有交换论证支持最优性。不要把“每次看起来划算”直接当作证明。

例题：[频次数组](problems/ch05-array-22.md)、[标记数组](problems/ch05-array-27.md)、[去极值平均](problems/ch05-array-08.md)、[均分砖堆](problems/ch05-array-09.md)、[区间去重](problems/ch05-array-35.md)、[首次适应](problems/ch05-array-40.md)、[两端配对](problems/ch05-array-41.md)。

### 13. 常用数论方法

素数先排除小于2的数，再试除到平方根；因数成对出现，合数必有一个不超过平方根的因数。判断`d <= n/d`可避免计算d*d时溢出。一次求整个区间的素数时，筛法从p²开始标记p的倍数，保留尚未被标记的数。

辗转相除使用`gcd(a,b) = gcd(b,a%b)`，余数为0时停止；原数会被工作变量的更新覆盖，所以求最小公倍数时要保留原输入，用`m / gcd * n`降低中间乘积溢出的风险，最终结果仍须能装进类型。

例题：[素数试除](problems/ch03-function-03.md)、[筛法](problems/ch05-array-34.md)、[递归公约数](problems/ch03-function-11.md)、[公约数与公倍数](problems/ch04-01.md)。

### 14. C字符串先保证结束，再谈处理

C字符串是以`'\0'`结束的字符数组；结束符占空间，但不属于可见内容。长度80最多需要81格，`'0'`是普通数字字符，不能替代结束符。`scanf("%80s", s)`最多读80个非空白字符并补结束符，遇空格会停，也不会自动丢弃超长输入剩下的字符。

整行输入用fgets，保留行内部空格；读完组数后再读整行，要先消费数值行剩余换行。手工收集字符时，写入k个字符后补`s[k] = '\0';`。同一字符串中的字母转大小写、过滤、分段、插入等操作，仍沿用数组扫描；读写同一数组时先考虑是否会覆盖未读内容。

| 接口 | 作用与边界 | 首次讲解 |
|---|---|---|
| `strlen(s)` | 首个结束符之前的字节数，不等于数组容量 | [字符串长度](problems/ch05-array-02.md) |
| `strcmp(a,b)` | 比较内容；结果的负、零、正表示小于、相等、大于 | [单词缩写](problems/ch05-string-09.md) |
| `strstr(s,sub)` | 找连续子串；返回起点指针，未找到为NULL | [GLB串](problems/ch05-string-35.md) |
| `strcpy(dst,src)` | 连结束符一起复制，目标容量必须足够 | [字符移位](problems/ch06-02.md) |
| `strcspn(s,"\r\n")` | 到首个指定字符前的长度，无匹配则为串长 | [组新串](problems/ch06-03.md) |
| `sprintf(dst,format,...)` | 按格式写入数组，不替调用者检查容量 | [A+B Format](problems/ch05-array-02.md) |

ctype的isspace还识别制表符、回车等空白，不能只用字符等于空格替代；传入普通char前，先转unsigned char，满足分类函数的实参范围要求。对UTF-8文本，英文常占1字节，汉字常占3字节；按汉字比较回文时，必须保留完整字符边界。

例题：[整行输入](problems/ch05-string-02.md)、[首字母大写](problems/ch05-string-48.md)、[含中文的回文](problems/ch05-string-27.md)。

### 15. 字符串中的通用方法与大整数

连续段计数不是整串频次统计：aaabbbaa要分成aaa、bbb、aa，保留三个段。子串匹配则逐个尝试起点，只有所有对应字符相同才成功；求第一次位置时可停止，统计次数时继续向右一格，可保留重叠。

超大十进制数可用每格一位的数组，低位放下标0。加法从低位累加并传carry；乘法把第i位与第j位的部分积加到第i+j列，再统一进位。输出去掉多余高位0，但结果为0时保留一位。进制解析从左向右做`value = value * base + digit`，乘加前检查数位合法性与溢出。

超大实数比较可删除整数前导0、小数末尾0，化成统一文本再比较；不能删小数开头或中间有意义的0。校验码则按题目指定权重求和、取余、查表，只能检出规则所覆盖的错误，不能替代其他真实性验证。

例题：[连续段编码](problems/ch05-string-13.md)、[朴素子串匹配](problems/ch05-string-36.md)、[大数加法](problems/ch05-string-37.md)、[竖式乘法](problems/ch05-string-38.md)、[进制解析](problems/ch05-array-46.md)、[超大实数规范化](problems/ch05-string-46.md)、[加权校验](problems/ch05-string-39.md)。

## 四、指针：把“哪个位置”传给函数

### 16. 地址、解引用与输出参数

`&x`取得变量地址，`int *p`声明可指向int的指针，`*p`访问所指整数。这里的星号由所在位置区分是声明、解引用还是乘法。使用指针前必须保证它指向仍存在、类型正确的对象，不能解引用未初始化、空或已经释放的指针。

```c
void set_zero(int *p) {
    *p = 0;
}
/* 在main中：int x = 7; set_zero(&x); 此后x为0。 */
```

普通值参数只能改副本；传地址后，函数写`*p`就写到调用者原变量。多个指针形参可带回多个结果，数组形参也允许处理调用者的元素。`(*p)++`增加所指数值，`p++`移动指针到下一元素；T指针加1按一个T的大小移动，不能把它理解为固定加一个字节。数组尾后位置可用于比较，但不能取值。

void*是通用对象地址，缺少具体元素类型。qsort把元素地址交给比较回调，回调再转成与数组一致的指针并读取；返回负、零、正，表达元素的先后关系。不要用两数直接相减作比较结果而忽略相减溢出。

例题：[通用指针与qsort比较回调](problems/ch05-array-30.md)、[字符指针前进](problems/ch06-10.md)、[写回计数](problems/ch06-11.md)、[写回多个结果](problems/ch06-20.md)。

## 五、C++：从标准库对象到自己的类

### 17. string、vector与流

C++标准库名字放在std命名空间，用`std::`限定来源。cin的`>>`按类型读取并以空白分词，cout的`<<`可以连续输出；读取成功可作为循环条件。getline读整行、保留内部空白并去掉分隔换行。cout中的`'\n'`只输出换行，endl还刷新缓冲区。

std::string自动管理字符串存储，vector<T>管理一串同类型对象；push_back向末尾追加。它们仍有有效下标限制，size()返回无符号长度，空容器不能取size()-1位置。string的==比较内容，<按字典序比较；find找不到时返回npos，substr从指定字节位置取片段，empty判空后才可back或pop_back。

```cpp
std::vector<std::string> words;
std::istringstream input(line);
std::string word;
while (input >> word) words.push_back(word);
for (const std::string &s : words) std::cout << s << '\n';
```

istringstream把已有文本变成可提取单词的输入流；范围for依次访问元素。`const std::string &s`是已有元素的只读别名，避免复制；`int &a`作为函数形参时可修改调用者变量，调用不需要再显式取地址。声明里的引用符号与表达式里的取地址用途不同。

流格式操纵器也有状态：setw只影响紧接着的一项；fixed与setprecision配合控制小数位，通常持续影响后续输出，要按需要恢复。static_cast是C++显式转换写法，仍需遵守目标类型的可表示范围。

例题：[C++字符串与输入输出](problems/ch05-string-17.md)、[vector和字符串片段](problems/ch05-string-27.md)、[const引用](problems/ch05-string-29.md)、[字符串输入流](problems/ch05-string-49.md)、[引用参数](problems/ch07-06.md)、[流格式](problems/ch07-05.md)。

### 18. 类把数据与相关操作放在一起

```cpp
class Dog {
private:
    int age;
public:
    Dog(int a) : age(a) {}
    int getAge() const { return age; }
    void grow(int years) { age += years; }
};
```

class定义类型，`Dog jack(2)`创建对象，`jack.grow(3)`经点号调用方法。每个对象各有自己的普通成员。本题集中private数据通过类的成员函数访问，public构成外部接口；方法后的const表示不通过当前对象修改普通成员，适合只读显示和get方法。

构造函数与类同名、没有返回类型，创建对象时自动执行。冒号后的成员初始化列表在函数体前初始化成员，实际次序按成员声明顺序。非静态方法内的this指向当前对象，`this->age`明确访问当前成员；`p->member`等价于`(*p).member`。

默认实参允许省略调用最右侧的参数；函数重载则要求同名函数的参数类型或个数不同，编译器根据实参选择，仅返回类型不同不算重载。static成员由整个类共享，静态方法没有this；C++11常规写法还需在类外定义静态数据成员。

例题：[类与访问控制](problems/ch07-01.md)、[函数重载](problems/ch07-04.md)、[构造初始化](problems/ch07-07.md)、[this与默认实参](problems/ch07-13.md)、[静态成员](problems/ch07-14.md)。

### 19. 组合、拷贝与资源生命周期

组合是“拥有”：Line中有两个Point成员。成员对象先构造，外层构造函数体再执行。`Line line2(line1)`是用已有对象初始化新对象，即拷贝构造；编译器生成的版本通常逐成员复制，手工拥有动态资源的类不能直接假设这种浅复制足够。

`new int[n]`创建动态数组，使用后配对`delete[]`，不能误用普通delete，也不能释放后继续访问。自动管理存储的string、vector通常省去这些手工步骤。析构函数`~Type()`在对象生命周期结束时清理；局部对象离开作用域会自动析构，不必手工调用它。创建包含基类、成员子对象的对象时，从内部依赖到外层完成构造，销毁顺序相反。

例题：[动态数组](problems/ch07-05.md)、[组合与拷贝](problems/ch07-16.md)、[构造析构的可见顺序](problems/ch07-20.md)。

### 20. 继承、抽象接口与动态多态

公有继承表达“是一种”：Book是一种Document。基类的private成员仍受保护，派生类不能直接访问；protected允许本类和派生类使用，但不向main公开。派生构造函数在初始化列表中先调用基类构造函数，再初始化自身成员。

virtual允许派生类重写相同签名的方法，override让编译器核对确实发生重写。通过基类指针或引用调用虚函数时，实际对象类型决定运行哪个版本；同一个Container指针可分别指向Sphere、Cylinder、Cube。重载按调用参数在编译期选择，动态多态按对象实际类型在运行期选择，两者不能混为一谈。

纯虚函数写成`virtual void getArea() = 0;`，含未实现纯虚函数的类不能直接创建对象，具体派生类要完成实现。多态基类的析构函数应为virtual，才支持通过基类指针delete派生对象时正确清理。多继承同时列出几个基类，按声明次序构造；遇到同名成员可用`Date::display()`等限定来源。

例题：[继承和protected](problems/ch07-18.md)、[纯虚接口](problems/ch07-19.md)、[多继承](problems/ch07-23.md)、[基类指针的动态调用](problems/ch07-24.md)。

## 做题时如何使用这份汇总

遇到不会读的写法，先找本页相应专题，再打开所链接的首次例题。读懂后回到当前题，只跟踪本题的变量、下标与边界，不必重读后续页面里重复的基础定义。运行时至少试一次题目样例，再补一个会改变分支或碰到端点的小用例，例如0项、相等值、首尾位置、整除、进位、缺失目标；比较输出时同时检查空格、标点、补零和小数位。
