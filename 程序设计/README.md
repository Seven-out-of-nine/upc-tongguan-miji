# 程序设计：从零开始学做题

[返回仓库首页](../README.md)

本目录整理当前保存网页中的 **241 道编程题**。每题都有原题、适合入门的解答、步骤讲解、知识点总结、易错点和相似题链接，可直接在 GitHub 阅读。基础部分以标准 C11 为主，明确需要类、引用、重载、继承或动态多态等功能时使用 C++11。

## 先从这里开始

1. [零基础起步](零基础起步.md)：先运行第一个程序，认识变量、输入输出和测试。
2. 按第2章 → 分支 → 循环 → 数组 → 字符串 → 函数与指针 → 面向对象的顺序学习；函数初步可在学完分支后先读。
3. 每题先自己写出“读什么、怎么算、输出什么”，卡住时看讲解，再对照解答。
4. 做完沿页尾的相似题链接再做一题，检查自己能否迁移方法。
