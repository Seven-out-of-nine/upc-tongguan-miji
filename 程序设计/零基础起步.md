## 第一个程序怎样运行

先安装或打开学校要求的 C/C++ 开发环境，新建源文件。C程序文件名以`.c`结尾，C++程序以`.cpp`结尾。把题解中的“完整本地运行程序”复制进去，保存为UTF-8，再编译、运行。使用Code::Blocks或Dev-C++时，编译运行按钮会完成这两步。

“编译”是把源码翻译成可执行程序；“运行”是执行翻译后的程序。编译失败时先看最前面的错误，常见原因是少分号、括号不成对、把英文标点写成中文标点。

```c
#include <stdio.h>
int main(void) {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("%d\n", a + b);
    return 0;
}
```

输入`3 4`后回车，程序输出`7`。`int a,b`准备两个放整数的变量；`scanf`把输入存进去；`printf`把相加结果显示出来。`&a`表示把变量a的地址交给输入函数，让它知道该把数写在哪里。

## 读题时先填三句话

- 输入：读几个数？是整数、小数、单个字符，还是一整行文字？一组还是多组？
- 处理：需要算公式、按条件分类、循环累加，还是保存一批数据？先拿样例在纸上算一遍。
- 输出：每行输出什么？需要几位小数？有没有固定提示文字、逗号、空格？

输入的样例是给程序的，输出的样例是程序应显示的。不要把“输入：”“输出：”这些说明文字也打印出来。少数面向对象演示题明确含输入提示语，应按该题样例保留。

## 先记住这些写法

| 写法 | 在本资料中的常见用途 |
| --- | --- |
| `int n;` | 保存一个整数；较大整数常用`long long` |
| `double x;` | 保存带小数的数，`scanf`读它用`%lf` |
| `printf("%.2f",x);` | 输出小数点后两位 |
| `if (条件) ... else ...` | 根据条件选择不同处理 |
| `for (int i=0;i<n;i++)` | 重复n次，下标依次是0到n-1 |
| `while (条件)` | 重复次数未事先确定时继续处理 |
| `a[i]` | 取数组中下标为i的元素，第一项下标是0 |
| `'3' - '0'` | 把数字字符变为整数3 |
| `s[k]='\0';` | 给字符数组中的字符串补结束标记 |

`=`是赋值，`==`才是判断相等。整数`7/2`得到3，想得到3.5可写`7.0/2`。`%`是余数运算，`7%2`为1。负奇数判断用`n%2!=0`，因为负数的余数可能是-1。

## 函数题到底提交哪一部分

如果页面给了“前置代码”和“后置代码main”，平台已经替你准备好了程序框架。题解的“平台提交版”通常只是一两个函数，不要再交一个main。想在自己电脑上运行，就展开“完整本地运行程序”，或下载源码目录里的文件。

原题预设代码按原样保留，有些含非标准头文件或输入边界问题；学习和本地编译请优先用题解给出的完整程序。每题的说明会指出重要差异。

## 怎样用测试检查自己

先跑原样例，再补一个能检查边界的例子：判断区间时试分界点；找最大值时试全负数；删字符时试全部被删；排序时试已经有序、逆序、重复数字。程序“能运行”不等于“答案正确”。

如果样例过了却仍然不对，优先检查：数组有没有越界、字符串有没有结束符、整数中间结果有没有溢出、输出格式是否一致，以及题目要求的递归、类或引用是否真的使用了。

## 用命令行编译（可选）

在有GCC的终端里，C程序可这样编译：

```sh
gcc -std=c11 solutions/ch02-01.c -o hello
```

需要`sqrt`等数学函数时，在Linux等环境补上`-lm`。C++用：

```sh
g++ -std=c++11 solutions/ch07-01.cpp -o date
```

保存和终端均使用UTF-8，才能正常显示含中文的演示输出。旧MinGW如果对标准`%lld`读写异常，可编译时补`-D__USE_MINGW_ANSI_STDIO=1`。本资料附带的校验脚本已经包含该兼容选项。
