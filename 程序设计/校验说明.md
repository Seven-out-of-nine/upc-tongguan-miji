# 源码与题解校验

[学习首页](README.md)

本目录每道题都有一份完整独立源码，C采用C11，C++采用C++11。函数题的完整源码供本地运行，页面另列平台只需提交的片段。题目中的特定结构要求，例如递归、引用、动态分配、this、静态成员、组合与多态，也进行了人工对照。

## 自己运行检查

需要Python 3与GCC/G++。在本目录运行：

```sh
python tools/check.py
```

Windows编译器不在PATH中时，可指定编译器目录：

```sh
python tools/check.py --compiler-dir "C:/mingw64/bin"
```

只检查某一章时，例如指针与函数：

```sh
python tools/check.py --only ch06-
```

脚本编译每个程序，再执行`tests/cases.json`中的原题样例及额外用例。它保留输出中的前导空格，忽略每行行尾多余空格与最后空行，以兼容原网页中少数多出的行尾空白。示例中的三角形缩进、输出标签和数字格式仍会被检查。编译或用例失败时返回非零退出码。

## 检查范围

除逐题样例和补充用例外，整理过程中还做了独立对照：百行杨辉三角与精确组合数、长大整数加乘、数组内积中间超64位后抵消、贪心配对与穷举最优解、字符串中英文回文、重叠课程区间、费用与日期分界、负数及递归中间结果等。题干矛盾、缺少的范围和原代码问题在对应页说明。

测试覆盖的是本资料已保存的241道题及列出的用例，不包含第4章尚未保存的80道题，也不代表所有可能输入均已穷举。未明确规定的输入不擅自增加平台输出协议。最终运行统计见[校验记录](校验记录.json)。
