## 资料领取说明

本科目资料比较“狠”，暂不公开上传到仓库，**仅向参与仓库共创的同学提供**。

参与共创后，可以联系[仓库作者 Seven-out-of-nine](https://github.com/Seven-out-of-nine)申请领取，并附上自己的共创记录，例如分享资料、贡献笔记、协助勘误的 PR 或 Issue 链接。具体领取方式与作者沟通。

## 一起参与共创

欢迎分享自己整理的课程资料、学习笔记和复习经验，也欢迎帮助其他课程补充内容、核对答案、完善导航。

同学们公开分享的思政笔记统一放在[笔记分享](笔记分享/README.md)文件夹，操作方法见[贡献指南](../CONTRIBUTING.md)。
