# 油专通关秘籍 · 高等数学（2-1）

把课本框架、课堂内容、练习与真题串起来，按下面的路线复习。

**粗看课本知识点 → 复习 PPT → 重做练习册 → 做完近二十年真题（近五年精做，更早年份只想思路，数不用算）→ 课本练习题 → 高数学习指导。**

## 复习路线

| 顺序 | 做什么 | 具体做法 | 完成标准 |
| --- | --- | --- | --- |
| 1 | 粗看课本知识点 | 先看定义、定理条件、公式与例题类型，配合下面的知识点索引过一遍 | 能说清各章解决什么问题，能判断常见定理何时可用 |
| 2 | 复习 PPT | 按课堂顺序回顾老师强调的例题、证明与易错点 | 把课堂重点和知识点索引对应起来 |
| 3 | 重做练习册 | 遮住答案重新做，卡住时先定位知识点；做完再核对参考答案 | 错题能解释错因，隔一轮能独立重做 |
| 4 | 做完近二十年真题 | **近五年精做**：完整计算、写证明、核对答案并复盘；**更早年份只想思路即可，数不用算**：写出考点、条件、关键步骤或积分式 | 精做卷能独立完成；思路卷能讲清为什么这样做 |
| 5 | 课本练习题 | 根据真题暴露的薄弱点，回到课本补做对应习题 | 同类题换函数、换参数仍会做 |
| 6 | 高数学习指导 | 用综合题、章节总结补漏，再回看错题 | 定义、条件、计算、证明、应用都没有明显短板 |

遇到不会的题，按“题目 → 考点 → 定理条件 → 方法 → 易错点”记录；旧卷可以省略最后的数值运算，仍要写出关键推导和证明理由。
