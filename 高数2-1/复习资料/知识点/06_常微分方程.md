## 一、识别比套公式更重要

先看最高阶导数，再看未知函数及其导数是否只以一次幂线性出现。线性方程的系数只能依赖自变量；含 $yy'$、$(y')^2$ 等通常是非线性方程。

通解通常含与阶数相同个数的独立任意常数；初值条件用于确定常数。求出表达式后还要代回原方程，确认定义区间和初值。

| 观察到的形式 | 优先方法 |
| --- | --- |
| $y'=f(x)g(y)$ | 分离变量，并单独检查 $g(y)=0$ 对应的常值解 |
| $y'=F(y/x)$ | 设 $u=y/x$，即 $y=ux$，在 $x\ne0$ 的区间讨论 |
| $y'+P(x)y=Q(x)$ | 一阶线性积分因子法 |
| $y'+P(x)y=Q(x)y^n$ | 若课程覆盖伯努利方程，在 $y\ne0$ 且幂有定义的区间设 $z=y^{1-n}$，$n\ne0,1$；另查原方程有定义时的零解 |
| $y''=f(x)$ | 直接积分两次 |
| 不显含 $y$：$y''=f(x,y')$ | 令 $p(x)=y'$，得到一阶方程 |
| 不显含 $x$：$y''=f(y,y')$ | 局部令 $p(y)=y'$，用 $y''=p\,dp/dy$；另查被除掉的解 |
| $y''+py'+qy=f(x)$，$p,q$ 为常数 | 齐次通解 + 非齐次特解 |

一阶“齐次型” $y'=F(y/x)$ 与线性方程“右端为零”的齐次是两种不同概念。

## 二、分离变量与一阶线性

### 分离变量

由 $y'=f(x)g(y)$，在 $g(y)\ne0$ 的区间上写成

$$
\int\frac{dy}{g(y)}=\int f(x)\,dx+C.
$$

凡是除以 $g(y)$，就要回查 $g(y)=0$ 的常值解。积分后的隐式关系可以是合适的答案，不必为了显式表达强行开方丢掉分支。

### 一阶线性

对 $y'+P(x)y=Q(x)$，若 $P,Q$ 在区间 $I$ 上连续，取积分因子

$$
\mu(x)=e^{\int P(x)\,dx}.
$$

则 $(\mu y)'=\mu Q$，所以

$$
y=e^{-\int P(x)\,dx}
\left(\int Q(x)e^{\int P(x)\,dx}\,dx+C\right).
$$

复习时优先记住 **“乘积分因子，把左边变成乘积导数”**。若有初值 $y(x_0)=y_0$，可用无歧义的定积分形式：

$$
\mu(x)=\exp\!\left(\int_{x_0}^xP(t)\,dt\right),\qquad
y(x)=\frac{y_0+\int_{x_0}^x\mu(t)Q(t)\,dt}{\mu(x)}.
$$

有时把 $x$ 看作 $y$ 的函数更容易化成线性方程；转换时要检查局部可逆性及除法条件。

## 三、二阶常系数线性方程

先解齐次方程 $y''+py'+qy=0$，特征方程为

$$
r^2+pr+q=0.
$$

| 特征根 | 实通解 |
| --- | --- |
| 两个不同实根 $r_1,r_2$ | $y_h=C_1e^{r_1x}+C_2e^{r_2x}$ |
| 二重实根 $r$ | $y_h=(C_1+C_2x)e^{rx}$ |
| 共轭复根 $\alpha\pm i\beta$，$\beta>0$ | $y_h=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$ |

对非齐次方程 $y''+py'+qy=f(x)$，任取一个特解 $y_p$，则

$$
y=y_h+y_p.
$$

待定系数法的关键是**把同类型项设全，并判断重合**：

| 右端结构 | 特解试设 |
| --- | --- |
| $e^{\lambda x}P_m(x)$ | $x^s e^{\lambda x}Q_m(x)$，$Q_m$ 为含全部待定系数的 $m$ 次多项式 |
| $e^{\alpha x}[P_m(x)\cos\beta x+Q_n(x)\sin\beta x]$，$\beta>0$ | $x^s e^{\alpha x}[U_k(x)\cos\beta x+V_k(x)\sin\beta x]$，$k=\max(m,n)$ |

第一行 $s$ 是 $\lambda$ 作为特征根的重数；第二行 $s$ 是 $\alpha+i\beta$ 作为特征根的重数；不是特征根时取 $s=0$。二阶方程对应重数不超过 $2$。右端只有正弦时，通常也要同时设正弦和余弦两部分。

解题顺序：**特征根 → 齐次通解 → 特解形式 → 代回定系数 → 合并 → 用初值定常数**。

## 四、可降阶与应用题

对 $y''=f(x)$ 积分两次，每次引入一个常数。令 $p=y'$ 降阶后，还需要再解 $y'=p$；不能求得 $p$ 就结束。

对于 $y''=f(y,y')$，把 $p$ 看成 $y$ 的函数，需要在局部可把 $y$ 当变量的区间内使用链式法则；中途若除以 $p$，要另查 $p=0$ 的解。

应用题先写变量含义和初值，再列变化率关系。练习册 6.2、6.5 和上册模拟卷中可见变化过程与运动问题。复习时检查：

- 增长与衰减的正负号，例如 $M'=kM$ 中 $k<0$ 表示衰减。
- 运动中 $s'=v$、$v'=a$；阻力方向与速度方向相反。
- 排水等问题中，体积变化率与高度变化率通过 $V'(t)=S(h)h'(t)$ 联系。
- 求解区间要符合物理条件，如时间非负、质量或水量非负。

## 五、易错点

- 先化为 $y'+P(x)y=Q(x)$；$y'$ 前系数不是 $1$ 时，先在系数非零区间除过去。
- 分离变量时除掉未知函数，可能丢常值解；最后必须补查。
- 二重特征根的第二个解要乘 $x$。
- 非齐次特解与齐次解重合时，按重数乘 $x^s$；不能只凭感觉改系数。
- 通解中常数要独立；二阶初值问题通常需要两个条件。
- 初值应代入完整通解；不能只代入齐次部分或特解。
- 公式适用区间不能跨越系数奇点，如 $P(x)=1/x$ 时要分别在 $x>0$ 或 $x<0$ 讨论。

## 六、复习时自测

- [ ] $y'=xy$：能写通解，并核查 $y=0$ 是否包含其中。
- [ ] $y'+y=e^x$：能写积分因子和左侧的乘积导数。
- [ ] $y''-2y'+y=0$：能判断重根并写出两个独立解。
- [ ] $y''-2y'+y=e^x$：能说明特解为什么试设为 $Ax^2e^x$。
- [ ] $y''+y=\sin x$：能识别共振并设全特解形式。
- [ ] 对应用题，能先写出方程、初值、变量单位与合理区间。

旧真题只想思路时，至少写出方程类型、积分因子或特征根、特解试设和代初值步骤；系数计算与最后数值可留待精做。
