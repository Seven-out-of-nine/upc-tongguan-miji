如果仓库收录多门课程，建议上传为：

```text

└── 高数2-1/
    ├── README.md
    ├── .gitignore
    ├── 复习资料/
    ├── 补充资料/

    ├── 期末考试真题/

```

本目录内的 Markdown 使用相对链接，整目录放到仓库子目录后仍可浏览。可在仓库首页加：

```markdown
## 高等数学

- [高数（2-1）：复习路线、知识点与真题](高数2-1/README.md)
```

如果仓库只用于高数，也可把本目录中的内容直接放在仓库根目录，使用本 README 作为首页。

## 上传范围

上传本次整理后的目录内容。保留原始题目、答案和Word版本之间的相对位置，这样导航与报告中的来源链接不会失效。DOC／DOCX 在 GitHub 上不便直接阅读，可下载查看；新写的总结、报告和导航均为 Markdown。

`.gitignore` 排除了本地登记目录 `.fingerprints/`、压缩包和常见临时文件。若在网页端手动上传，仍需按资料包的清单选择文件；网页上传不会替你执行 Git 的忽略规则。

整理结果附有单独的 GitHub 资料包，解压后选择内部的 `高数2-1/` 目录即可。不要把压缩包本身当作可直接浏览的仓库内容。
