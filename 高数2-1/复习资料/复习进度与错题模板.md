## 更早年份：只想思路，数不用算

按导航逐年完成即可；2010—2011期末文件中的A、B卷分别记录。

| 日期 | 考试／学年／卷别 | 题号 | 考点 | 方法及关键条件 | 关键式／辅助函数／积分式 | 是否能独立讲清 |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

“只想思路”至少写到能执行的步骤，例如：令 $F=e^xf$ 并核对罗尔条件；或画区域后写出积分上下限、被积式。证明题须给出关键逻辑，应用题须完成建模；长篇代数与最终数值可以省略。

## 错题卡

复制下面的模板，一题一条。

```markdown
### 日期｜学年／卷别／题号

- 来源文件与PDF页码：
- 对应模块：
- 我的第一思路：
- 卡点／错因：概念、条件、分类、方法、计算、读题、时间分配
- 正确的关键步骤：
- 使用了什么定理，条件是否满足：
- 一句提醒：
- 待核对的问题：
- 下次复做日期：
- 遮住原解能否独立重做：
```

## 考前最后一轮

- [ ] 公式能写出适用条件，不只背表达式。
- [ ] 分段、绝对值、左右极限、分母为零等情况没有漏分支。
- [ ] 参数二阶导、变限求导、分部积分、共振特解等常错步骤已复查。
- [ ] 闭区间最值记得端点，反常积分记得拆开判断敛散。
- [ ] 概念简答能用自己的话解释并举例。
- [ ] 最近一次错题已在不看答案时重做；仍不确定的题有明确标记。
