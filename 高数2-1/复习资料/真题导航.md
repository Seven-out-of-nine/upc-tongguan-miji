## 年份口径与资料缺口

本表按最近 **20 个已结束学年：2006-2007—2025-2026** 建立索引，不把同一年的题目版、答案版、Word 版和拍照版重复算作多套。

- 期中已有明确年份资料 **18 个学年**；暂缺 `2015-2016`、`2020-2021`。
- 期末已有明确年份资料 **11 个学年**，连续覆盖 `2006-2007—2016-2017`；暂缺 `2017-2018—2025-2026`。
- 当前为 `2026-2027` 学年，按当前学年计算的近五学年是 `2022-2023—2026-2027`。文件夹尚无 `2026-2027` 真题，不能把旧卷标成这一学年的试卷。
- 现有最新五套期中卷是 **2021-2022—2025-2026**，可先作为完整精做组；它们与“按当前学年计的近五年”不是同一个区间。

缺口指未找到对应的明确年份试卷，不表示这些年份未组织考试；年份不明的旧 Word 文件也没有擅自归入缺失年份。

## 怎么做

按 README 路线完成课本概览、PPT 和练习册后，再进入真题阶段。

| 训练方式 | 完成标准 |
|---|---|
| 近五年精做 | 对已有卷限时独立作答，写完整过程并算出结果；证明题写清条件和推导，简答题也完整作答。做完后核对、订正，隔一段时间重做错题。 |
| 更早真题过思路 | 每题写出“考什么、用什么方法、关键步骤、适用条件”。计算题列到可执行的关键变形或积分式即可，后续数值运算可以省略；证明题至少写出辅助函数、所用定理和推导主线。 |
| 有答案、无题目版 | 先遮住答案，只看题干。能说出思路后再核对，避免把看懂答案当作会做。 |
| 没有可靠答案 | 保留自己的过程和疑问，回查课本、练习册或向老师核实。个人手写演算只供比较，不直接当成标准答案。 |

目前可先精做现有最新五套期中卷；补到 `2026-2027` 试卷后，将该卷加入精做区。期末近五年资料仍待补齐。若需要先练期末整卷，可以从现有最新的 `2012-2013—2016-2017` 五套开始，但应注明它们是旧卷，不能当作近期命题范围的证明。
