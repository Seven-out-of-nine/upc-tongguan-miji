# 计算机导论 · 笔记分享

[返回本课程](../README.md) · [返回社区首页](../../README.md) · [贡献教程](../../CONTRIBUTING.md)

这里收集同学们分享的计算机导论课堂笔记、知识总结、错题笔记和复习笔记。

本课程的同学笔记统一放在 **`计算机导论/笔记分享/`**，可在其中按学年、章节或主题分类。课件、习题等其他资料按课程相应分类放置。

- 文件名写清章节或主题，适用学年按实际情况注明。
- 简要说明内容、整理者／来源，标清待核对的部分。
- 保留原作者署名与授权说明，去除学号、联系方式等个人信息。

在自己的 Fork 中进入本目录上传笔记并提交，再向主仓库发起 PR。完整操作见[网页上传教程](../../README.md#first-upload)。
